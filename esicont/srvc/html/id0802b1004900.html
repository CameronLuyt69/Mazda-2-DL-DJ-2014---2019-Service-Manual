DTC U0100:00 [STANDARD DEPLOYMENT CONTROL SYSTEM]

id0802b1004900

System malfunction location
•  PCM communication error
Detection condition
•  The SAS control module does not receive CAN signal from PCM for 5 s or more, or receives CAN signal error from PCM for 0.4 s.
Fail-safe function
Not applicable
Possible cause
•  Malfunction in CAN line between the SAS control module and PCM
•  PCM malfunction
•  SAS control module malfunction
System wiring diagram
Not applicable


Diagnostic Procedure

•  Perform the malfunction diagnosis according to the troubleshooting procedure for the multiplex communication system. (See FOREWORD [SKYACTIV-G 1.3, SKYACTIV-G 1.5 (R.H.D.)].) (See FOREWORD [SKYACTIV-G 1.5 (L.H.D.)].) (See FOREWORD [SKYACTIV-D 1.5].)
