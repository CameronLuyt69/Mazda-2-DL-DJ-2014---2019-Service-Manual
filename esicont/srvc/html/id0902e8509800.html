DTC U2005:86 [INSTRUMENT CLUSTER]

id0902e8509800

Description

Error signal received from PCM
Detection condition
•  Instrument cluster receives the vehicle speed signal error from the PCM for 1 s or more with the ignition switched ON (engine off or on).
Fail-safe
Not applicable
Possible cause
•  DTCs are stored in the PCM.
•  PCM malfunction
•  Instrument cluster malfunction
System wiring diagram
Not applicable
