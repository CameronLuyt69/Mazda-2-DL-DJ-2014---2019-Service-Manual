DTC U2300:55 [CONNECTIVITY MASTER UNIT]

id0902n7106600

Description

Instrument cluster configuration not implemented
Detection condition
•  The connectivity master unit (CMU) detected any of the following conditions with the ignition switched to ACC or ON (engine off or on).
―  Instrument cluster configuration not read
―  Configuration data cannot be written to connectivity master unit (CMU) memory.
Fail-safe
Not applicable
Possible cause
Note
•  To correctly write the configuration data, which is sent from the instrument cluster to the connectivity master unit (CMU), to the connectivity master unit (CMU), 3 s or more must have elapsed since the ignition was switched ON (engine off or on).
•  Instrument cluster configuration is not completed.
•  Connectivity master unit (CMU) malfunction
System wiring diagram
Not applicable

Diagnostic Procedure

Step

Inspection

Action
1
RESET CONFIGURATION DATA FROM INSTRUMENT CLUSTER TO CONNECTIVITY MASTER UNIT (CMU)
•  Using the M-MDS, perform the instrument cluster configuration with the As-Built data.
(See INSTRUMENT CLUSTER CONFIGURATION (USING READ/WRITE FUNCTION).)
•  Clear the DTC for the connectivity master unit (CMU) using the M-MDS.
(See CLEARING DTC [CONNECTIVITY MASTER UNIT].)
•  Switch the ignition ON (engine off or on) and wait for 10 s or more.
•  Retrieve the connectivity master unit (CMU) DTCs using the M-MDS.
(See DTC INSPECTION [CONNECTIVITY MASTER UNIT].)
•  Is the same DTC displayed?
Yes
Using the M-MDS, re-perform the instrument cluster configuration using the As-Built data, then go to the next step.
(See INSTRUMENT CLUSTER CONFIGURATION (USING AS-BUILT DATA).)
No
Go to Step 3
2
VERIFY THAT REPAIRS HAVE BEEN COMPLETED
•  Clear the DTC for the connectivity master unit (CMU) using the M-MDS.
(See CLEARING DTC [CONNECTIVITY MASTER UNIT].)
•  Switch the ignition ON (engine off or on) and wait for 10 s or more.
•  Retrieve the connectivity master unit (CMU) DTCs using the M-MDS.
(See DTC INSPECTION [CONNECTIVITY MASTER UNIT].)
•  Is the same DTC displayed?
Yes
Replace the connectivity master unit (CMU), then go to the next step.
(See CONNECTIVITY MASTER UNIT (CMU) REMOVAL/INSTALLATION.)
No
Go to the next step.
3
VERIFY IF OTHER DTCs DISPLAYED
•  Are any other DTCs displayed?
Yes
Repair or replace the malfunctioning part according to the applicable DTC troubleshooting.
(See DTC TABLE [CONNECTIVITY MASTER UNIT].)
No
DTC troubleshooting completed.
