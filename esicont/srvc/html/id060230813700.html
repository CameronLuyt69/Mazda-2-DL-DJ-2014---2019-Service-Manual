DTC U2300:54/U2300:55/U2300:56 [EPS CONTROL MODULE]

id060230813700

DTC
U2300:54
EPS configuration
U2300:55
U2300:56
DETECTION CONDITION
•  EPS control module detects configuration data not read or data error
FAIL-SAFE FUNCTION
•  U2300:54, U2300:56
―  Power steering malfunction indicator light does not Illuminate
―  EPS motor current control enabled
•  U2300:55
―  Power steering malfunction indicator light Illuminates
―  EPS motor current control enabled
POSSIBLE CAUSE
•  Configuration procedure is not done properly
•  Correct data cannot be received from instrument cluster
SYSTEM WIRING DIAGRAM
—


Diagnostic Procedure

Step

Inspection

Action
1
RECORD CONFIGURATION DATA
•  Switch the ignition OFF.
•  Switch the ignition ON (engine off or on), and maintain this condition for approx. 1 min.
•  Switch the ignition OFF, and maintain this condition for approx. 3 s.
•  Switch the ignition ON (engine off or on).
Go to the next step.
2
VERIFY EPS CONTROL MODULE DTC
•  Using the M-MDS, clear the DTC from the EPS control module.
(See CLEARING DTC [EPS CONTROL MODULE].)
•  Using the M-MDS, perform the EPS control module DTC inspection.
(See DTC INSPECTION [EPS CONTROL MODULE].)
•  Is the same DTC present?
Yes
Repeat the inspection from Step1.
If the malfunction recurs, go to the next step.
No
Go to Step5.
3
VERIFY INSTRUMENT CLUSTER DTC
•  Using the M-MDS, perform the instrument cluster DTC inspection.
(See DTC INSPECTION [INSTRUMENT CLUSTER].)
•  Are any DTCs present?
Yes
Go to applicable DTC inspection.
(See DTC TABLE [INSTRUMENT CLUSTER].)
Repair the instrument cluster, then perform the configuration for the instrument cluster.
(See INSTRUMENT CLUSTER DISASSEMBLY/ASSEMBLY.)
(See INSTRUMENT CLUSTER CONFIGURATION (USING AS-BUILT DATA).)
No
Go to the next step.
4
VERIFY EPS CONTROL MODULE DTC
•  Using the M-MDS, clear the DTC from the EPS control module.
(See CLEARING DTC [EPS CONTROL MODULE].)
•  Using the M-MDS, perform the EPS control module DTC inspection.
(See DTC INSPECTION [EPS CONTROL MODULE].)
•  Is the same DTC present?
Yes
Repeat the inspection from Step1.
If the malfunction recurs, replace the steering column, then go to the next step.
(See STEERING WHEEL AND COLUMN REMOVAL/INSTALLATION.)
No
Go to the next step.
5
VERIFY NO DTC IS PRESENT
•  Are any DTCs present?
Yes
Go to applicable DTC inspection.
(See DTC TABLE [EPS CONTROL MODULE].)
No
DTC troubleshooting completed.
