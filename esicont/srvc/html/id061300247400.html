CONTROLLER AREA NETWORK (CAN) OUTLINE

id061300247400

•  The electric power steering (EPS) control module (CM) sends and receives data to and from other modules via the CAN. For details on the CAN, refer to the [MULTIPLEX COMMUNICATION SYSTEM]. (See MULTIPLEX COMMUNICATION SYSTEM.)

Data sent

•  EPS status
•  Power steering malfunction indicator light on request
•  Power steering warning alarm operation request
•  Steering angle (relative angle)
•  Steering angle (estimated absolute angle)
•  Steering angle (absolute angle)
•  Steering torque
•  Motor current
•  Power consumption

Data received

•  Vehicle speed
•  Engine speed
•  i-stop status
•  Wheel-speed
•  Steering angle (absolute angle)
•  Central configuration data
