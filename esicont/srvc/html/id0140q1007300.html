ACCELERATOR PEDAL POSITION (APP) SENSOR [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1007300


Purpose/Function

•  Detects the accelerator pedal depression amount as basic information (mainly used to determine the throttle valve opening) and sends it to the PCM as an accelerator pedal opening angle signal.

Construction

•  Built into the accelerator pedal.
am3zzn00003618
•  An electromagnetic induction has been adopted as the detecting element for detecting the accelerator pedal depression amount.
•  The APP sensor has a main sensor (No.1) and a sub sensor (No.2) for improved detection accuracy.

Operation

•  Sends the signal, which fluctuates according to the accelerator pedal depression amount, to the PCM.
