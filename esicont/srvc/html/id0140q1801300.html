Voltage Inspection

Note
•  The fuel pressure sensor cannot be removed as a single unit. When replacing the fuel pressure sensor, replace it together with the fuel distributor as a single unit.

1.  Connect the M-MDS to the DLC-2.

2.  Switch the ignition ON (engine off).

3.  Start the engine and warm it up completely.

4.  Verify that the fuel pressure sensor output voltage (PID: FUEL_PRES) is within the specification. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-G 1.3, SKYACTIV-G 1.5].) (See PCM INSPECTION [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)

•  If not as specified, replace the fuel distributor. (See FUEL INJECTOR REMOVAL/INSTALLATION [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
