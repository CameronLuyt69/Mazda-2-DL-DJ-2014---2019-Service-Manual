FRONT STABILIZER CONTROL LINK INSPECTION

id021300800500

1.  Remove the front stabilizer control link. (See FRONT STABILIZER REMOVAL.) (See FRONT STABILIZER INSTALLATION.)

2.  Inspect the front stabilizer control link for bends or damage.

•  If there is any malfunction, replace the front stabilizer control link. (See FRONT STABILIZER REMOVAL.) (See FRONT STABILIZER INSTALLATION.)

3.  Rotate and shake the front stabilizer control link ball joint 10 times.

4.  Install a hexagonal wrench to the front stabilizer control link ball joint stud, and measure the rotational torque of the front stabilizer control link ball joint using a torque wrench.

am2zzw00008258

Front stabilizer control link ball joint rotational torque
0.8—3.5 N·m {8.2—35 kgf·cm, 7.1—30 in·lbf}
•  If not within the specification, replace the front stabilizer control link. (See FRONT STABILIZER REMOVAL.) (See FRONT STABILIZER INSTALLATION.)
•  Even when within the specification, if there is excessive play in the front stabilizer control link ball joint, replace the front stabilizer control link. (See FRONT STABILIZER REMOVAL.) (See FRONT STABILIZER INSTALLATION.)
