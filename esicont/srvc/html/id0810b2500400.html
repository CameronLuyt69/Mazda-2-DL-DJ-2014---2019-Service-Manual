AIR BAG SYSTEM WARNING ALARM [STANDARD DEPLOYMENT CONTROL SYSTEM]

id0810b2500400


Purpose

•  The air bag system warning alarm notifies the driver that a malfunction occurred in the air bag system if a malfunction occurs in the air bag/seat belt pre-tensioner system warning light.

Function

•  When the SAS control module detects DTC B00D2:01 (air bag/seat belt pre-tensioner system warning light (transmission related error)), it sends an air bag system warning alarm request signal to the instrument cluster if DTCs other than DTC B00D2:01 (except DTCs which do not turn on air bag/seat belt pre-tensioner system warning light) are detected.

•  When the air bag system warning alarm request signal sent by CAN communication from the SAS control module is received, the instrument cluster activates the buzzer.
•  The buzzer for the air bag system warning alarm has the following activation patterns as shown in the table.
am2zzn00002057

Construction

•  The air bag system warning alarm sounds a buzzer in the instrument cluster.

Operation

1.  When the ignition is switched ON (engine off or on), the instrument cluster receives (1) the air bag system warning alarm request signal from the SAS control module.

2.  The instrument cluster microcomputer turns the transistor on (2) based on the air bag system warning alarm request signal.

3.  When the transistor turns on, a ground circuit with the air bag system warning alarm is established and the buzzer activates (3).
