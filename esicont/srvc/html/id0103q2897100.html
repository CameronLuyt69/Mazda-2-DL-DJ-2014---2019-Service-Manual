CHECK ENGINE LIGHT ILLUMINATES
DESCRIPTION
•  Check engine light illuminates incorrectly.
Note
•  If there is a malfunction in the engine system, the PCM stores a DTC and illuminates the check engine light.
POSSIBLE CAUSE
•  Emission system malfunction (DTC is stored in PCM)
•  ATX related malfunction (DTC is stored in TCM) (ATX)
•  Short or open circuit in wiring harness between the following terminals:
―  Instrument cluster terminal 1B—Body control module (BCM) terminal 2D
―  Instrument cluster terminal 1D—Body control module (BCM) terminal 2C
―  Body control module (BCM) terminal 3C—PCM terminal 2C
―  Body control module (BCM) terminal 3D—PCM terminal 2D
•  Instrument cluster malfunction
