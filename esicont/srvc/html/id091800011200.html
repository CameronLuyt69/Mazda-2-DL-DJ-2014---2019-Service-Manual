HEADLIGHT LEVELING ACTUATOR

id091800011200


Purpose, Function

Vehicles with headlight manual leveling system
•  The headlight leveling actuator drives the motor and changes the headlight LO optical axis using current which flows according to the position to which the headlight leveling switch is switched.
Vehicles with headlight auto leveling system
•  The headlight leveling actuator drives the motor based on the target optical axis voltage, which is input from the auto leveling control module, to change the headlight LO optical axis.

Construction

•  The headlight leveling actuator is integrated with the front combination lights.
•  The headlight leveling actuator consists of a motor which expands/contracts the shaft, a shaft, and a microcomputer which calculates the shaft expansion/contraction amount.

Operation

Vehicle with headlight manual leveling system
1.  The headlight leveling actuator calculates the motor drive amount based on the current (1) which flows according to the position the headlight leveling switch is switched to, and it drives (2) the motor until the optical axis reaches the target optical axis.
2.  When the motor is driven, the shaft moves (3) back and forth and the reflector moves to change (4) the optical axis.

Vehicles with headlight auto leveling system
1.  The headlight leveling actuator calculates the motor drive amount based on the target optical axis signal (1) from the auto leveling control module and drives (2) the motor until the optical axis reaches the target optical axis.
2.  When the motor is driven, the shaft moves (3) back and forth and the reflector moves to change (4) the optical axis.
