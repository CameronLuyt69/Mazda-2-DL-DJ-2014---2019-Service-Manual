REAR WHEEL HUB BOLT REPLACEMENT [REAR BRAKE (DISC)]

id0312a7800200

1.  Remove the rear brake caliper component and suspend it out of the way using a cable. (See WHEEL HUB COMPONENT REMOVAL/INSTALLATION [REAR BRAKE (DISC)].)

2.  Remove the rear disc plate. (See WHEEL HUB COMPONENT REMOVAL/INSTALLATION [REAR BRAKE (DISC)].)

3.  Remove the rear wheel hub bolt using the SST as shown in the figure.

am2zzw00007236

4.  Place a new rear wheel hub bolt in the wheel hub component.

5.  Install the rear wheel hub bolt by placing an appropriate-sized washer on the wheel hub component and tightening the wheel nut as shown in the figure.
