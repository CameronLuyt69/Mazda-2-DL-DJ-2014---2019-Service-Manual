SYMPTOM TROUBLESHOOTING [SEAT WARMER SYSTEM]

id0903m2970100

Troubleshooting item

Description
Seat warmer system does not operate
(See SEAT WARMER SYSTEM DOES NOT OPERATE [SEAT WARMER SYSTEM].)
•  The seat warmer does not warm up even if the seat warmer switch is turned on.
Seat warmer system operates constantly
(See SEAT WARMER SYSTEM OPERATES CONSTANTLY [SEAT WARMER SYSTEM].)
•  The seat warmer warms the seat even though the seat warmer switch is turned off.
Temperature for seat warmer system cannot be adjusted
(See TEMPERATURE FOR SEAT WARMER SYSTEM CANNOT BE ADJUSTED [SEAT WARMER SYSTEM].)
•  The temperature for the seat warmer cannot be adjusted (temperature level cannot be switched).
•  The seat warmer temperature continues to rise.
