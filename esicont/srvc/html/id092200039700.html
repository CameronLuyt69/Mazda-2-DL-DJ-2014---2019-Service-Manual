BLIND SPOT MONITORING (BSM) WARNING BUZZER

id092200039700


Purpose

•  The blind spot monitoring (BSM) warning buzzer alerts the driver of a possible collision with an approaching vehicle when changing lanes or backing up.

Functions

•  When the instrument cluster receives a blind spot monitoring (BSM) warning request signal from the blind spot monitoring (BSM) control module (LH), the blind spot monitoring (BSM) warning buzzer in the instrument cluster is activated.
•  The blind spot monitoring (BSM) warning buzzer sound pattern is a shown in the figure.
am2zzn00002034

Construction

•  The blind spot monitoring (BSM) warning buzzer is integrated with the instrument cluster, and it produces a buzzer sound.

Operation

1.  The instrument cluster receives (1) the blind spot monitoring (BSM) warning request signal from the blind spot monitoring (BSM) control module (LH).
2.  The instrument cluster turns the transistor on (2) based on the warning sound request signal.
3.  When the transistor turns on, a ground circuit with the buzzer is established, and the blind spot monitoring (BSM) warning buzzer is activated (3).
