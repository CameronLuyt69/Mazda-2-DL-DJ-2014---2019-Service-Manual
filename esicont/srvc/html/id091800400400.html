HEADLIGHT MANUAL LEVELING SYSTEM

id091800400400


Outline

•  The headlight manual leveling system changes the headlight LO optical axis according to the operation of the headlight leveling switch to prevent driver dazzle from the headlight glare of oncoming vehicles and to assure a range of visibility.

Function

•  When the headlight leveling switch is turned upward, the headlight LO optical axis moves upward. When the switch is turned downward, the axis moves downward.

Operation

1.  When the headlight leveling switch is operated (1) with the headlights LO turned on, the resistance value changes according to the changed position, and electric current flows (2) to the headlight leveling actuator.

2.  When electric current flows to the headlight leveling actuator, the motor inside the actuator operates (3) and the headlight LO optical axis changes (4).
