ADVANCED KEYLESS ENTRY SYSTEM DOES NOT OPERATE [SECURITY AND LOCKS]

id0903k7012100

Description
•  The door locking operation using the door request switch is not possible.
•  The liftgate/trunk lid cannot be open using the liftgate/trunk lid opener switch.
Possible Causes
•  Liftgate/trunk lid opener switch malfunction
•  Open circuit in wiring harness between the following terminals:
―  BCM terminal 2S and liftgate opener switch terminal A/trunk lid opener switch terminal C
―  LF control unit terminal C and request switch (LF) terminal D
―  LF control unit terminal A and request switch (RF) terminal D
―  Start stop unit terminal 1P and door lock link switch (driver's side) terminal D (L.H.D.) / J (R.H.D.)
―  Start stop unit terminal 1AF and ground
―  Start stop unit terminal 2B and ground
•  Short to ground in wiring harness between start stop unit terminal 1P and door lock link switch (driver's side) terminal D (L.H.D.) / J (R.H.D.)
•  Connector poor contact or terminal damage
•  Customer's mis-operation or misunderstanding
