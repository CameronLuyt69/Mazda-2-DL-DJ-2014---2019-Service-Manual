LF CONTROL UNIT

id091400111400


Purpose

•  The keyless buzzer and keyless antenna are controlled by the input/output signals from the start stop unit.

Function

•  The LF control unit controls the keyless buzzer sound based on the signal from the start stop unit.
•  The LF control unit sends the request signal from the keyless antenna based on the signal from the start stop unit.

Construction

•  The LF control unit is located on the inside of the front side trim.
am2zzn00001823

Operation


Keyless buzzer control

1.  The LF control unit receives (1) a beeper sound request signal from the start stop unit.

2.  When the LF control unit receives the beeper sound request signal, it sounds (2) the keyless buzzer.

am2zzn00001824


Keyless antenna control

1.  The LF control unit receives (1) a request output signal from the start stop unit.

2.  When the LF control unit receives the request output signal, it outputs (2) the request signal from the keyless antenna.
