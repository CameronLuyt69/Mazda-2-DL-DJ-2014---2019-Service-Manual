FRONT FOG LIGHT INDICATOR LIGHT

id091800041100


Purpose

•  The front fog light indicator light notifies the driver that the front fog lights are turned on.

Function

•  When the instrument cluster receives the front fog light signal sent from the BCM via CAN communication, it turns the front fog light indicator light on.

Construction

•  The front fog light indicator light is built into the instrument cluster.
am2zzn00002967

Operation

1.  When the light switch is moved to the TNS position and the fog light switch is moved to the F.FOG position with the ignition switched ON (engine off or on), the start stop unit sends (1) a front fog light signal to the BCM via CAN communication.
2.  The BCM sends (2) the front fog light signal to the instrument cluster.
3.  The instrument cluster turns the transistor on (3) based on the front fog light signal.
4.  When the transistor turns on, a ground circuit with the front fog light indicator light is established, and the front fog light indicator light turns on (4).
