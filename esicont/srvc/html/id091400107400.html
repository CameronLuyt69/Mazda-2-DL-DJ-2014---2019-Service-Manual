ADVANCED KEYLESS ENTRY SYSTEM

id091400107400


Outline

•  An advanced keyless entry system has been adopted which performs automatic authorization of the remote transmitter that the customer carries and locking/unlocking of the doors.

Function

•  Remote transmitter authorization is performed if any of the following operations is performed.
―  Locking/unlocking using a request switch on an outer handle
―  Locking/unlocking using a remote transmitter
―  Trunk lid opening using remote transmitter (4SD)
―  Opening the liftgate/trunk lid
•  Each turn light flashes to notify the user that the lock/unlock operation is completed.
•  The advanced keyless entry system has the following functions in the event that the user operates the system incorrectly or to prevent the user from leaving the vehicle without locking.
―  Auto re-lock function: After unlocking, if all doors or the liftgate/trunk lid are not opened and a period of time according to the personalized setting has elapsed, all doors are automatically locked.
―  Out-of-area (reception area) type auto lock function*: After closing all doors, when the remote transmitter is brought out of the reception area of the keyless antenna, all doors are automatically locked.
―  Remote transmitter pause function: If all doors are locked with a remote transmitter left in the vehicle, the functions of the remote transmitter inside the vehicle are paused.
―  Remote transmitter left-in-vehicle prevention function: If the liftgate/trunk lid is closed with a remote transmitter left in the vehicle, the liftgate/trunk lid can be opened by pressing the liftgate/trunk lid opener switch.
―  Warning function: Warns that there is a malfunction in the advanced keyless entry system or the system is operated incorrectly using any of the following:
•  Keyless beeper
•  Keyless warning alarm
•  KEY warning light (red)
*  :The initial value for the personalization setting is off. When using the function, turn the personalization setting on.

Remote transmitter battery voltage low indication function

•  This function notifies the driver that the battery voltage of the remote transmitter is low by flashing the KEY indicator light (green).

Operation


Lock/unlock operation using request switch on outer handle

Operation Conditions
•  When the request switch is on with all the following conditions met, lock/unlock operation is performed.
―  ACC relay and IG1 relay OFF (ignition switched OFF) detected
―  All door latch switch OFF (all doors closed condition) is detected
―  Liftgate latch switch OFF (liftgate closed condition) is detected (5HB)*1
―  The remote transmitter is within the reception area outside keyless antenna.
*1  :The operation conditions are included depending on the vehicle's period of manufacture.

1.  When the driver's or passenger's side request switch is pressed, a request switch on signal is input (1) to the start stop unit via the LF control unit.

2.  Based on the request switch on signal, the start stop unit sends (2) a request output signal to the LF control unit to verify that the remote transmitter is inside the reception area.

3.  The LF control unit outputs (3) the request signal from the outside keyless antenna of the door in which the request switch was pressed.

4.  The remote transmitter receives the request signal from the outside keyless antenna, and sends (4) ID data to the keyless receiver.

5.  The keyless receiver transmits (5) the received ID data to the start stop unit.

6.  The start stop unit verifies the ID data, and if it determines a programmed remote transmitter is outside the vehicle, it sends a lock/unlock request signal to the BCM and at the same time, it sends (6) a beeper sound request signal to the LF control unit.

7.  When the BCM receives the lock/unlock request signal, it sends (7) a lock/unlock signal to the electrical supply unit (ESU) via LIN communication.

8.  When the electrical supply unit (ESU) receives the lock/unlock signal, it operates (8) the front/rear door lock actuator motor to lock/unlock the front/rear doors.

Note
•  It takes approx. 1—2 s from when a request switch is pressed until the lock/unlock operation is completed.

9.  When the LF control unit receives the beeper sound request signal, it operates (9) the keyless beeper for the following number of times:

―  Lock: Sounds once
―  Unlock: Sounds twice

10.  The BCM flashes (10) each turn light as follows:

•  Lock: Each turn light flashes once
•  Unlock: Each turn light flashes twice

Lock/unlock operation using remote transmitter

Operation Conditions
•  When door locking is performed
―  Lock operation is performed when the lock button of the remote transmitter is operated with all of the following conditions met.
•  ACC relay and IG1 relay OFF (ignition switched OFF) detected
•  All door latch switch OFF (all doors closed condition) is detected
•  Liftgate latch switch OFF (liftgate closed condition) is detected (5HB)*1
*1  :The operation conditions are included depending on the vehicle's period of manufacture.
•  When door unlocking is performed
―  When the unlock button of the remote transmitter is operated with the ACC relay and IG1 relay OFF (ignition switched OFF) detected, unlock operation is performed.

1.  When the lock or unlock button of the remote transmitter is pressed, the remote transmitter sends (1) ID data.

2.  When the keyless receiver receives ID data, it transmits (2) the data to the start stop unit.

3.  The start stop unit verifies the ID data, and if the ID data match, it sends (3) a lock/unlock request signal to the BCM and at the same time, it sends (3) a beeper sound request signal to the LF control unit.

4.  When the BCM receives the lock/unlock request signal, it sends (4) a lock/unlock signal to the electrical supply unit (ESU) via LIN communication.

5.  When the electrical supply unit (ESU) receives the lock/unlock signal, it operates (5) the front/rear door lock actuator motor to lock/unlock the front/rear doors.

6.  When the LF control unit receives the beeper sound request signal, it operates (6) the keyless beeper for the following number of times:

―  Lock: Sounds once
―  Unlock: Sounds twice

7.  The BCM flashes (7) each turn light as follows:

•  Lock: Each turn light flashes once
•  Unlock: Each turn light flashes twice

Liftgate/Trunk lid open operation

Operation Conditions
•  When the remote transmitter is in outside the keyless antenna reception area, the liftgate/trunk lid is opened by pressing the liftgate/trunk lid opener switch.

1.  When the liftgate/trunk lid opener switch is turned on, the liftgate/trunk lid opener signal is input (1) to the BCM.

2.  The BCM sends (2) the liftgate/trunk lid open signal to the start stop unit.

3.  Based on the liftgate/trunk lid open signal, the start stop unit sends (3) a request output signal to the LF control unit to verify that the remote transmitter is inside the reception area.

4.  Based on the request output signal from the start stop unit, the LF control unit outputs (4) a request signal using the keyless antenna inside the rear bumper.

5.  The remote transmitter receives the request signal from the antenna (outside, rear), and sends (5) ID data to the keyless receiver.

6.  The keyless receiver transmits (6) the received ID data to the start stop unit.

7.  The start stop unit verifies the ID data, and if the ID data matches, it sends (7) a liftgate/trunk lid release request signal to the BCM.

8.  When the BCM receives the liftgate/trunk lid release request signal, it sends (8) a liftgate/trunk lid release signal to the electrical supply unit (ESU) via LIN communication.

9.  When the electrical supply unit (ESU) receives the liftgate/trunk lid release signal, it operates (9) the liftgate/trunk lid lock actuator motor to open the liftgate/trunk lid.

am2zzn00001813


Trunk lid opening operation using remote transmitter

Operation Conditions
•  The trunk lid opens when the trunk lid open button of the remote transmitter is operated with the ACC relay and IG1 relay off (ignition switched OFF condition).

1.  When the trunk lid open button is pressed for approx. 0.5 s, the remote transmitter sends (1) the ID data to the keyless receiver.

2.  The keyless receiver transmits (2) the received ID data to the start stop unit.

3.  The start stop unit verifies the ID data, and if the ID data matches, it sends (3) a trunk lid release request signal to the BCM.

4.  When the BCM receives the trunk lid release request signal, it sends (4) a trunk lid release signal to the electrical supply unit (ESU) via LIN communication.

5.  When the electrical supply unit (ESU) receives the trunk lid release signal, it operates (5) the trunk lid release actuator motor to open and opens the trunk lid.

Auto re-lock function operation

1.  After the start stop unit sends an unlock request signal to the BCM, if any of the following conditions is not met for 30 s*1, it sends a lock request signal to the BCM.
―  Any of door latch switch or liftgate/trunk lid latch switch on signals (any door or liftgate/trunk lid open) received
―  Front door lock-link switch lock (driver's door locked) detected
―  ACC relay or IG1 relay ON (ignition switched to ACC or ON) detected
2.  When the BCM receives the lock request signal, it sends a lock signal to the electrical supply unit (ESU) and locks the front/rear doors.
*1  :Personalization setting time (See SECURITY AND LOCKS PERSONALIZATION.)


Out-of-area (reception area) type auto lock function operation

1.  The start stop unit goes on auto lock stand-by and operates the keyless beeper once when all of the following conditions are met.

•  ACC relay and IG1 relay OFF (ignition switched OFF) detected
•  Front door lock-link switch unlock (driver's door unlocked) detected
•  Remote transmitter is not within inside keyless antenna reception area
•  Remote transmitter is within outside keyless antenna reception area
•  All of door latch switches and liftgate latch switch off signals (all doors and liftgate closed) received from any of door latch switch or liftgate latch switch on signal (any door or liftgate open) received

2.  After entering stand-by status, the start stop unit verifies that the remote transmitter is within the keyless antenna reception area. When the remote transmitter is moved out of the keyless antenna reception area or approx. 30 s have elapsed, it performs a lock operation on all of the lock actuators, and operates the keyless beeper once.


Remote transmitter pause function operation

When door locking is performed
1.  If a lock signal is input from the remote transmitter or the request switch while the start stop unit recognizes the remote transmitter inside the vehicle with all the following conditions met, the request signal is output using the inside keyless antenna. It also operates the keyless beeper for 10 s.
―  ACC relay and IG1 relay OFF (ignition switched OFF) detected
―  All door latch switches and liftgate/trunk lid latch switch off signals (all doors, liftgate/trunk lid closed) received
2.  When the remote transmitter inside the vehicle sends the ID data to the keyless receiver, the keyless receiver transmits the received ID data to the start stop unit.
3.  The start stop unit receives the ID data, and after approx. 32 s, it suspends the functions of the transmitter inside the vehicle.
When the liftgate/trunk lid is closed
1.  When the liftgate/trunk lid latch switch off signal (liftgate/trunk lid closed) is received with all the following conditions met, the request signal is output using the inside keyless antenna. It also operates the keyless beeper for 10 s.
―  ACC relay and IG1 relay OFF (ignition switched OFF) detected
―  All door latch switch off signals (all doors closed) received
―  Front door lock-link switch lock (driver's door locked) detected
―  Liftgate/trunk lid latch switch on signal (liftgate/trunk lid open) received
2.  When the remote transmitter inside the vehicle sends the ID data to the keyless receiver, the keyless receiver transmits the received ID data to the start stop unit.
3.  The start stop unit receives the ID data, and after approx. 32 s, it suspends the functions of the remote transmitter inside the vehicle.
Remote transmitter pause cancel operation
•  The functions of the paused remote transmitter are restored when any one of the following conditions is met:
―  Remote transmitter with which engine can be started is brought inside vehicle
―  Paused lock/unlock button of the remote transmitter is pressed


Remote transmitter left-in-vehicle prevention function operation

1.  When the start stop unit receives the liftgate/trunk lid latch switch off signal (liftgate/trunk lid closed) with all the following conditions met, it operates the keyless beeper for 10 s and the remote transmitter left-in-vehicle prevention function operates.
―  Liftgate/Trunk lid latch switch on signal (liftgate/trunk lid open) received
―  All door latch switch off signals (all doors closed) received
―  Front door lock-link switch lock (driver's door locked) detected
2.  When the liftgate/trunk lid opener switch is pressed while the remove transmitter left-in-vehicle prevention function is operating, the start stop unit verifies the remote transmitter ID data and if it determines that the transmitter is inside the vehicle, it sends a liftgate/trunk lid release request signal to the BCM.
3.  When the BCM receives a liftgate/trunk lid release request signal, it sends a liftgate/trunk lid release signal to the electrical supply unit (ESU) to open the liftgate/trunk lid.
•  When any of the following conditions is met while the remote transmitter left-in-vehicle prevention function is operating, the remote transmitter left-in-vehicle prevention function is canceled.
―  Lock/unlock operation using remote transmitter or request switch
―  Any door latch on signal (any door open) received
―  Vehicle speed of 10 km/h or more received
―  Liftgate/Trunk lid latch switch on signal to off signal (liftgate/trunk lid open to closed) received
