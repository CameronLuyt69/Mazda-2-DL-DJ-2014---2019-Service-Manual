LIGHTS-ON REMINDER WARNING ALARM

id092200019200


Purpose

•  The lights-on reminder warning alarm warns the driver that the TNS and headlights are not turned off.

Function

•  The instrument cluster controls the lights-on reminder warning alarm based on the following signals:

Signal name

Sending module/part name

Communication method
TNS signal
Start stop unit
HS-CAN
Driver's side front door latch switch on (door open) signal
BCM

•  If the ignition is switched off or ACC when all the above vehicle condition signals are received, the instrument cluster operates the lights-on reminder warning alarm.

am2zzn00002865

Construction

•  The lights-on reminder warning alarm sounds using the buzzer built into the instrument cluster.

Operation

1.  The instrument cluster receives (1) a TNS signal from the start stop unit and a driver's side front door latch switch on (door open) signal from the BCM via CAN communication.

2.  When the ignition is switched ACC or off, the instrument cluster turns the transistor on (2) based on each signal.

3.  When the transistor is turned on, the ground circuit with the lights-on reminder warning alarm is established and the lights-on reminder warning alarm operates (3).
