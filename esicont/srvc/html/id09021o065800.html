DTC U1A4B:54 [BLIND SPOT MONITORING (BSM) SYSTEM]

id09021o065800

Caution
•  When replacing a blind spot monitoring (BSM) control module (RH) having any of the following part numbers, it is necessary to replace the blind spot monitoring (BSM) control module (LH) at the same time to perform the configuration normally.
―  DA6A-67Y80 A
―  DA6A-67Y80 B

Description

Radar aiming is not performed or radar sensor axis is deviated (Blind spot monitoring (BSM) control module (RH))
Detection condition
•  Malfunction in radar aiming of the blind spot monitoring (BSM) control module (RH) detected for 1 s or more with the ignition switched ON (engine off or on).
Fail-safe
•  Blind spot monitoring (BSM) system is stopped.
Possible cause
•  Blind spot monitoring (BSM) radar aiming (RH) was not performed.
•  Deviation of blind spot monitoring (BSM) control module (RH) radar sensor axis
•  Blind spot monitoring (BSM) control module (RH) malfunction
System wiring diagram
Not applicable

Step
