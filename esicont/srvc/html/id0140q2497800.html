PID/DATA Monitor Inspection

Note
•  The actuator position sensor of the turbocharger with variable turbine geometry is built into the turbocharger actuator. turbocharger actuator is built into the turbocharger with variable turbine geometry. When replacing the actuator position sensor of the turbocharger with variable turbine geometry, replace the turbocharger with variable turbine geometry itself.

1.  Connect the M-MDS to the DLC-2.

2.  Switch the ignition ON (engine on).

3.  Access the PID/DATA monitor item VGTURB_ACT and simulation item VGTURB_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

4.  Verify that the VGTURB_ACT monitor value conforms to the VGTURB_DSD monitor value when the simulation item VGTURB_DSD is set from 0 % to 90 %.

•  If not as verified, replace the turbocharger with variable turbine geometry. (See TURBOCHARGER WITH VARIABLE TURBINE GEOMETRY REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
