SECURITY AND LOCKS PERSONALIZATION

id091400111100

Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the Mazda Modular Diagnostic System (M-MDS). Do not select [Not equipped] in the setting displayed on the Mazda modular diagnostic system (M-MDS).
•  A personalization feature has been adopted which switches each function between operation/non-operation.
•  The settings of the following functions, and warning and guidance functions for the system can be turned ON/OFF optionally.
•  The Mazda Modular Diagnostic System (M-MDS) is required to perform the setting. Refer to the SECURITY AND LOCKS PERSONALIZATION FEATURES SETTING PROCEDURE in the workshop manual for the detailed setting procedure.
