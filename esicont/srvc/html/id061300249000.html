POWER STEERING WARNING BUZZER

id061300249000


Purpose

•  The power steering warning alarm warns the driver that the electric power steering (EPS) system is in backup control. (See ELECTRIC POWER STEERING (EPS) CONTROL MODULE.)

Function

•  When the EPS control module (CM) detects a motor rotation angle sensor internal malfunction, it switches to the motor rotation angle sensor backup control, and after a certain period of time has elapsed, it outputs a power steering warning alarm request signal to the instrument cluster.
•  The instrument cluster sounds the power steering warning buzzer intermittently when it receives the power steering warning buzzer request signal.
am2zzn00002172

Construction

•  The power steering warning buzzer sounds using the buzzer built into the instrument cluster.

Operation

1.  The instrument cluster received (1) the power steering warning buzzer request signal from the EPS CM.

2.  The instrument cluster microcomputer turns the transistor on (2) based on power steering warning buzzer request signal.

3.  When the transistor turns on, a ground circuit with the alarm is established and the alarm sounds (3).
