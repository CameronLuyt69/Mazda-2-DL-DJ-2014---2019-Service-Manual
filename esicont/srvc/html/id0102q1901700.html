DTC U0433:00

Abnormal message from laser sensor
DETECTION CONDITION
•  Correct data cannot be received from laser sensor.
Diagnostic support note
•  This is a continuous monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA is not available.
•  Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
•  Inhibits the smart city brake support control.
•  Displays a message related to a smart city brake support in the display. (With center display)
•  Illuminates smart city brake support (SCBS) indicator light (amber).
POSSIBLE CAUSE
•  Laser sensor malfunction
SYSTEM WIRING DIAGRAM
Not applicable
