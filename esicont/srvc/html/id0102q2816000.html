OBD ON-BOARD SYSTEM READINESS TEST [SKYACTIV-D 1.5]

id0102q2816000

•  This shows the OBD systems operating status. If any monitor function is incomplete, the M-MDS will identify which monitor function has not been completed. The Misfire, Fuel System and CCM are continuous monitoring-type functions. The A/F sensor, A/F sensor heater and catalyst will be monitored under drive cycles. The OBD diagnostic system is initialized by performing the DTC cancellation procedure or disconnecting the negative battery cable.
