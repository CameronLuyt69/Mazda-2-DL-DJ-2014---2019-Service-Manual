DTC P2226:00 [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0102q1159300

Note
•  To determine the malfunctioning part, proceed with the diagnostics from "Function Inspection Using M-MDS".

Details On DTCs

DESCRIPTION

BARO sensor range/performance problem
DETECTION CONDITION
Determination conditions
•  Communication error between BARO sensor and PCM
•  Non-volatile memory error in BARO sensor
Preconditions
•  Battery voltage: 10.5—16 V*1
*1: Value can be verified by displaying PIDs using M-MDS
Malfunction determination period
•  5 s period
Drive cycle
•  1
Self test type
•  CMDTC self test, KOEO self test, KOER self test
Sensor used
•  BARO sensor (built-into PCM)
FAIL-SAFE FUNCTION
•  Fixes the barometric pressure for the engine control at 101.32 kPa {1.0332 kgf/cm2, 14.695 psi}.
VEHICLE STATUS WHEN DTCs ARE OUTPUT
•  Not applicable
POSSIBLE CAUSE
•  BARO sensor (built-into PCM) malfunction
•  PCM malfunction


System Wiring Diagram

•  Not applicable

Function Explanation (DTC Detection Outline)

•  If there is a communication error between the BARO sensor and the CPU or a malfunction in the non-volatile memory inside the BARO sensor, the PCM stores a DTC.
