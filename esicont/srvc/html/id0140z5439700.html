ACTUATOR POSITION SENSOR (TURBOCHARGER WITH VARIABLE TURBINE GEOMETRY) [SKYACTIV-D 1.5]

id0140z5439700


Purpose/Function

•  The actuator position sensor detects the open/closed condition of the variable nozzle which drives the turbocharger actuator of the variable geometry turbocharger as basic information for mainly boost control.
•  The actuator position sensor detects the open/closed condition of the valve which drives the turbocharger actuator of the variable geometry turbocharger and sends the signal to the PCM as a turbocharger actuator opening angle signal.

Construction

•  The actuator position sensor of the variable geometry turbocharger is located on the turbocharger actuator.
am2zzn00003726
•  The actuator position sensor of the variable geometry turbocharger has adopted a Hall element to the detection area for detecting the open/closed condition of the valve which drives the turbocharger actuator of the variable geometry turbocharger.

Operation

•  The signal, which changes according to the open/closed condition of the variable nozzle driving the turbo actuator of the variable geometry turbocharger, is sent to the PCM.
