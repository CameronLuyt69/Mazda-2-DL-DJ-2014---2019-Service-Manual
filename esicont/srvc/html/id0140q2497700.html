Voltage Inspection

Note
•  The LP-EGR control valve position sensor is built into the LP-EGR control valve. When replacing the LP-EGR control valve position sensor, replace the LP-EGR control valve.

1.  Switch the ignition ON (engine off).

2.  Measure the voltage at the LP-EGR control valve terminal B.

am2zzw00011409

•  If the voltage is within the specification, go to the next step.
•  If the voltage is not within the specification, replace the LP-EGR control valve. (See LP-EGR CONTROL VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
Specification
1.05—1.35 V

3.  Connect the M-MDS to the DLC-2.

4.  Access the PID/DATA monitor item LP_EGR_ACT and simulation item LPEGR_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

5.  Verify that the LP_EGR_ACT monitor value conforms to the LPEGR_DSD monitor value when the simulation item LPEGR_DSD is set from 0 % to 80 %.

•  If not as verified, replace the LP-EGR control valve. (See LP-EGR CONTROL VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
