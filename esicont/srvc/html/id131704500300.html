i-ELOOP INDICATOR LIGHT (GREEN) [i-ELOOP]

id131704500300


Purpose, Function

•  The i-ELOOP indicator light (green) notifies the user that the i-ELOOP operation condition is in regenerative braking mode or pre-charge mode.

Construction

•  The i-ELOOP indicator light (green) is built into the instrument cluster.
am2zzn00003831

Operation

i-ELOOP operation condition is in regenerative braking mode
•  The i-ELOOP indicator light (green) turns on during regenerative braking mode. (With center display)
•  For vehicles with the center display, the energy generation status is displayed in the center display. For the message content and verification method, refer to the [CENTER DISPLAY].(See CENTER DISPLAY [WITH CENTER DISPLAY].)
i-ELOOP operation condition is in pre-charge mode
•  If the capacitor (i-ELOOP) voltage is low (such as capacitor (i-ELOOP) replacement) when the DC-DC converter (i-ELOOP) is replaced, the i-ELOOP indicator light (green) flashes in the initial pre-charge mode (only once).
•  When the capacitor (i-ELOOP) voltage is 9.5 V or more while in the pre-charge mode, the i-ELOOP indicator light (green) turns off.
•  The DC-DC converter (i-ELOOP) sends an i-ELOOP indicator light (green) flash request to the instrument cluster via CAN communication.
