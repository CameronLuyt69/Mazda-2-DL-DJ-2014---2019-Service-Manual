8

Smart Brake Support/Smart City Brake Support (SBS/SCBS) indicator light (amber) stay on
POSSIBLE CAUSE
•  Laser sensor internal malfunction.
•  DSC HU/CM internal malfunction.
•  DSC HU/CM detects a malfunction (input and output device malfunction).
•  PCM and/or instrument cluster internal malfunction.

Diagnostic procedure

STEP

INSPECTION

ACTION
1
CONFIRM LASER SENSOR DTC
•  Retrieve the laser sensor DTC using the M-MDS.
(See DTC INSPECTION [LASER SENSOR].)
•  Are any DTCs present?
Yes
Go to the applicable DTC inspection.
(See DTC INSPECTION [LASER SENSOR].)
No
Go to the next step.
2
CONFIRM DSC HU/CM DTC
•  Retrieve the DSC HU/CM DTC using the M-MDS.
(See DTC INSPECTION [DSC HU/CM].)
•  Are any DTCs present?
Yes
Go to the applicable DTC inspection.
(See DTC INSPECTION [DSC HU/CM].)
No
Go to the next step.
3
CONFIRM PCM DTC
•  Retrieve the PCM DTC using the M-MDS.
(See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
(See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)
•  Are any DTCs present?
Yes
Go to the applicable DTC inspection.
(See DTC TABLE [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
(See DTC TABLE [SKYACTIV-D 1.5].)
No
Retrieve the instrument cluster DTC using the M-MDS.
(See DTC INSPECTION [INSTRUMENT CLUSTER].)
•  If any DTCs are present, go to the applicable DTC inspection.
(See DTC TABLE [INSTRUMENT CLUSTER].)
•  If there is not a DTC, replace the instrument cluster.
(See INSTRUMENT CLUSTER REMOVAL/INSTALLATION.)
