TORSION BEAM AXLE REMOVAL/INSTALLATION [REAR BRAKE (DISC)]

id0214c8128000

Caution
•  Performing the following procedures without first removing the rear ABS wheel-speed sensor may possibly cause an open circuit in the wiring harness if it is pulled by mistake. Before performing the following procedures, disconnect the rear ABS wheel-speed sensor wiring harness (axle side) and fix the wiring harness to an appropriate place where it will not be pulled by mistake while servicing the vehicle.

1.  Remove the main silencer and the three-way catalytic converter as a single unit. (SKYACTIV-G 1.3, SKYACTIV-G 1.5) (See EXHAUST SYSTEM REMOVAL/INSTALLATION [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)

2.  Remove the main silencer and middle pipe as a single unit. (SKYACTIV-D 1.5) (See EXHAUST SYSTEM REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

3.  Remove the rear ABS wheel-speed sensor from the wheel hub component.

4.  Remove the rear ABS wheel-speed sensor wiring harness from the brackets and set it aside so that it does not interfere with the servicing.

5.  Disconnect the auto leveling sensor link. (With headlight auto leveling system)

am2zzw00008235

6.  Set the rear parking brake cable away from the torsion beam axle hook.

am2zzw00008246

7.  Remove the following parts. (See WHEEL HUB COMPONENT REMOVAL/INSTALLATION [REAR BRAKE (DISC)].)

(1)  Rear brake caliper component
(2)  Rear disc plate
(3)  Wheel hub component
(4)  Dust cover

8.  Support the torsion beam axle using a jack.

Warning
•  If the torsion beam axle falls off while it is removed/installed, it may cause serious injury or death, or vehicle damage. Always use a jack when removing/installing the torsion beam axle and verify that it is securely supported.

9.  Remove the rear coil spring. (See REAR COIL SPRING REMOVAL/INSTALLATION [REAR BRAKE (DISC)].)

10.  Remove the bolts. (See Torsion Beam Axle Installation Note.)

am2zzw00008248

11.  Lower the jack slowly and remove the torsion beam axle.

12.  Remove the bolts and nuts. (with dynamic damper)

am2zzw00012794

13.  Remove the dynamic dampers. (with dynamic damper)

14.  Install in the reverse order of removal.
