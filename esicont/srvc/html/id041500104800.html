CONTROLLER AREA NETWORK (CAN)

id041500104800


Outline

•  The DSC HU/CM sends and receives data to and from other modules via the CAN system. Refer to MULTIPLEX COMMUNICATION SYSTEM for a detailed explanation of the CAN system. (See MULTIPLEX COMMUNICATION SYSTEM.)

Data sent

•  Brake status
•  Cruise control system-related information
•  DSC system-related information
•  Engine Status
•  i-stop related information
•  Smart City Brake Support (SCBS)-related information
•  Vehicle speed
•  Wheel speed (LF, RF, LR, RR)
•  Yaw rate
•  Lateral-G
•  Longitudinal-G


Data received

•  Acceleration signal status
•  Accelerator pedal opening angle
•  Air bag system warning light on request
•  Ambient temperature
•  ATX gear position
•  Back-up light on request
•  Back-up light switch
•  Battery charge status
•  Brake light status
•  Brake switch (No.1 signal)
•  Clutch pedal stroke sensor
•  Collision detection (front, side, roll over)
•  Collision detection (rear)
•  Cruise control control status
•  Cruise control set speed
•  Cruise control switch
•  Cruise control switch signal
•  Cruise control system-related information
•  Driving condition
•  DSC OFF switch status
•  DSC system-related information
•  Engine displacement
•  Engine speed
•  Engine torque
•  Fuel cut request
•  Hands-free telephone system-related information
•  Ignition key status
•  Ignition off timer
•  i-stop related information
•  Manual shift control
•  Parking brake status
•  Rolling counter
•  Shift range position
•  Smart City Brake Support (SCBS)-related information
•  Steering angle (relative steering angle) signal
•  Target gear position
•  Tire size
•  TPMS OFF switch status
•  Traveled distance
•  Vehicle speed
•  Yaw rate
•  Lateral-G
•  Longitudinal-G
