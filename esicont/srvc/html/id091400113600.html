THEFT-DETERRENT SYSTEM OPERATION RECORD

id091400113600


Purpose

•  The theft-deterrent system operation history is a record of the theft-deterrent system operation.

Function

•  The theft-deterrent system operation record is stored by the BCM and displayed using the Mazda Modular Diagnostic System (M-MDS).
•  The BCM records the following when the theft-deterrent system is operated.
―  Time and date
―  Theft-deterrent system operation time
―  Location in theft-deterrent system where operation was triggered

Construction

•  Based on the stored record, the BCM displays the following operation record on the Mazda Modular Diagnostic System (M-MDS) screen.
ac5wzn00001074

Operation

•  The BCM sends an alarm sound signal to the theft-deterrent siren or theft-deterrent horn, and records the operation history simultaneously.

Fail-safe

•  Not applicable
