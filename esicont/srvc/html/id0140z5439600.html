SPEED SENSOR ASSY (TURBOCHARGER WITH VARIABLE TURBINE GEOMETRY) [SKYACTIV-D 1.5]

id0140z5439600


Purpose/Function

•  The speed sensor component detects the turbine speed in the variable geometry turbocharger as basic information for mainly boost control.
•  Detects the turbine speed in the variable geometry turbocharger and sends the turbine speed to the PCM.

Construction

•  The speed sensor component of the variable geometry turbocharger is located on the variable geometry turbocharger.
am2zzn00003724
•  The speed sensor component of the variable geometry turbocharger has adopted a MR (Magnetic Resistance) element to the detection area for detecting the turbine speed in the variable geometry turbocharger.

Operation

•  A rectangular wave pattern signal is sent to the PCM which changes according to the turbine speed in the variable geometry turbocharger.
