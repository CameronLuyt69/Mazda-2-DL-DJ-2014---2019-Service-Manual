REAR FOG LIGHT INDICATOR LIGHT

id091800013900


Purpose

•  The rear fog light indicator light notifies the driver that the rear fog light is turned on.

Functions

•  When the instrument cluster receives a rear fog light signal sent from the BCM via CAN communication, it turns the rear fog light indicator light on.

Construction

•  The rear fog light indicator light is built into the instrument cluster.
am2zzn00001953

Operation

1.  When the fog light switch is turned to the R.FOG position with the ignition switched ON (engine off or on) and headlight LO or HI signal received, the start stop unit sends (1) a rear fog light signal to the BCM via CAN communication.
2.  The BCM sends (2) the rear fog light signal to the instrument cluster.
3.  The instrument cluster turns the transistor on (3) based on the rear fog light signal.
4.  When the transistor is turned on, the rear fog light indicator light ground circuit is established and the rear fog light indicator light turns on (4).
