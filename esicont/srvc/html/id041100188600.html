REAR BRAKE (DRUM) REMOVAL/INSTALLATION

id041100188600

Warning
•  When removing/installing the brake drum component parts, the spring could fly off and cause injury. Remove/install the spring being careful not to allow the spring to fly off. Wear protective equipment such as safety glasses if necessary.
Caution
•  The parts securing the parking brake cable may be damaged if the parking brake lever is pulled while the brake drum is removed. Operate the parking brake lever only when the brake drums are installed.
Note
•  Excessive clearance between the brake drum and brake shoe could affect the correct operation of the automatic adjuster function. If the brake drum or brake shoe has been removed, verify that the clearance is within the specification and adjust it by turning the adjust screw of the adjuster using a flathead screwdriver if necessary.

1.  Remove the rear ABS wheel-speed sensor from the wheel hub component.

am2zzw00007246

2.  Remove the rear ABS wheel-speed sensor wiring harness from the bracket.

3.  Remove in the order indicated in the table.

4.  Install in the reverse order of removal.

5.  If any brake line has been disconnected anytime during the procedures, add brake fluid, bleed the brakes, and inspect for leakage after the procedure has been completed. (See BRAKE FLUID AIR BLEEDING.)

6.  Adjust the parking brake and inspect the following.

(1)  After depressing the brake pedal a few times, verify that the brakes do not drag.
(2)  Inspect the brake pedal-to-floor clearance. (See BRAKE PEDAL INSPECTION.)
(3)  Inspect the parking brake lever stroke. (See PARKING BRAKE LEVER INSPECTION.)
•  If there is any malfunction, adjust the applicable part.

Shoe Return Spring (Upper) Removal Note

1.  Support the shoe return spring with a hand as shown in the figure, to prevent it from flying off.

am2zzw00007333

2.  Move the flathead screwdriver in the direction of arrow (1).

3.  Move the shoe return spring in the direction of arrow (2) and remove it.


Shoe Return Spring (Lower), Adjuster Component, Leading Shoe, Adjuster Lever, Adjuster spring Installation Note

1.  Install the shoe return spring (lower side) to the trailing shoe.

2.  Install the adjuster component to the trailing shoe.

3.  Install the adjuster lever and adjuster spring to the leading shoe as shown in the figure. Secure the adjuster lever so that it does not fall.

am2zzw00004362

4.  Install the shoe return spring (lower side) to the leading shoe.

5.  Install the leading shoe, adjuster lever, and adjuster spring to the wheel cylinder as a single unit.

am2zzw00007334

6.  Verify that the adjuster component and adjuster lever are installed as shown in the figure.

am2zzw00004363

Note
•  The parts cannot actually be seen at the same angle as shown in the figure because they are blocked by the backing plate.

7.  Reduce the outer diameter of the brake shoe and secure the adjuster lever to prevent it from falling.

Note
•  The adjuster lever will fall unless it is pressed by the adjuster component.


Shoe Return Spring (Upper) Installation Note

1.  Support the shoe return spring with a hand as shown in the figure, to prevent it from flying off.

am2zzw00007335

2.  Move the flathead screwdriver in the direction of arrow (1).

3.  Move the shoe return spring in the direction of arrow (2) and install it.


Brake Drum Installation Note

1.  Verify that each part of the drum brake is installed correctly referring to the figure.

am2zzw00007336

2.  Turn the adjust screw on the adjuster component and adjust the brake shoe until the outer diameter (M) of the brake shoe is as specified below.

am2zzw00007337

Note
•  Adjust the brake shoe being careful of the adjuster lever.
Adjustment value
199.4—199.6 mm {7.851—7.858 in}

3.  Install the brake drum.

4.  Depress the brake pedal five times and operate the auto adjuster.

5.  Verify that there is no brake drag.

•  If there is brake drag, adjust the outer diameter of the brake shoe again.
