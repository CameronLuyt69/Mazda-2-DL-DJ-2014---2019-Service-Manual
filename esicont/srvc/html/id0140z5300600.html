ADJUSTABLE SPEED LIMITER MAIN INDICATOR LIGHT (AMBER), ADJUSTABLE SPEED LIMITER SET INDICATOR LIGHT (GREEN) [SKYACTIV-D 1.5]

id0140z5300600


Purpose, Function

•  Informs the driver of the adjustable speed limiter control status.

Construction

•  The adjustable speed limiter main indicator light (amber)/adjustable speed limiter set indicator light (green) is equipped in the instrument cluster.
•  Digital speedometer type:
am2zzn00003854
•  Analog speedometer type (Type A):
am2zzn00003718

Operation


Adjustable speed limiter main indicator light (amber) illumination condition

•  The indicator light illuminates amber when the speed limiter switch is pressed and the adjustable speed limiter is activated.


Adjustable speed limiter set indicator light (green) illumination condition

•  The indicator light illuminates green when a speed has been set.

•  The PCM sends an adjustable speed limiter main indicator light (amber) or adjustable speed limiter set indicator light (green) illumination request to the instrument cluster via CAN communication.
