AIRFLOW MODE ACTUATOR [FULL-AUTO AIR CONDITIONER]

id0740a1004900


Purpose

•  The airflow mode actuator opens/closes the airflow mode door in the A/C unit to switch the air vent.

Function


Door open/close function

•  The door open/close function opens/closes the VENT, BI-LEVEL, HEAT, DEF/HEAT or DEFROSTER positions.


Door position detection function

•  The door position detection function fluctuates the potentiometer voltage value which is linked to the airflow mode actuator motor drive.


Construction

•  A potentiometer-type airflow mode actuator has been adopted.
•  The airflow mode actuator is located on the front passenger side of the A/C unit.
•  The operation range of the airflow mode actuator is as indicated in the diagram.
