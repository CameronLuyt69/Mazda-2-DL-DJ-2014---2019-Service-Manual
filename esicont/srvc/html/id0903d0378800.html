Description
LED HEADLIGHT WARNING LIGHT ILLUMINATES CONTINUOUSLY
(See LED HEADLIGHT WARNING LIGHT ILLUMINATES CONTINUOUSLY [HEADLIGHT AUTO LEVELING SYSTEM].)
•  Inspect the LED headlight warning light with the ignition switched ON (engine off or on).
THE HEADLIGHT AUTO LEVELING SYSTEM DOES NOT OPERATE IN RESPONSE TO VEHICLE POSTURE
(See THE HEADLIGHT AUTO LEVELING SYSTEM DOES NOT OPERATE IN RESPONSE TO VEHICLE POSTURE [HEADLIGHT AUTO LEVELING SYSTEM].)
•  The headlight auto leveling system does operate in response to the number of occupants, cargo load in trunk, and the fuel level.
•  One side of the headlight leveling actuator does not operate.
