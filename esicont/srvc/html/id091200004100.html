POWER WINDOW SYSTEM INITIALIZATION PROCEDURE

id091200004100

Note
•  If the following operations have been performed, the initial setting is reset, and auto up/down operation are disabled. Therefore, performing the initial setting is necessary.
―  Negative battery cable is disconnected.
―  Power window main switch connector is disconnected.
―  Power window system power supply fuse is removed.

1.  Switch the ignition ON (engine on or off).

2.  Operate the power window main switch (RF) and fully open the front door glass (driver-side).

3.  Operate the power window main switch (RF) and hold for approx. 2 s or more with the front door glass (driver-side) fully closed.
