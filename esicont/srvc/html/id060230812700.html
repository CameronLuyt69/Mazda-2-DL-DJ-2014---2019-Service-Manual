DTC C1B00:54, C1B00:95 [EPS CONTROL MODULE]

id060230812700

DTC
C1B00:54
Steering angle sensor
C1B00:95
DETECTION CONDITION
•  Error detected in signal from the start stop unit via CAN communication
FAIL-SAFE FUNCTION
•  C1B00:54
―  Power steering malfunction indicator light Illuminates when a present malfunction is detected
―  When switch the ignition off and then switch the ignition ON (engine off or on) after detecting a malfunction, the power steering malfunction indicator light flashes if the malfunction was caused by an incorrect installation, and re-illuminates if the cause is the EPS control module internal malfunction
―  EPS motor current control enabled
•  C1B00:95
―  Power steering malfunction indicator light Illuminates when a present malfunction is detected (Does not illuminate when a past malfunction is detected)
―  EPS motor current control enabled
POSSIBLE CAUSE
•  After disconnecting from the steering gear (pinion), in such cases where the steering column is removed/installed or the intermediate shaft is disconnected, the steering shaft installation is performed with the steering shaft rotated 360-degree by mistake
•  EPS control module malfunction

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY POWER STEERING MALFUNCTION INDICATOR LIGHT ILLUMINATION CONDITION
•  Switch the ignition OFF.
•  Switch the ignition ON (engine off or on), and verify that the power steering malfunction indicator light illumination condition.
•  Does the power steering malfunction indicator light illuminate?
Yes
Go to the next step.
No
Verify that the power steering malfunction indicator light is flashing or turned off, then go to Step3.
2
VERIFY EPS CONTROL MODULE DTC
•  Using the M-MDS, clear the DTC from the EPS control module.
(See CLEARING DTC [EPS CONTROL MODULE].)
•  Using the M-MDS, perform the EPS control module DTC inspection.
(See DTC INSPECTION [EPS CONTROL MODULE].)
•  Is the same DTC present?
Yes
Replace the steering column.
(See STEERING WHEEL AND COLUMN REMOVAL/INSTALLATION.)
No
Go to Step4.
3
VERIFY DTC TROUBLESHOOTING COMPLETED
•  Using the M-MDS, clear the DTC from the EPS control module.
(See CLEARING DTC [EPS CONTROL MODULE].)
•  Start the engine and turn the steering wheel fully lock-to-lock.
•  Using the M-MDS, perform the EPS control module DTC inspection.
(See DTC INSPECTION [EPS CONTROL MODULE].)
•  Is the same DTC present?
Yes
Repeat the inspection from Step1.
If the malfunction recurs, replace the steering column, then go to the next step.
(See STEERING WHEEL AND COLUMN REMOVAL/INSTALLATION.)
No
Go to the next step.
4
VERIFY NO DTC IS PRESENT
•  Are any DTCs present?
Yes
Go to applicable DTC inspection.
(See DTC TABLE [EPS CONTROL MODULE].)
No
DTC troubleshooting completed.
