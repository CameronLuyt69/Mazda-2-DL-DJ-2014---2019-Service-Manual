GLOW PLUG CONTROL MODULE INSPECTION [SKYACTIV-D 1.5]

id0113q2705500

1.  Perform the KOEO self-test. (See KOEO/KOER SELF TEST [SKYACTIV-D 1.5].)

2.  Verify that a glow control module related DTC is detected. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

•  If DTCs are detected, repair the malfunctioning part according to the applicable DTC troubleshooting. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)
•  If a DTC is not detected, go to the next step.

3.  Inspect the following items:

•  Glow control module damage
•  Glow control module connector damage or corrosion
―  If there is any malfunction, repair or replace the malfunctioning part.
―  If there is no malfunction, replace the glow control module. (See GLOW PLUG CONTROL MODULE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
