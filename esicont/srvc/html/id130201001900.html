DTC U0001:88

CAN system communication error (HS-CAN)
DETECTION CONDITION
•  Malfunction in CAN bus communication line.
FAIL-SAFE FUNCTION
•  Switches to bypass mode which shuts the capacitor (i-ELOOP) off.
POSSIBLE CAUSE
•  CAN bus communication line malfunction
•  DC-DC converter (i-ELOOP) malfunction
SYSTEM WIRING DIAGRAM
•  Not applicable

DTC U0100:00

CAN communication: communication error to PCM
DETECTION CONDITION
•  Communication error between the DC-DC converter (i-ELOOP) and PCM continues for 5 s or more.
FAIL-SAFE FUNCTION
•  Switches to bypass mode which shuts the capacitor (i-ELOOP) off.
POSSIBLE CAUSE
•  CAN communication line malfunction between DC-DC converter (i-ELOOP) and PCM
•  PCM malfunction
•  DC-DC converter (i-ELOOP) malfunction
SYSTEM WIRING DIAGRAM
•  Not applicable

DETECTION CONDITION

FAIL-SAFE FUNCTION
•  Not applicable
POSSIBLE CAUSE

DTC U0151:00

CAN communication: communication error to SAS control module
DETECTION CONDITION
•  Communication error between the DC-DC converter (i-ELOOP) and SAS control module continues for 5 s or more.
FAIL-SAFE FUNCTION
