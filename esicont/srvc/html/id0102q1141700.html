ON-BOARD DIAGNOSTIC SYSTEM DIAGNOSTIC DATA MEMORY FUNCTION [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0102q1141700


Outline

•  Records diagnostic data related to the engine control system in the PCM.

Function

•  The diagnostic data recording/erasing conditions are determined by the number of drive cycles set for each item. (See ON-BOARD DIAGNOSTIC SYSTEM TEST MODE [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
•  Diagnostic data which can be recorded in the PCM are as follows:
―  Number of DTCs
―  DTC
―  Pending code
―  Freeze frame data
―  On-board diagnostic system diagnosis condition
•  Another method for erasing diagnostic data is by using the memory clearing function of the external tester.
