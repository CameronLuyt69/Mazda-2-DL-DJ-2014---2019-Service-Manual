ON-BOARD DIAGNOSTIC SYSTEM SIMULATION FUNCTION [TCM (CW6A-EL)]

id0502p4280700


Purpose/Function

•  The simulation function can drive output parts based on use of the M-MDS.
•  Inspection of an individual output part is facilitated by the simulation function because the output part is driven forcibly.
