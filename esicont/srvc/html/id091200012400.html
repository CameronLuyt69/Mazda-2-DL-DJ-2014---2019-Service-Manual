POWER WINDOW MOTOR

id091200012400


Purpose

•  The power window motor transmits rotation force to the power window regulator.
•  The power window motor (driver's side) outputs pulse to the power window control module to input motor operation status.

Function

The power window motor rotates clockwise/counterclockwise when it receives an open/close signal from the power window main switch or the power window subswitch.

Construction

•  The power window motor consists of the following parts:
―  Motor
―  Connector
―  Gear
•  The power window motor (driver's side) has two Hall effect switches.
―  The Hall effect switches output pulse to the power window control module.
am2zzn00002388

Operation


Open operation

•  When the power window motor receives an open signal from the power window main switch or power window subswitch, the motor rotates counterclockwise.


Close operation

•  When the power window motor receives a close signal from the power window main switch or power window subswitch, the motor rotates clockwise.


Hall effect switch operation

•  The Hall effect switch utilizes magnets set on a rotating axis to detect the motor rotation, and outputs one pulse cycle for each rotation of the motor rotation axis.
•  The high and low pulse points of Hall effect switches 1 and 2 are different during opening and closing because the phase difference shifts by approx. 90°.

Fail-safe

•  When the power window motor is operated continuously for a certain period of time, the power window motor operation is stopped temporarily to protect the power window motor inner circuit.
