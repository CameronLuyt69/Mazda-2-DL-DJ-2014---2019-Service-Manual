TRANSAXLE OVERHEATS [CW6A-EL]

id050321102600

TROUBLESHOOTING ITEM

Transaxle overheats
DESCRIPTION
•  Burnt smell emitted from the transaxle.
•  Smoke is emitted from the transaxle.
POSSIBLE CAUSE
1.  Signal malfunction
―  APP sensor malfunction
―  Brake switch malfunction
―  CKP sensor malfunction
―  ECT sensor No.1 malfunction
2.  ATF malfunction
3.  Oil cooler malfunction
4.  Control valve body malfunction

Diagnostic procedure

STEP

INSPECTION

ACTION
1
INSPECT SIGNAL PARTS FOR MALFUNCTION
•  Inspect the value at the following PCM PIDs using the M-MDS.
(See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
―  APP (APP sensor)
―  BOO (Brake switch)
―  ECT (ECT sensor No.1)
―  RPM (CKP sensor)
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
No
Go to the next step.
2
INSPECT ATF LEVEL
•  Inspect the ATF level.
(See AUTOMATIC TRANSAXLE FLUID (ATF) INSPECTION [CW6A-EL].)
•  Is there any malfunction?
Yes
Adjust the ATF level to the specification.
(See AUTOMATIC TRANSAXLE FLUID (ATF) ADJUSTMENT [CW6A-EL].)
No
Go to the next step.
3
VISUALLY INSPECT OIL COOLER
•  Visually inspect the oil cooler.
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
(See OIL COOLER REMOVAL/INSTALLATION [CW6A-EL].)
No
Go to the next step.
4
VERIFY IF MALFUNCTION CAUSE IS CONTROL VALVE BODY
•  Inspect the value at the following TCM PIDs using the M-MDS.
(See ON-BOARD DIAGNOSTIC SYSTEM PID/DATA MONITOR INSPECTION [TCM (CW6A-EL)].)
―  ECU_A
―  ECU_B
―  ECU_C
―  GEAR_SEL
―  LINEDES
―  OP_SW1
―  OP_SW2
―  OP_SW3
―  OP_SW4
―  OSS
―  SS1
―  SS2
―  SS3
―  SS4
―  SSLU
―  SSLU_PRES
―  SSP
―  SSP_PRES
―  TR
―  TSS
―  VSS
•  Is there any malfunction?
Yes
Replace the control valve body, then go to the next step.
(See CONTROL VALVE BODY REMOVAL/INSTALLATION [CW6A-EL].)
No
Symptom troubleshooting is completed.
