EVAPORATOR TEMPERATURE SENSOR INSPECTION [FULL-AUTO AIR CONDITIONER]

id0740a1801200

Note
•  Inspect the evaporator temperature sensor when it is installed to the A/C unit.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the following parts:

(1)  Glove compartment (See GLOVE COMPARTMENT REMOVAL/INSTALLATION.)
(2)  Dashboard under cover (See DASHBOARD UNDER COVER REMOVAL/INSTALLATION.)
(3)  side wall (passenger-side) (See SIDE WALL REMOVAL/INSTALLATION.)

3.  Connect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

4.  Switch the ignition ON (engine on).

5.  Set the fan speed to MAX HI.

6.  Set the temperature control to MAX COLD.

7.  Set to the RECIRCULATE mode.

8.  Turn the A/C switch off.

9.  Close all doors and windows.

10.  Wait for 5 min.

11.  Switch the ignition off.

12.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

13.  Disconnect the evaporator temperature sensor connector.

14.  Measure the temperature at the blower inlet.

15.  Measure the resistance between the evaporator temperature sensor terminals A and B.
