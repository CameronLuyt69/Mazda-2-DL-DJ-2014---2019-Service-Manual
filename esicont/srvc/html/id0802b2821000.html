DTC B0003:53 [TWO-STEP DEPLOYMENT CONTROL SYSTEM]

id0802b2821000

System malfunction location
•  Operation (deployment) inhibited
Detection condition
Warning
•  Detection conditions are for understanding the DTC outline before performing an inspection. Performing an inspection according to only the detection conditions may cause injury due to an operating error, or damage the system. When performing an inspection, always follow the inspection procedure.
•  The SAS control module configuration has not been set
•  The SAS control module configuration has been set, but air bag system is not normal
Fail-safe function
Not applicable
Possible cause
•  SAS control module configuration setting not implemented
•  Air bag system malfunction
•  SAS control module malfunction
System wiring diagram
Not applicable
