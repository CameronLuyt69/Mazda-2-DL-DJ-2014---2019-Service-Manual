POWER DOOR LOCK SYSTEM

id091400108200


Outline

•  All doors lock/unlock when locking/unlocking is performed using the driver's door lock knob or the front door key cylinder.

Function


Door lock-link switch interlock function

•  All doors lock/unlock when locking/unlocking is performed using the driver's door lock knob with all doors closed.


Door key interlock function

•  When the front door key cylinder is operated to lock/unlock, all the doors lock/unlock.


Double locking function (With double locking)

•  When the BCM receives the door lock signal two times continuously with all doors closed, it inhibits the lock/unlock operation using the door lock knob.


Collision detection unlock function (With collision detection unlock function)

•  All doors unlock if the vehicle has a collision.


Auto door lock function (With auto door lock function)

•  Doors lock/unlock according to the selector lever position (ATX), vehicle speed, or ignition switch position. The auto door lock function settings can be changed using the personalization feature. For details on the personalization setting, refer to [SECURITY AND LOCKS PERSONALIZATION]. (See SECURITY AND LOCKS PERSONALIZATION.)

Operation


Operation Conditions

•  When the door lock and link switch lock/unlock signal (operation of front door key cylinder or driver's door lock knob) is detected while all the door latch switches and liftgate latch switch off signals (all doors and liftgate closed) are detected, the power door lock system operates.


Lock operation using front door key cylinder

1.  When the key is inserted in the front door key cylinder and a lock operation is performed, the front door key cylinder switch switches to the lock side.

2.  When the BCM detects a front door key cylinder switch lock signal (1), it sends a front door key cylinder switch lock signal (2) to the electrical supply unit (ESU) via LIN communication.

3.  When the electrical supply unit (ESU) receives the front door key cylinder switch lock signal, it turns the transistor on (3) and the door lock relay on (4).

4.  When the door lock relay turns on, the front and rear door lock actuator motors perform a lock operation (5), and the front and rear doors lock.

Collision detection unlock function operation (With collision detection unlock function)

1.  If the vehicle is involved in a collision, the SAS control module sends (1) a collision detection door unlock signal to the BCM via CAN communication and it sends (2) the signal to the electrical supply unit (ESU) via hard wire.

2.  The BCM sends (3) the received collision detection door unlock signal to the electrical supply unit (ESU) via LIN communication.

3.  The electrical supply unit (ESU) unlocks all the doors after approx. 6 s it received the collision detection door unlock signal (4).

Note
•  The collision detection unlock function will operate even if only one of the signals is sent.

Auto door lock function (With auto door lock function)

Selector lever interlock door lock/unlock control (ATX)
•  The doors lock when the selector lever is shifted to a position other than the P position with all the following conditions met.
―  Theft-deterrent system in operation stop-mode, initial mode, or stand-by preparatory mode
(See THEFT-DETERRENT SYSTEM.)
―  Ignition switch ON (engine off or on) is detected
―  All door latch switch OFF (all doors closed condition) is detected
―  Liftgate latch switch OFF (liftgate closed condition) is detected (5HB)
―  Vehicle is determined to be driven.
•  The doors unlock when the selector lever is shifted to the P position with all the following conditions met.
―  Theft-deterrent system in operation stop-mode, initial mode, or stand-by preparatory mode
(See THEFT-DETERRENT SYSTEM.)
―  Ignition switch ON (engine off or on) is detected
Vehicle speed interlock door lock control
•  The doors unlock when the vehicle speed of 20 km/h {12 mph} or more is detected with all the following conditions met.
―  Theft-deterrent system in operation stop-mode, initial mode, or stand-by preparatory mode
(See THEFT-DETERRENT SYSTEM.)
―  Ignition switch ON (engine on) is detected
―  All door latch switch OFF (all doors closed condition) is detected
―  Liftgate latch switch OFF (liftgate closed condition) is detected (5HB)
IG interlock door unlock control
•  The doors unlock when the ignition is switched to ACC or OFF from ON (engine on) with all the following conditions met.
―  Theft-deterrent system in operation stop-mode, initial mode, or stand-by preparatory mode
(See THEFT-DETERRENT SYSTEM.)
―  Doors locked by selector lever interlock door lock control or vehicle interlock door lock control
