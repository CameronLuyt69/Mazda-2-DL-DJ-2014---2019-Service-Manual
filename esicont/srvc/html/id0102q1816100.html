OBD PARAMETER IDENTIFICATION (PID) ACCESS [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

•  The PID mode allows access the certain data values, analog and digital inputs and outputs, calculated values and system status information. Since the PID values for output devices are the PCM internal data values, inspect each device to identify which output devices are malfunctioning.
