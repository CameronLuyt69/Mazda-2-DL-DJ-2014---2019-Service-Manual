LIFTGATE OPENER SWITCH

id091400005900


Purpose

•  Transmits the liftgate opener switch operation of the user to the BCM.

Function

•  The liftgate switch on signal is sent to the BCM by operating the liftgate switch.

Construction

•  By locating the liftgate opener switch to the liftgate lower end, the operation for pressing the liftgate opener switch and opening the liftgate can be performed simultaneously.
•  The shape of the liftgate opener switch allows for uniform application of load using all the fingers of one hand when opening the liftgate.
am2zzn00002267

Operation

•  While the liftgate opener switch is pressed, the switch turns on (contact point: closed).
