PID/DATA Monitor Inspection (A/F Sensor)

1.  Connect the M-MDS to the DLC-2.

2.  Start the engine and warm it up completely.

3.  Access the following PIDs using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

•  Access the following PIDs using the M-MDS.
•  RPM (Engine speed)
•  O2S11 (A/F sensor output current)

4.  Drive the vehicle and decelerate the engine speed by releasing the accelerator pedal fully when the engine speed is 3,000 rpm or more.

5.  Verify that the A/F sensor output current (PID: O2S11) is 0.95 mA or more while decelerating as shown in the figure.

•  If not as verified, replace the A/F sensor. (See AIR FUEL RATIO (A/F) SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)


Resistance Inspection (A/F Sensor Heater)

Warning
•  A hot engine and exhaust system can cause severe burns. Turn off the engine and wait until they are cool before removing the exhaust system.

1.  Turn the steering wheel to full right lock.

2.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

3.  Lift up the vehicle.

4.  Remove the plate (exhaust system). (See EXHAUST SYSTEM REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

5.  Disconnect the A/F sensor connector. (See AIR FUEL RATIO (A/F) SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

6.  Measure the resistance between A/F sensor terminals C and D.
