DTC P0500:00

Vehicle speed signal circuit malfunction
DETECTION CONDITION
•  Under the following conditions, the vehicle speed signal input from DSC HU/CM is incorrect:
―  Engine is running.
―  The vehicle is driven in D position or R position.
―  Output shaft speed sensor related DTC is not recorded
―  There is correlation between output shaft speed sensor speed and turbine/input shaft speed sensor speed.
FAIL-SAFE FUNCTION
•  Inhibits learning control.
•  Inhibits i-stop control.
•  Inhibits AAS.
POSSIBLE CAUSE
•  ABS HU/CM (with ABS)/DSC HU/CM (with DSC) DTC is stored.
―  ABS wheel-speed sensor malfunction
SYSTEM WIRING DIAGRAM
Not applicable
