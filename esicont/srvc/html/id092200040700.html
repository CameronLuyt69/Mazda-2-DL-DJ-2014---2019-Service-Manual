LDWS WARNING LIGHT

id092200040700


Purpose

•  The LDWS warning light warns the driver that the vehicle may be departing from its lane or the lane departure warning system (LDWS) has a malfunction.

Function

•  The instrument cluster flashes the LDWS warning light based on the warning indication request signal sent from the forward sensing camera (FSC) via CAN communication.
•  The instrument cluster turns the LDWS warning light on based on the system malfunction indication request signal sent from the forward sensing camera (FSC) via CAN communication.
•  The flash pattern of the LDWS warning light is as shown in the figure.

Construction

•  The LDWS warning light is built into the instrument cluster.
am2zzn00002946

Operation

1.  The instrument cluster receives (1) the warning indication request signal or the system malfunction indication request signal from the forward sensing camera (FSC) via CAN communication.

2.  The instrument cluster turns the transistor on (2) intermittently for a warning indication request signal and continuously for a system malfunction indication request signal.

3.  The LDWS warning light flashes (3) when the transistor is turned on intermittently, and it turns on (3) when the transistor is turned on continuously.
