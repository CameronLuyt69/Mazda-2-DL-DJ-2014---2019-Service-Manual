CLEARING DTC [AUDIO]

id0902f6855600

Note
•  The audio system DTC can be verified using the on-board diagnostic test mode to activate the on-board diagnostic function by operating the audio unit.
•  Before clearing the memory, be sure to enter all of the DTCs displayed by the DTC inspection in the Audio Repair Order Form.
•  If an audio unit DTC is cleared, select For Audio Unit below.
•  If a Bluetooth® unit DTC is cleared, select For Bluetooth® Unit below. (With Bluetooth® unit)
•  If a CD player DTC is cleared, select For CD Player below. (With CD player)

For Audio Unit

1.  DTCs are displayed. (See DTC INSPECTION [AUDIO].)

2.  While pressing the POWER/VOLUME button, press the MENU button for 3 s or more.

am3zzw00014960

Note
•  After clearing the DTCs, "No Err" is displayed and a beep sounds.

3.  Switch the ignition off to end the on-board diagnostic test mode.


For Bluetooth® Unit

Note
•  To clear a Bluetooth® unit DTC, it is necessary for vehicles with the Bluetooth® unit and the audio unit to recognize that the Bluetooth® unit is connected.

1.  DTCs are displayed. (See DTC INSPECTION [AUDIO].)

2.  While pressing the TA button (European (L.H.D. U.K.) specs.)/AUTO-M button (Except European (L.H.D. U.K.) specs.), press the Preset button 4 for 3 s or more.

European (L.H.D. U.K.) specs.

am2zzw00010755

Except European (L.H.D. U.K.) specs.

am2zzw00010756
Note
•  After clearing, "No Err" is displayed.

3.  Switch the ignition off to end the on-board diagnostic test mode.


For CD Player

Note
•  To clear a CD player DTC, it is necessary for vehicles with the CD player and the audio unit to recognize that the CD player is connected.

1.  DTCs are displayed. (See DTC INSPECTION [AUDIO].)

2.  While pressing the TA button (European (L.H.D. U.K.) specs.)/AUTO-M button (Except European (L.H.D. U.K.) specs.), press the Preset button 6 for 3 s or more.
