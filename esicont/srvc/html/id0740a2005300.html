EVAPORATOR TEMPERATURE SENSOR [MANUAL AIR CONDITIONER]

id0740a2005300


Purpose, Function

•  The evaporator temperature sensor converts the airflow temperature passing through the detected evaporator to an electrical signal.

Construction

•  A thermistor-type evaporator temperature sensor has been adopted.
am2zzn00002162
•  A fin-thermo-type sensor has been adopted to the sensor area of the evaporator temperature sensor which inserts between the evaporator fins.
•  The evaporator temperature sensor is located on the A/C unit.

Operation

•  The thermistor changes the resistance according to the surrounding temperature.
•  The resistance decreases if the temperature increases, and increases if the temperature decreases.
