POWER WINDOW CONTROL MODULE/POWER OUTER MIRROR CONTROL MODULE

id091200014900


Purpose

•  Controls the driver's side power window system based on the power window main switch operation signal and power window motor (driver's side) pulse.
•  Controls the power outer mirror system based on the power window man switch operation signal.

Function

•  When the power window control module receives a power window main switch operation signal, it turns on/off the open/close relay.
•  The power window control module detects the power window motor operation status based on the pulse from the power window motor (driver's side).

Construction

•  The power window control module and the power outer mirror control module are built into the power window main switch.
am2zzn00002004

Operation

Power window control module
•  The power window control module detects the motor rotation speed and rotation direction based on pulse 1 and 2 from the power window motor (driver's side).
am2zzn00002005
Power outer mirror control module
•  For the power outer mirror control module operation, refer to [POWER OUTER MIRROR SYSTEM]. (See POWER OUTER MIRROR SYSTEM.)

Fail-safe

•  When power window control module detects a pulse (Hall effect switch) error, it switches the power window system to fail-safe mode to prevent incorrect operation.

Malfunction condition

Ignition is switched ON (engine off or on)

Ignition is switched off
