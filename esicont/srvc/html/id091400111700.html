REMOTE TRANSMITTER

id091400111700


Purpose

•  When the lock button/unlock button of the remote transmitter is pressed, ID data is sent to the keyless receiver.

Function

•  When the remote transmitter sends ID data, the operation indicator light is turned on.

Construction

•  The remote transmitter has a built-in operation indicator light.
•  The remote transmitter has a built-in electronic communication device (transponder) and specific electronic codes (key ID number).
•  In case the remote transmitter is inoperable due to battery depletion, the doors can be locked/unlocked using the auxiliary key.
