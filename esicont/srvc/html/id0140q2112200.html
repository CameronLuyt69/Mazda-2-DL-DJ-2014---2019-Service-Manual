IAT Sensor No.1


Resistance inspection

Note
•  Because the IAT sensor No.1 is integrated in the MAF sensor, replacing the IAT sensor No.1 includes replacement of the MAF sensor/IAT sensor No.1.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Disconnect the MAF sensor/IAT sensor No.1 connector.

3.  Measure the resistance between MAF sensor/IAT sensor No.1 terminals A and B.

IAT Sensor No.2


Resistance inspection

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the engine cover. (See ENGINE COVER REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

3.  Remove the IAT sensor No.2. (See INTAKE AIR TEMPERATURE (IAT) SENSOR NO.2 REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

4.  Place the IAT sensor No.2 in water with a thermometer, and heat the water gradually.

5.  Measure the resistance between IAT sensor No.2 terminals A and B.

•  If not as specified, replace the IAT sensor No.2. (See INTAKE AIR TEMPERATURE (IAT) SENSOR NO.2 REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
