Inspection

1.  Connect the M-MDS to the DLC-2.

2.  After vehicle identification, select the following from the M-MDS initialization screen.

1.  "Data logger"
2.  "Module"
3.  "IC"

3.  Using the simulation function LCD_SEG, verify that the display screen and open/close angle for the combiner change by pressing the tripmeter switch.

•  If the display screen and open/close angle for the active driving display cannot be changed, refer to the symptom troubleshooting. (See SYMPTOM TROUBLESHOOTING [INSTRUMENT CLUSTER].)

Combiner Angle Initialization Setting

Note
•  If foreign matter is caught in the mechanism while the combiner is opening/closing, the combiner angle could deviate. If the angle has deviated, perform the combiner angle initialization setting to return the combiner angle to the set position.

1.  Verify that there is no foreign matter around the open/close area of the combiner. Remove all foreign matter along the track in which the combiner closes.

2.  Switch the ignition off.

3.  Disconnect the negative battery cable or remove the ROOM 25 A fuse. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

4.  Connect the negative battery cable or install the ROOM 25 A fuse. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

Note
•  When the negative battery cable is connected or the ROOM 25A fuse is installed, the combiner fully opens after opening approx. 10 degrees, and then it performs angle initialization.

5.  Switch the ignition ON (engine off or on).

6.  Verify that the combiner opens to the set position.

Note
•  If the angle deviation is not corrected, repeat the procedure from Step 1.
