DSC OFF SWITCH INSPECTION

id041500802000

Note
•  The DSC OFF switch is integrated with the cluster switch.
•  If the DSC OFF switch is replaced, replace the cluster switch. (See CLUSTER SWITCH REMOVAL/INSTALLATION.)

Resistance Inspection

1.  Remove the cluster switch. (See CLUSTER SWITCH REMOVAL/INSTALLATION.)

2.  Measure the resistance between cluster switches B and C under the following conditions:

Resistance with DSC OFF switch pressed and held (standard)
•  0 ohms
Resistance with any switches not pressed (standard)
•  1,139.99—1,163.01 ohms
am2zzw00011239
•  If not within the specification, replace the cluster switch. (See CLUSTER SWITCH REMOVAL/INSTALLATION.)


LED Illumination Inspection

1.  Remove the cluster switch. (See CLUSTER SWITCH REMOVAL/INSTALLATION.)

2.  Apply battery positive voltage to cluster switch terminal J, and connect terminal I to ground.

aatjjw00009828

3.  Verify that the LED illuminates.

•  If there is any malfunction, replace the cluster switch.
