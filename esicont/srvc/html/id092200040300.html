BLIND SPOT MONITORING (BSM) SWITCH

id092200040300


Purpose

•  The driver can optionally choose to switch the blind spot monitoring (BSM) system to operational or non-operational.

Function

•  The switch operation signal is sent to the instrument cluster.

Construction

•  The blind spot monitoring (BSM) switch is built into the cluster switch.
•  The resistance is built into each switch.
am2zzn00002382

Operation

1.  When the blind spot monitoring (BSM) switch is operated, a cluster switch operation signal is sent (1) to the instrument cluster.
2.  The instrument cluster sends (2) the blind spot monitoring (BSM) switch operation signal to the blind spot monitoring (BSM) control module (LH) based on the switch operation signal (detected voltage).
3.  When the blind spot monitoring (BSM) control module (LH) receives the blind spot monitoring (BSM) switch operation signal from the instrument cluster, it switches the blind spot monitoring (BSM) system to operate/not operate (3).
