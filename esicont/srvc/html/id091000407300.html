Gap Adjustment

1.  Verify that the gap between the bonnet and the front bumper is within the specification.

am2zzw00008777

Standard clearance
a: 1.7—5.3 mm {0.07—0.20 in}
•  If the measured value exceeds the standard clearance, adjust the bonnet using the following procedure.
1.  Loosen the bonnet hinge installation bolts and adjust the bonnet position. (See BONNET REMOVAL/INSTALLATION.)
2.  Tighten the bonnet hinge installation bolts. (See BONNET REMOVAL/INSTALLATION.)
3.  Verify that the gap between the bonnet and the front bumper is within the specification.

2.  Verify that the gap between the bonnet and the front fender panel is within the specification.

am2zzw00008778

Standard clearance
b: 2.5—4.5 mm {0.10—0.17 in}
•  If the measured value exceeds the standard clearance, adjust the bonnet using the following procedure:
1.  Loosen the bonnet hinge installation bolts and adjust the bonnet position. (See BONNET REMOVAL/INSTALLATION.)
2.  Tighten the bonnet hinge installation bolts. (See BONNET REMOVAL/INSTALLATION.)
3.  Verify that the bonnet opens/closes smoothly.
•  If the bonnet does not open/close smoothly, adjust the bonnet latch position. (See BONNET LATCH REMOVAL/INSTALLATION.)
4.  Verify that the gap between the bonnet and the front fender panel is within the specification.


Height Difference Adjustment

1.  Verify that the height difference between the bonnet and the front bumper is within the specification.

am2zzw00008779

Standard clearance
a: –2.0—2.0 mm {–0.078—0.078 in}
•  If the measured value exceeds the standard clearance, adjust the bonnet using the following procedure:
1.  Loosen the bonnet latch installation bolts, and reposition the bonnet latch. (See BONNET LATCH REMOVAL/INSTALLATION.)
2.  Tighten the bonnet latch installation bolts. (See BONNET LATCH REMOVAL/INSTALLATION.)
3.  Turn the stopper rubber to adjust the height of the bonnet.
