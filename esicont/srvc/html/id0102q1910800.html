DTC U0073:00

CAN system communication error (HS CAN)
DETECTION CONDITION
•  Malfunction in CAN bus communication line.
Diagnostic support note
•  This is a continuous monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA is not available.
•  Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
Not applicable
POSSIBLE CAUSE
•  CAN bus communication line malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable

DTC U0101:00

CAN communication: communication error to TCM
DETECTION CONDITION
•  Communication error between the PCM and TCM continues for 5 s or more.
Diagnostic support note
•  This is a continuous monitor (other).
•  The check engine light illuminates if the PCM detects the above malfunction condition during the first drive cycle.
•  FREEZE FRAME DATA/Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
•  Controls the turbine rotation signal at 0.
•  Inhibits the AT torque reduction request.
•  Inhibits the i-stop control and flashes the i-stop warning light (amber) (engine stalls while engine is stopped by i-stop control). (With i-stop)
POSSIBLE CAUSE
Note
•  During malfunction diagnosis, first verify the malfunction detection of DTC U0074:00 or U0115:00 for the TCM.
•  CAN communication line malfunction between PCM and TCM
•  TCM malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable

DTC U0121:00

CAN communication: communication error to ABS HU/CM or DSC HU/CM
DETECTION CONDITION
•  Communication error between the PCM and DSC HU/CM continues for 5 s or more. (with DSC)
•  Communication error between the PCM and ABS HU/CM continues for 5 s or more. (without DSC)
Diagnostic support note
•  This is a continuous monitor (other).
•  The check engine light illuminates if the PCM detects the above malfunction condition during the first drive cycle.
•  FREEZE FRAME DATA/Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
•  Inhibits the DSC control. (with DSC)
•  Inhibits the ABS control. (without DSC)
•  Inhibits the i-stop control and flashes the i-stop warning light (amber) (engine stalls while engine is stopped by i-stop control). (With i-stop)
POSSIBLE CAUSE
Vehicles with DSC
•  CAN communication line malfunction between PCM and DSC HU/CM
•  DSC HU/CM malfunction
•  PCM malfunction
Vehicles without DSC
•  CAN communication line malfunction between PCM and ABS HU/CM
•  ABS HU/CM malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable
