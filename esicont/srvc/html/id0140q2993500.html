TURBOCHARGER INITIALIZATION [SKYACTIV-D 1.5]

id0140q2993500

1.  Connect the M-MDS to the DLC-2.

2.  After the vehicle is identified, select the following item from the initial screen of the M-MDS.

(1)  Select the “Powertrain”.

3.  Then, select the items from the screen menu in the following order.

(1)  Select the “Initialization”.
(2)  Select the “Turbo charger”.

4.  Perform the procedure according to the directions on the screen.
