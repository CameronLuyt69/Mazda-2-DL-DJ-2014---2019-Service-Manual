DTC
C1031:41
Tire Pressure Monitoring System (TPMS)
DETECTION CONDITION
•  When the DSC HU/CM detects malfunction in the memory for storing a calculated tire pressure value
FAIL-SAFE FUNCTION
Refer to DTC TABLE. (See DTC TABLE [DSC HU/CM].)
POSSIBLE CAUSE
•  DSC HU/CM internal error
•  DSC HU/CM malfunction
SYSTEM WIRING DIAGRAM
—


Diagnostic Procedure

Step

Inspection

Action
1
INITIALIZE A TPMS MEMORY
•  Switch the ignition OFF.
•  Connect the M-MDS to DLC-2.
•  After the vehicle is identified, select the following items from the initial screen of the M-MDS.
1.  Select “Chassis”.
2.  Select “ABS/DSC”.
3.  Select “TPMS Reset”.
•  Using the M-MDS, perform the procedure according to the directions on the screen.
•  Is the initialization normally completed?
Yes
Go to the next step.
No
Repeat the inspection from Step1
If the malfunction recurs, replace the DSC HU/CM, then go to the next step.
(See DSC HU/CM REMOVAL/INSTALLATION [L.H.D.].)
(See DSC HU/CM REMOVAL/INSTALLATION [R.H.D.].)
2
VERIFY DTC TROUBLESHOOTING COMPLETED
•  Using the M-MDS, clear the DTC from the DSC HU/CM.
(See CLEARING DTC [DSC HU/CM].)
•  Using the M-MDS, perform the DSC HU/CM DTC inspection.
(See DTC INSPECTION [DSC HU/CM].)
•  Is the same DTC present?
Yes
Repeat the inspection from Step1
If the malfunction recurs, replace the DSC HU/CM, then go to the next step.
(See DSC HU/CM REMOVAL/INSTALLATION [L.H.D.].)
(See DSC HU/CM REMOVAL/INSTALLATION [R.H.D.].)
No
Go to the next step.
3
VERIFY NO DTC IS PRESENT
•  Are any DTCs present?
Yes
Go to applicable DTC inspection.
(See DTC TABLE [DSC HU/CM].)
No
DTC troubleshooting completed.
