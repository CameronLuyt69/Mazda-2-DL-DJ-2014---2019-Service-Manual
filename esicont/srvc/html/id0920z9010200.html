Purpose

•  The audio unit controls the entertainment system-related parts.

Function


Display function

•  Displays audio information such as radio and CD related information in the audio unit display.


Memory function

•  The audio unit stores the following information.
―  DTC
―  Radio frequencies stored in preset
―  Sound quality settings
•  AF (Setting Alternative Frequency (AF))
•  REG (Setting Regional Programme (REG))
•  ALC (auto volume adjustment)
•  BASS (low range adjustment)
•  TREB (high range adjustment)
•  FADE (front/back volume adjustment)
•  BAL (left/right volume adjustment
•  BEEP (operation sound setting)
•  BT SETUP
―  Clock setting
•  12Hr/24Hr (time display setting)
―  Volume setting
Note
•  The sound quality, clock, and volume settings stored in the audio unit are erased if the battery cables are disconnected.


ALC (auto level control) function

•  Compensates for the passengers' sense of a lack of audio volume which occurs as a result of external noise while driving.


Sound quality/time adjustment function

•  The sound quality of the audio unit and the time displayed on the audio unit display can be adjusted by rotating the POWER/VOLUME button after selecting the MENU button of the audio unit.

TA (traffic announcement) function

•  When traffic information is received while listening in the following modes, the audio switches automatically to the traffic information.
―  FM radio
―  CD
―  AUX
―  USB (iPod)
―  Bluetooth® audio
•  When the traffic information has finished, the audio unit returns to the mode that was being listened to before the traffic information broadcast.
•  If the TA function is set to ON, "TA" is displayed in the audio unit display regardless of traffic information reception.
Note
•  If traffic information is received while the TA function is set to OFF, "TA" is displayed in the audio unit display. If the TA button on the audio panel is selected during "TA" display, announcement of traffic information starts.
•  If the following operations are performed during a traffic information announcement, the traffic information announcement is cancelled.
―  Turn the audio unit power off
―  Switch to AM radio by operating FM/AM/CLOCK button
―  Turn TA function off by operating TA button


On-board diagnostic function

•  The audio unit has an on-board diagnostic function to facilitate system diagnosis. DTCs are stored in the event of a malfunction occurring. For details, refer to the DIAGNOSTIC SYSTEM. (See ON-BOARD DIAGNOSTIC [ENTERTAINMENT SYSTEM (WITHOUT CENTER DISPLAY)].)


Diagnostic assist function

•  A diagnostic assist function is equipped which can verify the following. For details, refer to the DIAGNOSTIC SYSTEM. (See ON-BOARD DIAGNOSTIC [ENTERTAINMENT SYSTEM (WITHOUT CENTER DISPLAY)].)
―  Connection status of related parts
―  Operation status of related parts
―  Related part specifications

Operation


ALC (auto level control) operation

•  The audio unit automatically changes the volume and audio quality based on the vehicle speed signal received from the instrument cluster.
am2zzn00003503
•  The ALC function is divided into 7 levels. When the level is in the high range, the volume correction range and correction amount are large. The maximum correction amount is 14dB. The ALC function can be stopped by selecting ALC OFF.
am2zzn00003504
