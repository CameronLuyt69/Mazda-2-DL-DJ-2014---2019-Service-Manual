INSTRUMENTATION/DRIVER INFO. PERSONALIZATION

id092200018400

Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the Mazda modular diagnostic system (M-MDS). Do not select [Not equipped] in the setting displayed on the Mazda modular diagnostic system (M-MDS).
Note
•  Settings of some personalization features displayed on the Mazda Modular Diagnostic System (M-MDS) cannot be changed depending on the vehicle specification.
•  A personalization feature has been adopted which enables the instrument cluster settings to be changed.
•  The setting for each function can be switched using the Mazda Modular Diagnostic System (M-MDS) or the center display (with center display). Refer to the [INSTRUMENT CLUSTER PERSONALIZATION FEATURES SETTING PROCEDURE] in the workshop manual for the detailed setting procedure.
