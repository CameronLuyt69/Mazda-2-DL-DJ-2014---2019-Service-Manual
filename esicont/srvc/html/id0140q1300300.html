ADJUSTABLE SPEED LIMITER WARNING ALARM [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1300300


Purpose

•  Functions to warn the driver if the vehicle speed exceeds the maximum vehicle speed limit by 3 km {2 mph} or more even if the adjustable speed limiter control condition is under limiter operation.

Function

•  The adjustable speed limiter warning alarm sound pattern is as shown in the figure.
am2zzn00003436

Construction

•  The adjustable speed limiter warning alarm sounds using the buzzer built into the instrument cluster.

Operation

1.  The instrument cluster receives (1) the adjustable speed limiter warning alarm request signal from the PCM.

2.  The instrument cluster microcomputer turns the transistor on (2) based on the adjustable speed limiter warning alarm request signal.

3.  When the transistor turns on, a ground circuit with the alarm is established and the alarm sounds (3).
