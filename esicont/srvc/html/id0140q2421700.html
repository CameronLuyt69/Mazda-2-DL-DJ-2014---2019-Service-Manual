FUEL INJECTOR INJECTION AMOUNT CORRECTION [SKYACTIV-D 1.5]

Note
•  The fuel injection amount learning can be performed when all the following conditions are met. The implementation conditions for the fuel injection amount learning can be met by warming up the engine completely.
Implementation conditions for fuel injector injection amount correction
―  ECT: 70—95 °C {158—203 °F}
―  IAT: 0—65 °C {32—149 °F}
―  Fuel temperature: 20—80 °C {68—176 °F}
•  If fuel injector injection amount correction is not completed, the check engine light and glow indicator light and master warning light illuminates.
In addition, the PCM stores DTCs P1200:00 and P167B:00. (cleared by completing fuel injector injection amount correction)
•  If only P167B:00 is stored, the glow indicator light flashes.
•  If fuel injector injection amount correction is not completed, the check engine light and glow indicator light and master warning light illuminates. In addition, the PCM stores DTCs P1200:00 and P167B:00. (cleared by completing fuel injector injection amount correction)
•  If only DTC P167B:00 is stored, the glow indicator light flashes.
•  The engine will race a few times right after the fuel injection amount learning is started.The engine will race a few times right after the fuel injection amount learning is started.
•  If the fuel injection amount learning fails, switch the ignition off, wait for 15 s or more, then perform the procedure again.

1.  Maintain the engine speed at 2,500—3,000 rpm and warm up the engine completely.

2.  Verify the charging system warning light turns off.

3.  Meet the following conditions:

•  OFF switch of climate control unit: OFF (Push)
•  All electrical load: OFF
•  Accelerator pedal: Released (foot removed from accelerator pedal)
•  Selector lever: P or N position (ATX)
•  Shift lever: Neutral position (MTX)
•  Clutch pedal: Released (foot removed from clutch pedal) (MTX)
•  DTC except P1200:00, P167B:00 not detected


Using the M-MDS

1.  Connect the M-MDS to the DLC-2.

2.  After the vehicle is identified, select the following item from the initial screen of the M-MDS.

(1)  Select the “Powertrain”.

3.  Then, select the items from the screen menu in the following order.

(1)  Select the “Engine Checks”.
(2)  Select the “Learning”.
(3)  Select the “Injector Amount Correction”.

4.  Perform the procedure according to the directions on the screen.


Without Using the M-MDS

Note
•  DTC P1905:00 may be detected by grounding the test terminal to the body. In this case, DTC P1905:00 is automatically erased by disconnecting the test terminal ground.

1.  Start the engine.

2.  Wait until idle speed is stabilized. (approx. 10 s)

3.  Short the connection between body ground and test terminal five times within 5 s using a jumper wire.

Note
•  If the fuel injector injection amount correction is initiated, the glow indicator light illuminates.

4.  Verify that the glow indicator light illuminates.

―  If the glow indicator light does not illuminate, perform the following procedure:
1.  Switch the ignition off.
2.  Perform the procedure again from Step 1 (meeting fuel injection amount activation conditions).
Note
•  If the fuel injector injection amount correction is completed correctly, the glow indicator light flashes five times.

5.  Verify that the glow indicator light flashes 5 times approx. 3 min after it was turned on, then it turns off.

―  If the glow indicator light does not turn off, perform the following procedure:
1.  Switch the ignition off and wait for 15s or more.
2.  Perform the procedure again from Step 1 (meeting fuel injection amount activation conditions).

6.  Detach the jumper wire from the test terminal.

7.  Switch the ignition off.
