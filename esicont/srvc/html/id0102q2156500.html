DTC P0313:00

Misfire detected with low fuel
DETECTION CONDITION
•  “Injection amount cumulative value after lowering point E”, which is calculated by the PCM, exceeds the threshold value (larger than DTC P115A:00).
Diagnostic support note
•  This is an intermittent monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA/Snapshot data is not available.
•  DTC is not stored in the PCM memory.
FAIL-SAFE FUNCTION
•  PCM restricts engine torque.
•  Inhibits the auto DPF regeneration control.
•  Inhibits the compulsory DPF regeneration control.
•  Inhibits engine-stop by operating the i-stop function.
POSSIBLE CAUSE
•  Fuel runout
•  Fuel gauge (integrated in instrument cluster) malfunction
•  Fuel gauge sender unit malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable
