CLIMATE CONTROL UNIT [MANUAL AIR CONDITIONER]

id0740a2005100


Purpose

•  The climate control unit controls the air conditioner in conjunction with the A/C operations performed by the occupants.

Function

•  The climate control unit outputs an operation signal for each switch or dial. (See MANUAL AIR CONDITIONER SYSTEM [MANUAL AIR CONDITIONER].)

Dial set position detection function

•  The climate control unit detects the set position of each operation dial and outputs the following signals to the instrument cluster.
•  The instrument cluster determines each control based on each dial set position signal from the climate control unit.

Construction

•  The climate control unit has adopted a wire type to the following controls.
―  Air mix door (temperature setting dial)
―  Air intake door (RECIRCULATE/FRESH lever (RECIRCULATE/FRESH lever type))
―  Airflow mode door (MODE dial)
•  The climate control unit consists of a control panel and a control unit.
•  The MS-CAN terminal resistance is integrated into the climate control unit.
Note
•  The terminal resistance integrated into the climate control unit is used by the MS-CAN transmission, but CAN transmission is not used in the manual air conditioner system.
•  The switches and dials shown in the figure are positioned on the control panel.

Temperature setting dial set position detection function (Without heater system)
•  For the temperature setting dial set position detection function, the potentiometer integrated with the climate control unit is linked to the temperature setting dial operation.
•  When the temperature setting dial set position is MAX COLD, the potentiometer voltage increases. When the position is MIN COLD, the voltage decreases.
