KEY WARNING LIGHT (RED)/KEY INDICATOR LIGHT (GREEN)

id091400603400


Purpose


KEY warning light (red)

•  The KEY warning light (red) notifies the driver that the engine cannot be started, the remote transmitter is outside of the vehicle, or that there is a malfunction in the system.


KEY indicator light (green)

•  The KEY indicator light (green) notifies the driver that the engine starting conditions have been met or that the remote transmitter battery voltage is depleted.


Function


KEY warning light (red)

•  When a malfunction is detected in the keyless entry system or advanced keyless entry system, the KEY warning light (red) turns on. (See ON-BOARD DIAGNOSIS SYSTEM [ADVANCED KEYLESS ENTRY SYSTEM].) (See ON-BOARD DIAGNOSIS SYSTEM [START STOP UNIT].)
―  For vehicles with the center display, a warning message in the center display is displayed when the KEY warning light (red) is turned on. For the message content and verification method, refer to the CENTER DISPLAY. (See CENTER DISPLAY [WITH CENTER DISPLAY].)
•  The KEY warning light (red) flashes if the engine cannot be started and when the ignition is switched to ACC or ON (engine off or on) and the transmitter is taken outside of the vehicle. (See KEYLESS ENTRY SYSTEM.) (See ADVANCED KEYLESS ENTRY SYSTEM.) (See PUSH BUTTON START SYSTEM [KEYLESS ENTRY SYSTEM].) (See PUSH BUTTON START SYSTEM [ADVANCED KEYLESS ENTRY SYSTEM].)


KEY indicator light (green)

•  When the engine-starting conditions have been met, the KEY indicator light (green) turns on. (See PUSH BUTTON START SYSTEM [KEYLESS ENTRY SYSTEM].) (See PUSH BUTTON START SYSTEM [ADVANCED KEYLESS ENTRY SYSTEM].)
•  If the remote transmitter battery voltage is depleted, the KEY indicator light (green) flashes. (See KEYLESS ENTRY SYSTEM.) (See ADVANCED KEYLESS ENTRY SYSTEM.)
―  For vehicles with the center display, a warning message in the center display is displayed when the KEY indicator light (green) flashes. For the message content and verification method, refer to the CENTER DISPLAY. (See CENTER DISPLAY [WITH CENTER DISPLAY].)


Construction

•  The KEY warning light (red)/KEY indicator light (green) are built into the instrument cluster.

Operation


KEY warning light (red)

1.  The instrument cluster receives (1) the system condition display request signal or warning indication request signal from the start stop unit via CAN communication.

2.  The instrument cluster turns the transistor on (2) intermittently for a system condition display request signal and continuously for a warning indication request signal.

3.  When the transistor is turned on intermittently, the KEY warning light (red) flashes (3), and when it is turned on continuously, the KEY warning light (red) turns on (3).

am2zzn00001852


KEY indicator light (green)

1.  The instrument cluster receives (1) the system condition display request signal or battery voltage low indication request signal from the start stop unit via CAN communication.

2.  The instrument cluster turns the transistor on (2) intermittently for a battery voltage low indication request signal and continuously for a system conditions indication request signal.

3.  When the transistor is turned on intermittently, the KEY indicator light (green) flashes (3), and when it is turned on continuously, the KEY indicator light (green) turns on (3).
