PID/DATA Monitor Inspection

Note
•  Because the intake shutter valve position sensor is integrated in the intake shutter valve, replacing the intake shutter valve position sensor includes replacement of the intake shutter valve.

1.  Connect the M-MDS to the DLC-2.

2.  Switch the ignition ON (engine off).

3.  Access the PID/DATA monitor item ISV_ACT and ISV_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

4.  Verify that the ISV_ACT monitor value conforms to the ISV_DSD monitor value.

•  If not as verified, replace the intake shutter valve. (See INTAKE SHUTTER VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
