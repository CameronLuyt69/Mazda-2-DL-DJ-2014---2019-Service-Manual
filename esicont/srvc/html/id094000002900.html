Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the M-MDS. Do not select [Not equipped] in the setting displayed on the M-MDS.
Note
•  Settings of some personalization features displayed on the M-MDS cannot be switched depending on the vehicle specification.

Auto light system (Using center display)

•  (See CENTER DISPLAY PERSONALIZATION FEATURES SETTING PROCEDURE.)

Note
•  When the system is set to [Extra High] or [High], each light turns on when the ambient light is brighter than when the system is set to [Standard] because the illumination level required to turn on the headlights LO, TNS and panel light increases. When the system is set to "Extra Low" or "Low", because the illumination level required to turn on the headlights LO, TNS and panel light decreases, each light turns on when the ambient light is darker than when the system is set to "Standard".
•  The personalization feature may not be set correctly if [Jpan Only] such as [Extra High (Jpan Only)] is selected. Do not select [Jpan Only].
