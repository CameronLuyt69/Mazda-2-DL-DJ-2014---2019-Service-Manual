INSTRUMENT CLUSTER PERSONALIZATION FEATURES SETTING PROCEDURE

id092200033600

Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the M-MDS. Do not select [Not equipped] in the setting displayed on the M-MDS.
Note
•  Settings of some personalization features displayed on the M-MDS cannot be switched depending on the vehicle specification.

Turn And Hazard Indicator Alarm


Using M-MDS

1.  Connect the M-MDS to the DLC-2.

2.  After vehicle identification, select the following from the M-MDS initialization screen.

(1)  “Module programming”
(2)  “Programmable Parameters”

3.  Select menu in the “IC”.

4.  Select an item name, and than select option.

Mazda Modular Diagnostic System (M-MDS) display
