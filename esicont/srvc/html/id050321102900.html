STARTER DOES NOT WORK [CW6A-EL]

id050321102900

TROUBLESHOOTING ITEM

Starter does not work
DESCRIPTION
•  Starter does not work even when in P or N position.
POSSIBLE CAUSE
1.  Wiring harness between TCM terminal J and PCM terminal 2BD malfunction
2.  Wiring harness between TCM terminal J and start stop unit terminal 1F malfunction
3.  Wiring harness between start stop unit terminal 2H and LF control unit terminal G malfunction (With advanced keyless entry system)
4.  Immobilizer system operating or system malfunction
5.  Engine control system malfunction

Diagnostic procedure

STEP

INSPECTION

ACTION
1
INSPECT WIRING HARNESS BETWEEN TCM AND PCM
•  Switch the ignition off.
•  Disconnect the PCM connector and TCM connector.
•  Visually inspect for pin deformity, open circuit, or wiring harness non-insulation between TCM terminal J and PCM terminal 2BD.
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
No
Go to the next step.
2
INSPECT WIRING HARNESS BETWEEN TCM AND START STOP UNIT
•  Disconnect the start stop unit connector.
•  Visually inspect for pin deformity, open circuit, or wiring harness non-insulation between TCM terminal J and start stop unit terminal 1F.
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
No
Without advanced keyless entry system:
•  Go to step 4.
With advanced keyless entry system:
•  Go to the next step.
3
INSPECT WIRING HARNESS BETWEEN TCM AND LF CONTROL UNIT
•  Disconnect the LF control unit connector.
•  Visually inspect for pin deformity, open circuit, or wiring harness non-insulation between start stop unit terminal 2H and LF control unit terminal G.
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
No
Go to the next step.
4
INSPECT IMMOBILIZER SYSTEM AND ENGINE CONTROL SYSTEM FOR MALFUNCTION
•  Perform the symptom troubleshooting “NO.3 WILL NOT CRANK”.
(See NO.3 WILL NOT CRANK [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
•  Is there any malfunction?
Yes
Repair or replace any malfunctioning parts according to the inspection result.
No
Symptom troubleshooting is completed.
