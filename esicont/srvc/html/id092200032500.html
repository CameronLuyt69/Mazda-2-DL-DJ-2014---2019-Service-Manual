SPEEDOMETER

id092200032500


Purpose

•  The speedometer notifies the driver of the speed at which the vehicle is traveling.

Function

•  The instrument cluster displays the current vehicle speed based on the vehicle speed signal from the PCM.

Construction

Digital speedometer type
•  A digital display speedometer has been adopted.
•  The current vehicle speed is displayed in the speedometer display and the active driving display.
am2zzn00002924
Analog speedometer type
•  An analog needle display speedometer with a stepping motor mechanism has been adopted.
am2zzn00002925

Operation

1.  When the ignition is switched ON (engine on), the instrument cluster receives (1) a vehicle speed signal from the PCM via the CAN communication.

2.  The instrument cluster displays (2) the current vehicle speed based on the vehicle speed signal.

Fail-safe
