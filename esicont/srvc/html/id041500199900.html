SMART CITY BRAKE SUPPORT (SCBS) PERSONALIZATION

id041500199900

•  For vehicle equipped with instrument cluster type A and type B, a personalization function has been adopted with which setting for the Smart City Brake Support (SCBS) can be changed by operation of the steering switch.
•  For vehicle equipped with instrument cluster type C, a personalization function has been adopted with which setting for the Smart City Brake Support (SCBS) can be changed by operation of the Smart City Brake Support OFF switch.
