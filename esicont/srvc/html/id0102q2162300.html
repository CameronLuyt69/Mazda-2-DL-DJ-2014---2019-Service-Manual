INAPPROPRIATE OPERATION AND CONTROL RECORD [SKYACTIV-D 1.5]

id0102q2162300


Purpose

•  For the purpose of protecting passengers and the vehicle, the PCM performs protection control according to the vehicle driving conditions/environment surrounding the vehicle.
The inappropriate operation and control record of the protection control executed by the PCM can be displayed using the Mazda Modular Diagnostic System (M-MDS) and it can be used during malfunction diagnosis.

Function/display

•  The PCM records the following information as an inappropriate operation and control record.
―  Inappropriate operation and control code
―  Inappropriate operation and control type
―  Odometer value
•  The Mazda Modular Diagnostic System (M-MDS) reads out the inappropriate operation and control record and indicates it as shown in the figure below.
