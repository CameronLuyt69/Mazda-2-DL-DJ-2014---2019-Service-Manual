KEYLESS WARNING ALARM

id091400006100


Purpose

•  The keyless warning alarm notifies the driver that the presence of the remote transmitter cannot be verified or the steering lock cannot be released.

Function

•  When the instrument cluster receives the keyless warning alarm request signal sent from the start stop unit via CAN communication, the keyless warning alarm sounds.
•  When any of the following conditions is met, the start stop unit sends a keyless warning alarm request signal to the instrument cluster via CAN communication.
―  Driver's door latch switch on signal (door open) is received with ignition switched to ACC (pattern A)
―  Remote transmitter cannot be detected inside vehicle when off signals for all door latch switches (doors closed) are received with ignition not switched OFF (pattern B)
―  Steering lock cannot be released (pattern C)
•  The keyless warning alarm sounds in the pattern shown in the figure.

Construction

•  The keyless warning alarm sounds using the buzzer built into the instrument cluster.

Operation

1.  The start stop unit sends (1) a keyless warning alarm request signal to the instrument cluster.

2.  The instrument cluster microcomputer turns the transistor on (2) based on the keyless warning alarm request signal.

3.  When the transistor turns on, a ground circuit with the alarm is established and the alarm sounds (3).
