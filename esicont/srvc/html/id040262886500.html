SIMULATION INSPECTION [DSC HU/CM]

id040262886500

1.  Connect the M-MDS to the DLC-2.

2.  After the vehicle is identified, select the following items from the initialization screen of the M-MDS.

(1)  Select “DataLogger”.
(2)  Select “Modules”.
(3)  Select “ABS”.

3.  Select the applicable simulation item from the PID table.

4.  Perform the simulation function, inspect the operations for each parts.

•  If the operation of output parts cannot be verified after the simulation inspection is performed, this could indicate the possibility of an open or short circuit, sticking, or operation malfunction in the output parts.
