Note
•  Because the IAT sensor No.1 is integrated in the MAF sensor, replacing the IAT sensor No.1 includes replacement of the MAF sensor/IAT sensor No.1.
•  If the MAF sensor/IAT sensor No.1 is replaced, perform the Operation After Replacing MAF Sensor/IAT Sensor No.1 procedure. (See Operation After Replacing MAF Sensor/IAT Sensor No.1.)

MAF Sensor/IAT Sensor No.1 Removal/Installation

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Disconnect the MAF sensor/IAT sensor No.1 connector.

am2zzw00011444

3.  Remove the screws.

4.  Remove the MAF sensor/IAT sensor No.1.

5.  Install in the reverse order of removal.

6.  Perform the Operation After Replacing MAF Sensor/IAT Sensor No.1. (See Operation After Replacing MAF Sensor/IAT Sensor No.1.)
