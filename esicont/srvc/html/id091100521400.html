LIFTGATE ADJUSTMENT

id091100521400

1.  Measure the gap and height difference between the liftgate and the roof panel.

am2zzw00008920

Standard clearance
a: 5.0—7.0 mm {0.20—0.27 in}
b: –2.0—0.0 mm {–0.078—0.000 in}
•  If the measured value exceeds the standard clearance, adjust the liftgate using the following procedure:
1.  Loosen the liftgate hinge installation bolts and reposition the liftgate. (See LIFTGATE REMOVAL/INSTALLATION.)
2.  Tighten the liftgate hinge installation bolts. (See LIFTGATE REMOVAL/INSTALLATION.)
3.  Verify that the gap and height difference between the liftgate and the roof panel is within the specification.

2.  Measure the gap and height difference between the liftgate and the rear fender panel.

am2zzw00008921

Standard clearance
c: 3.0—5.4 mm {0.12—0.21 in}
d: –1.7—0.7 mm {–0.06—0.02 in}
•  If the measured value exceeds the standard clearance, adjust the liftgate using the following procedure:
1.  Loosen the liftgate hinge installation bolts and reposition the liftgate. (See LIFTGATE REMOVAL/INSTALLATION.)
2.  Tighten the liftgate hinge installation bolts. (See LIFTGATE REMOVAL/INSTALLATION.)
3.  Verify that the gap and height difference between the the liftgate and the rear fender panel is within the specification.
4.  Verify that the liftgate opens/closes smoothly.
•  If the liftgate does not open/close smoothly, adjust the liftgate lock striker position. (See LIFTGATE LOCK STRIKER REMOVAL/INSTALLATION.)

3.  Measure the gap between the liftgate and the rear bumper.

Standard clearance
e: 4.0—8.0 mm {0.16—0.31 in}
•  If the measured value exceeds the standard clearance, adjust the liftgate using the following procedure:
1.  Loosen the liftgate hinge installation bolts and reposition the liftgate. (See LIFTGATE REMOVAL/INSTALLATION.)
2.  Tighten the liftgate hinge installation bolts. (See LIFTGATE REMOVAL/INSTALLATION.)
3.  Verify that the gap between the liftgate and the rear bumper is within the specification.

4.  Spray or pour water on the liftgate and surrounding area using a hose or high pressure water pressure car wash and verify that there is no water leakage.
