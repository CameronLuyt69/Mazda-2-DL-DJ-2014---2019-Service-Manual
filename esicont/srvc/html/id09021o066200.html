DTC U2300:55 [BLIND SPOT MONITORING (BSM) SYSTEM]

id09021o066200

Description

Instrument cluster configuration not implemented
Detection condition
•  Blind spot monitoring (BSM) control module (LH) received a signal which indicates the instrument cluster configuration is not performed with the ignition switched ON (engine off or on).
Fail-safe
•  Blind spot monitoring (BSM) system is stopped.
Possible cause
Note
•  To correctly write the configuration data sent from the instrument cluster to the Blind spot monitoring (BSM) control module (LH) to the blind spot monitoring (BSM) control module (LH), 30 s or more need to have elapsed since the ignition was switched ON (engine off or on).
•  Instrument cluster configuration is not completed.
•  Blind spot monitoring (BSM) control module (LH) malfunction
System wiring diagram
Not applicable

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY BLIND SPOT MONITORING (BSM) CONTROL MODULE DTCs AGAIN
•  Clear the DTC for the blind spot monitoring (BSM) control module using the M-MDS.
(See CLEARING DTC [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the ignition ON (engine off or on) and wait for 30 s or more.
•  Retrieve the blind spot monitoring (BSM) control module DTCs using the M-MDS.
(See DTC INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Is the same DTC displayed?
Yes
Go to the next step.
No
Go to Step 4.
2
RESET CONFIGURATION DATA FROM INSTRUMENT CLUSTER TO BLIND SPOT MONITORING (BSM) CONTROL MODULE (LH)
•  Using the M-MDS, perform the instrument cluster configuration (using As-Built data).
(See INSTRUMENT CLUSTER CONFIGURATION (USING AS-BUILT DATA).)
•  Clear the DTC for the blind spot monitoring (BSM) control module using the M-MDS.
(See CLEARING DTC [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the ignition ON (engine off or on) and wait for 30 s or more.
•  Retrieve the blind spot monitoring (BSM) control module DTCs using the M-MDS.
(See DTC INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Is the same DTC displayed?
Yes
Using the M-MDS, perform the instrument cluster configuration (using As-Built data) again, then go to the next step.
(See INSTRUMENT CLUSTER CONFIGURATION (USING AS-BUILT DATA).)
No
Go to Step 4.
3
VERIFY THAT REPAIRS HAVE BEEN COMPLETED
•  Clear the DTC for the blind spot monitoring (BSM) control module using the M-MDS.
(See CLEARING DTC [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the ignition ON (engine off or on) and wait for 30 s or more.
•  Retrieve the blind spot monitoring (BSM) control module DTCs using the M-MDS.
(See DTC INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)

Yes

(See BLIND SPOT MONITORING (BSM) CONTROL MODULE REMOVAL/INSTALLATION.)
No
Go to the next step.
