THROTTLE POSITION (TP) SENSOR [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1006900


Purpose/Function

•  Detects the throttle valve opening/closing condition, which operates in accordance with the accelerator pedal operation, as basic information (mainly used to determine the fuel injection amount) and sends it to the PCM as the throttle valve opening angle signal.

Construction

•  Built into the throttle body.
am3zzn00003609
•  A Hall element has been adopted (as the detecting element) for detecting the throttle valve opening/closing condition.
•  The TP sensor has a main sensor (No.1) and a sub sensor (No.2) for improved detection accuracy.

Operation

•  Sends the signal, which fluctuates according to the throttle valve opening/closing, to the PCM.
