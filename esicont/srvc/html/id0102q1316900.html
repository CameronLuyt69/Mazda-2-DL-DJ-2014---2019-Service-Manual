DTC P117A:00

Engine oil temperature is high
DETECTION CONDITION
•  With the transmission in 5th gear or lower gear, an engine speed of 6,100 rpm or more continues for 6 min.
Diagnostic support note
•  This is a continuous monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA is not available.
•  Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
•  Limits intake air amount
POSSIBLE CAUSE
•  High engine speed condition continues
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable
