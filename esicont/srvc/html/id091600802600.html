Reusing Rear Spoiler

Warning
•  Always wear gloves when using a utility knife. Using a utility knife with bare hands can cause injury.

1.  Using a utility knife, remove the double-sided adhesive tape applied to the rear spoiler.

2.  Clean and degrease the double-sided adhesive tape application area of the rear spoiler.

3.  Affix the double-sided adhesive tape to the position shown in the figure.

am2zzw00008976

4.  If the protector is damaged, replace the part that is damaged with a new protector.

am2zzw00008977

5.  Clean and degrease the double-sided adhesive tape application area of the trunk lid.

am2zzw00008978

6.  Peel off the backing from the double-sided adhesive tape applied to the rear spoiler.

7.  Install the rear spoiler to the trunk lid.

am2zzw00008979

8.  Install the bolts.

am2zzw00008980

9.  Install the trunk lid trim. (See TRUNK LID TRIM REMOVAL/INSTALLATION.)

10.  Press the rear spoiler and apply the double-sided adhesive tape to the rear spoiler installation area.


Rear Spoiler Newly Replaced

Note
•  Double-sided adhesive tape has already been adhered to a new rear spoiler.

1.  Clean and degrease the double-sided adhesive tape application area of the trunk lid.

am2zzw00008978

2.  Clean and degrease the double-sided adhesive tape application area of the rear spoiler.

3.  Install the rear spoiler to the trunk lid.

am2zzw00008981

4.  Install the bolts.

am2zzw00008982

5.  Install the trunk lid trim. (See TRUNK LID TRIM REMOVAL/INSTALLATION.)

6.  Press the rear spoiler and apply the double-sided adhesive tape to the rear spoiler installation area.
