BLIND SPOT MONITORING (BSM) OFF INDICATOR LIGHT DOES NOT TURN ON [BLIND SPOT MONITORING (BSM)]

id0903d9055600

Note
•  If there is any vehicle malfunction complaint lodged by a customer, first perform malfunction diagnosis according to the troubleshooting procedure. (See FOREWORD [BLIND SPOT MONITORING (BSM)].)

Description

•  The blind spot monitoring (BSM) OFF indicator light does not turn on while under the illumination conditions.

Possible malfunction

Note
•  The detection performance of the blind spot monitoring (BSM) control module has limitations and the blind spot monitoring (BSM) system may not operate normally. For the detection performance limitations, refer to the [BLIND SPOT MONITORING (BSM) CONTROL MODULE] in the technical guide.
•  The blind spot monitoring (BSM) control module (LH) cannot verify the blind spot monitoring (BSM) switch ON/OFF.
―  Blind spot monitoring (BSM) switch-related malfunction
―  Blind spot monitoring (BSM) control module (LH) malfunction
•  The instrument cluster cannot turn on the blind spot monitoring (BSM) OFF indicator light.
―  Instrument cluster malfunction (illumination circuit malfunction)

Diagnostic Procedure

Step

Inspection

Action
1
DETERMINE IF CAUSE OF MALFUNCTION IS BLIND SPOT MONITORING (BSM) SWITCH OR BLIND SPOT MONITORING (BSM) INDICATOR LIGHT
•  Display the blind spot monitoring system (BSM) PID MAIN_SW item using the M-MDS.
(See PID/DATA MONITOR INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the blind spot monitoring (BSM) switch ON/OFF.
•  Does the PID MAIN_SW monitoring value turn on and off according to the blind spot monitoring (BSM) switch ON/OFF operation?
Yes
Go to Step 3.
No
Go to the next step.
2
BLIND SPOT MONITORING (BSM) SWITCH INSPECTION
•  Inspect the blind spot monitoring (BSM) switch.
(See BLIND SPOT MONITORING (BSM) SWITCH INSPECTION.)
•  Is the blind spot monitoring (BSM) switch normal?
Yes
Go to the next step.
No
Replace the blind spot monitoring (BSM) switch.
(See BLIND SPOT MONITORING (BSM) SWITCH REMOVAL/INSTALLATION.)
3
DETERMINE IF MALFUNCTION CAUSE IS INSTRUMENT CLUSTER OR BLIND SPOT MONITORING (BSM) CONTROL MODULE (LH)
•  Turn off all the indicator lights and warning lights in the instrument cluster using the simulation function WL+IL of the M-MDS instrument cluster.
(See ACTIVE COMMAND MODES INSPECTION [INSTRUMENT CLUSTER].)
•  Did the blind spot monitoring (BSM) OFF indicator light turn off?
Yes
Replace the blind spot monitoring (BSM) control module (LH).
(See BLIND SPOT MONITORING (BSM) CONTROL MODULE REMOVAL/INSTALLATION.)
No
Replace the instrument cluster.
(See INSTRUMENT CLUSTER REMOVAL/INSTALLATION.)
