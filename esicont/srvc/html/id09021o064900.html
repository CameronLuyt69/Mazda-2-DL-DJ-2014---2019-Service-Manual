DTC U0001:88/U0100:00/U0121:00/U0155:00/U0214:00 [BLIND SPOT MONITORING (BSM) SYSTEM]

id09021o064900

Description
•  U0001:88
―  Unit communication error (MS-CAN)
•  U0100:00
―  Communication error with PCM
•  U0121:00
―  Communication error with DSC HU/CM
•  U0155:00
―  Communication error with instrument cluster
•  U0214:00
―  Communication error with start stop unit
Detection condition
•  U0001:88
―  Blind spot monitoring (BSM) control module (LH) detects a CAN bus communication line (MS-CAN) malfunction with the ignition switched ON (engine off or on).
•  U0100:00
―  Blind spot monitoring (BSM) control module (LH) cannot receive the CAN signal from the PCM for 2 s or more with the ignition switched ON (engine off or on).
•  U0121:00
―  Blind spot monitoring (BSM) control module (LH) cannot receive the CAN signal from the DSC HU/CM for 2 s or more with the ignition switched ON (engine off or on).
•  U0155:00
―  Blind spot monitoring (BSM) control module (LH) cannot receive the CAN signal from the instrument cluster for 2 s or more with the ignition switched ON (engine off or on).
•  U0214:00
―  Blind spot monitoring (BSM) control module (LH) cannot receive the CAN signal from the start stop unit for 2 s or more with the ignition switched ON (engine off or on).
Fail-safe
•  U0001:88
―  Blind spot monitoring (BSM) system is stopped.
•  U0100:00
―  Blind spot monitoring (BSM) system is stopped.
•  U0121:00
―  Blind spot monitoring (BSM) system is stopped.
•  U0155:00
―  Blind spot monitoring (BSM) system is stopped.
•  U0214:00
―  Blind spot monitoring (BSM) system is stopped.
Possible cause
•  Malfunction in CAN bus communication line
•  Malfunction in CAN communication line between PCM and blind spot monitoring (BSM) control module (LH)
―  Instrument cluster communication error (vehicle speed signal is not sent via instrument cluster from PCM)
•  Malfunction in CAN communication line between DSC HU/CM and blind spot monitoring (BSM) control module (LH)
―  Instrument cluster communication error (yaw rate signal is not sent via instrument cluster from DSC HU/CM)
•  Malfunction in CAN communication line between instrument cluster and blind spot monitoring (BSM) control module (LH)
•  Malfunction in CAN communication line between start stop unit and blind spot monitoring (BSM) control module (LH)
―  Instrument cluster communication error (turn switch signal is not sent via instrument cluster from start stop unit)
System wiring diagram
Not applicable
