Note
•  The MAP sensor is integrated with the boost air temperature sensor. When replacing the MAP sensor or the boost air temperature sensor, replace the MAP sensor/boost air temperature sensor.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the bolt.

am2zzw00011422

3.  Remove the bracket.

4.  Disconnect the MAP sensor/boost air temperature sensor connector.

am2zzw00011423

5.  Remove the screw.

6.  Remove the MAP sensor/boost air temperature sensor.

am2zzw00011424

7.  Install in the reverse order of removal.
