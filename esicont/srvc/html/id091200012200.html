POWER WINDOW SYSTEM

id091200012200


Outline

•  The door glass opens/closes electrically when the power window main switch or the power window subswitch is operated.

Function


Manual open/manual close function

•  When the power window main switch or subswitch is operated for manual operation, the front door glass/rear door glass performs manual open/manual close operation.


Auto open/auto close function

•  When the power window main switch is operated for auto operation, the driver's side front door glass performs auto open/auto close operation.


IG OFF timer function

•  The driver's side power window can be operated using the power window main switch for approx. 40 s after the ignition is switched from ON (engine on or off) to ACC or OFF.


Auto reverse pinch protection function

•  If an obstruction by a foreign object is detected during the auto close operation, the operation changes from close to open.


Fully-closed position record function

•  The power window control module records the fully-closed position of the driver's side front door glass so that the auto reverse pinch protection function does not operate when the driver's side front door glass is fully closed.

Operation


Operation of driver's side manual open/close function (Example: manual close operation)

1.  When the power window main switch is operated for manual close operation, the manual close switch is switched (1).

2.  When the power window control module detects a manual close signal, current flows to the close relay (2) and the close relay turns on (3).

3.  When the close relay turns on, the power window motor (driver's side) performs close operation (4).

am2zzn00001976


Operation of auto open/close function (Example: auto open operation)

1.  When the power window main switch is operated for auto open operation, the auto switch and the manual open switch are switched (1).

2.  When the power window control module detects an auto open signal, current flows to the open relay (2) and the open relay turns on (3).

3.  When the open relay turns on, the power window motor (driver's side) performs auto open operation (4).

am2zzn00001977


Operation of front passenger's side and rear manual open/close function (Example: front passenger's side close operation)

1.  When the power window subswitch is operated for close operation, the close switch switches (1).

2.  When the close switch is on, the power window motor (passenger's side) performs close operation (2).

Operation of IG OFF timer function

•  When the ignition is switched from ON (engine off or on) to ACC or OFF, the IG OFF timer function of the power window control module is turned on, and the power window main switch can be operated for approx. 40 s after IG OFF is detected.


Operation of auto reverse pinch protection function

•  If the power window control module detects a change in the pulse signal from the power window motor for 0.3 s during auto close operation, it reverses the power window motor operation and opens the door glass approx. 200 mm {7.87 in}.


Fully-closed position record function

•  When the ignition is switched ON (engine off or on), and the switch is pulled and held for approx. 2 s after the driver's side door glass is fully closed from the fully opened position, the power window control module records the driver's side door glass position.
Note
•  Performing the following procedures will reset the initial setting and disables auto operation. Re-perform the initial setting.
―  Negative battery cable is disconnected
―  Power window main switch connector is disconnected
―  Power window system power supply fuse is removed
