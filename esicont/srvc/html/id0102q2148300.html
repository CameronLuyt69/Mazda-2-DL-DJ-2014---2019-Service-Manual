DTC P0219:00

Engine overspeed condition
DETECTION CONDITION
•  PCM detects that the engine speed is 5,670 rpm or more.
Diagnostic support note
•  This is an intermittent monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA/Snapshot data is not available.
•  DTC is not stored in the PCM memory.
FAIL-SAFE FUNCTION
Not applicable
POSSIBLE CAUSE
•  ATX system malfunction (ATX)
―  Excessive rotation due to improper gear lock
•  Malfunction caused by the following driving operations:
―  Excessive rotation due to improper shift operation
―  Deceleration using improper gear, and descending slope
•  Mechanical (engine) malfunction
―  Fuel injector malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable
