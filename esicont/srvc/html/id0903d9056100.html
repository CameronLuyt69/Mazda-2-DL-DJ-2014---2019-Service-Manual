BLIND SPOT MONITORING (BSM) WARNING BUZZER IS NOT ACTIVATED [BLIND SPOT MONITORING (BSM)]

id0903d9056100

Note
•  If there is any vehicle malfunction complaint lodged by a customer, first perform malfunction diagnosis according to the troubleshooting procedure. (See FOREWORD [BLIND SPOT MONITORING (BSM)].)

Description

•  The blind spot monitoring (BSM) warning buzzer does not activate even though the blind spot monitoring (BSM) warning indicator light is flashing.

Possible malfunction

Note
•  The detection performance of the blind spot monitoring (BSM) control module has limitations and the blind spot monitoring (BSM) system may not operate normally. For the detection performance limitations, refer to the [BLIND SPOT MONITORING (BSM) CONTROL MODULE] in the technical guide.
•  Volume setting of blind spot monitoring (BSM) warning buzzer is turned off using personalization feature
•  Instrument cluster receives incorrect beeper sound request signal
―  Instrument cluster malfunction
―  Blind spot monitoring (BSM) control module (LH) malfunction

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY PERSONALIZATION FEATURE SETTING
•  Verify the volume setting of the blind spot monitoring (BSM) warning buzzer of the personalization features.
(See INSTRUMENT CLUSTER PERSONALIZATION FEATURES SETTING PROCEDURE.)
•  Is the volume setting off?
Yes
Perform the volume setting of the blind spot monitoring (BSM) warning buzzer in consultation with the customer.
(See INSTRUMENT CLUSTER PERSONALIZATION FEATURES SETTING PROCEDURE.)
No
Go to the next step.
2
DETERMINE IF MALFUNCTION CAUSE IS BUZZER SOUND RELATED CIRCUIT
•  Implement the instrument cluster simulation ALARM using the M-MDS, and activate the warning alarm.
•  Is the warning alarm activated?
Yes
Go to the next step.
No
Replace the instrument cluster.
(See INSTRUMENT CLUSTER REMOVAL/INSTALLATION.)
3
DETERMINE IF MALFUNCTION CAUSE IS BLIND SPOT MONITORING (BSM) CONTROL MODULE
•  Implement the blind spot monitoring (BSM) system simulation Buzzer item using the M-MDS.
•  Does the blind spot monitoring (BSM) warning buzzer activate?
Yes
Go to the symptom troubleshooting procedure, "Blind spot monitoring (BSM) warning indicator light falsely flashes.
(See BLIND SPOT MONITORING (BSM) WARNING LIGHT FALSE FLASH [BLIND SPOT MONITORING (BSM)].)
No
Replace the blind spot monitoring (BSM) control module (LH).
(See BLIND SPOT MONITORING (BSM) CONTROL MODULE REMOVAL/INSTALLATION.)
