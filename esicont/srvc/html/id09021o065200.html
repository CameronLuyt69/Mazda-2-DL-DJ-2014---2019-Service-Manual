DTC U0415:68 [BLIND SPOT MONITORING (BSM) SYSTEM]

id09021o065200

Description

Error signal received from DSC HU/CM
Detection condition
•  Blind spot monitoring (BSM) control module (LH) receives the error signal from the DSC HU/CM for 2 s or more with the ignition switched ON (engine off or on).
Fail-safe
•  Blind spot monitoring (BSM) system is stopped.
Possible cause
•  DTCs are stored in the DSC HU/CM.
―  DSC HU/CM malfunction
•  DTCs are stored in the instrument cluster.
―  Instrument cluster malfunction
•  Blind spot monitoring (BSM) control module (LH) malfunction
System wiring diagram
Not applicable
