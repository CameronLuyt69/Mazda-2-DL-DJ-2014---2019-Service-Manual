DTC U3000:54 [BLIND SPOT MONITORING (BSM) SYSTEM]

id09021o066700

Description

Radar aiming is not performed or radar sensor axis is deviated (Blind spot monitoring (BSM) control module (LH))
Detection condition
•  Malfunction in radar aiming of blind spot monitoring (BSM) control module (LH) detected for 1 s or more with the ignition switched ON (engine off or on).
Fail-safe
•  Blind spot monitoring (BSM) system is stopped.
Possible cause
•  Blind spot monitoring (BSM) radar aiming (LH) was not performed.
•  Deviation of blind spot monitoring (BSM) control module (LH) radar sensor axis
•  Blind spot monitoring (BSM) control module (LH) malfunction
System wiring diagram
Not applicable

Diagnostic Procedure

Step

Inspection

Action
1
PERFORM BLIND SPOT MONITORING (BSM) CONTROL MODULE (LH) RADAR AIMING
•  Perform the blind spot monitoring (BSM) control module (LH) radar aiming.
(See BLIND SPOT MONITORING (BSM) RADAR AIMING.)
•  Clear the DTC for the blind spot monitoring (BSM) control module using the M-MDS.
(See CLEARING DTC [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the ignition ON (engine off or on) and wait for 2.5 s or more.
•  Retrieve the blind spot monitoring (BSM) control module DTCs using the M-MDS.
(See DTC INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Is the same DTC displayed?
Yes
Perform the blind spot monitoring (BSM) control module (LH) radar aiming again, then go to the next step.
(See BLIND SPOT MONITORING (BSM) RADAR AIMING.)
No
Go to Step 3.
2
VERIFY THAT REPAIRS HAVE BEEN COMPLETED
•  Clear the DTC for the blind spot monitoring (BSM) control module using the M-MDS.
(See CLEARING DTC [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Switch the ignition ON (engine off or on) and wait for 2.5 s or more.
•  Retrieve the blind spot monitoring (BSM) control module DTCs using the M-MDS.
(See DTC INSPECTION [BLIND SPOT MONITORING (BSM) SYSTEM].)
•  Is the same DTC displayed?
Yes
Replace the blind spot monitoring (BSM) control module (LH), then go to the next step.
(See BLIND SPOT MONITORING (BSM) CONTROL MODULE REMOVAL/INSTALLATION.)
No
Go to the next step.
3
VERIFY IF OTHER DTCs DISPLAYED
•  Are any other DTCs displayed?
Yes
Repair or replace the malfunctioning part according to the applicable DTC troubleshooting.
(See DTC TABLE [BLIND SPOT MONITORING (BSM) SYSTEM].)
No
