LED HEADLIGHT WARNING LIGHT ILLUMINATES CONTINUOUSLY [HEADLIGHT AUTO LEVELING SYSTEM]

id0903d0220000

Note
•  If there is any vehicle malfunction complaint lodged by a customer, perform FOREWORD [HEADLIGHT AUTO LEVELING SYSTEM] malfunction diagnosis according to the troubleshooting procedure. (See FOREWORD [HEADLIGHT AUTO LEVELING SYSTEM].)

Description

•  Inspect the LED headlight warning light with the ignition switched ON (engine off or on).

Possible malfunction

•  Auto leveling control module malfunction
•  Instrument cluster malfunction

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY LED HEADLIGHT WARNING LIGHT ILLUMINATION
•  Display the following instrument cluster WL+IL simulation items using the M-MDS.
(See ACTIVE COMMAND MODES INSPECTION [INSTRUMENT CLUSTER].)
•  Does the LED headlight warning light illumination turn off when the warning light, indicator light illumination is operated to off?
Yes
Replace the auto leveling control module.
(See AUTO LEVELING CONTROL MODULE REMOVAL/INSTALLATION.)
Go to the next step.
No
Replace the instrument cluster.
(See INSTRUMENT CLUSTER REMOVAL/INSTALLATION.)
Go to the next step.
2
VERIFY IF MALFUNCTION CAUSE IS CORRECTED
•  Switch the ignition to ACC or ON (engine off or on).
•  Does the LED headlight warning light illumination turn off?
Yes
Troubleshooting completed. (explain the contents of the servicing to the customer)
No
Verify the malfunction symptom in the symptom troubleshooting chart and perform the other applicable malfunction diagnosis.
(See SYMPTOM TROUBLESHOOTING [HEADLIGHT AUTO LEVELING SYSTEM].)
