CAMSHAFT POSITION (CMP) SENSOR [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1006700


Purpose/Function

•  Detects the camshaft speed as basic information (mainly used to determine the fuel injection timing and ignition timing) and sends it to the PCM as a CMP signal.

Construction


Intake CMP sensor

•  Installed on the cylinder head.
am2zzn00003379
•  A GMR element has been adopted (as the detecting element) for detecting the intake camshaft speed.


Exhaust CMP sensor (SKYACTIV-G 1.5 (with 4-2-1 exhaust system))

•  Installed on the rear housing.
am2zzn00003380
•  A GMR element has been adopted (as the detecting element) for detecting the exhaust camshaft speed.


Operation

•  Sends the signal, which fluctuates according to the camshaft speed, to the PCM.
