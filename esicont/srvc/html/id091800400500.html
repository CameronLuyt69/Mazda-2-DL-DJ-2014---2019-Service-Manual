EXTERIOR LIGHTING SYSTEM

id091800400500


Outline

•  Projector type headlights have been adopted to the front combination lights. (Front combination light (LED type))
•  LEDs have been adopted for the following lights:
―  Headlight (front combination light (LED type))
―  Parking light/running light (front combination light (LED type))
―  Brake light/taillight (rear combination light (LED type))
―  Side turn light
―  High-mount brake light
•  An auto light system has been adopted in which the TNS, headlight LO, and panel light automatically turn on and off. (With auto light system)
•  A headlight manual leveling system has been adopted which changes the headlight LO optical axis according to the operation of the headlight leveling switch. (With headlight manual leveling system)
•  A headlight auto leveling system has been adopted which changes the headlight LO optical axis according to change in vehicle height. (With headlight auto leveling system)
•  A High Beam Control (HBC) system has been adopted which automatically changes the headlights to low beams when it recognizes a vehicle ahead or travel on city streets. (With high beam control (HBC) system)
•  A coming home light system has been adopted which turns on the headlight LO for a specified time using the flash-to-pass operation.
•  A leaving home light system has been adopted which turns on the TNS and headlight LO for a specified time by operating the unlock button on the remote transmitter.
•  Power outer mirrors with built-in front side turn lights have been adopted.
•  Front fog lights have been adopted to the front bumper. (With front fog lights)
•  Rear fog light has been adopted in the rear bumper. (With rear fog light)
•  An emergency signal system (ESS) has been adopted which flashes the hazard warning lights if the vehicle suddenly decelerates while traveling at high speed.

Function

•  The BCM sends an exterior light on/off request signal to the electrical supply unit (ESU) based on the engine switch condition and light switch position signal, and the electrical supply unit (ESU) turns the exterior lights on/off.
