SECURITY INDICATOR LIGHT

id091400603300


Purpose

•  The security indicator light notifies the driver that the immobilizer system is operating or there is a malfunction in the system.

Function

•  The instrument cluster flashes the security indicator light based on the system condition display request signal sent via a CAN signal from the start stop unit.
•  When the immobilizer system is operating, it turns on for 0.1 s every approx. 2 s.
am2zzn00001847
•  If the immobilizer system is normal, the security indicator light turns on for approx. 3 s and then turns off after the push button start is pressed.
am2zzn00001848
•  When there is a malfunction in the immobilizer system, the DTC can be verified by the flashing pattern. For details, refer to the [ON-BOARD DIAGNOSTIC SYSTEM].(See ON-BOARD DIAGNOSIS SYSTEM [IMMOBILIZER SYSTEM].)

Construction

•  The security indicator light is built into the instrument cluster.
am2zzn00002356

Operation

1.  The instrument cluster receives (1) the system condition display request signal or warning indication request signal from the start stop unit via CAN communication.

2.  When the instrument cluster receives the system condition display request signal or warning indication request signal, it turns the transistor on (2).

3.  When the transistor turns on, the security indicator light turns on/flashes (3).
