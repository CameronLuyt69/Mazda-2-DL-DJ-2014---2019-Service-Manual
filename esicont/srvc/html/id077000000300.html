REFRIGERANT SYSTEM SERVICE CAUTIONS

id077000000300


Purpose of Adoption

•  New refrigerant HFO-1234yf (R-1234yf) has been newly adopted.

Service Point

•  Always use the following specified compressor oil (PAG oil). If compressor oil other than the specified type is used, the refrigerant performance may be lowered or the refrigerant cycle parts may be damaged.

SKYACTIV-G 1.3, SKYACTIV-G 1.5

Specified compressor oil
•  HFC-134a (R-134a) => ZXL200PG
•  HFO-1234yf (R-1234yf) => VC200YF
Compressor oil sealed volume (approx. quantity)
•  HFC-134a (R-134a) => 110 ml {110 cc, 3.72 fl oz}
•  HFO-1234yf (R-1234yf) => 110 ml {110 cc, 3.72 fl oz}


SKYACTIV-D 1.5

Specified compressor oil
•  HFC-134a (R-134a) => DH-PR
•  HFO-1234yf (R-1234yf) => YR20
Compressor oil sealed volume (approx. quantity)
•  HFC-134a (R-134a) => 140 ml {140 cc, 4.73 fl oz}
•  HFO-1234yf (R-1234yf) => 130 ml {130 cc, 4.40 fl oz}


Common Inquiry

•  Not applicable

Other

•  Shape of the charging valve for HFC-134a (R-134a) and HFO-1234yf (R-1234yf) is different.
