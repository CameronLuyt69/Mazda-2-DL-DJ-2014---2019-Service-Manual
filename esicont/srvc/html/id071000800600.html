REFRIGERANT PRESSURE CHECK

id071000800600

Note
•  Measure the refrigerant pressure after approx.10 min have elapsed from engine start.

1.  Install the manifold gauge. (See REFRIGERANT SYSTEM GENERAL PROCEDURES.)

2.  Start the engine and warm it up.

3.  Set the fan speed to MAX HI.

4.  Turn the A/C switch on.

5.  Set to RECIRCULATE mode.

6.  Set the temperature control to MAX COLD.

7.  Set to VENT mode.

8.  Close all the doors and all the windows.

9.  Maintain the engine speed at 1,500 rpm.

10.  Measure the ambient temperature and high- and low- pressure side reading of the manifold gauge.

11.  Verify that there are high/low pressure value readings within the shaded areas of the figure.
