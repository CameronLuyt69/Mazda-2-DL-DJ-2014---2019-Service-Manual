SEAT WARMER UNIT

id091300101400


Purpose, Function

•  The seat warmer unit warms the front seat.

Functions

•  By sending current to the electric heating wire built into the seat warmer unit from the seat warmer control unit, the electric heating wire warms up and the front seat cushion warm up.

Construction

•  The seat warmer unit is built into the following locations:
