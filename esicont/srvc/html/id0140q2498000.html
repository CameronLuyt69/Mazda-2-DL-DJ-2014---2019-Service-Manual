PID/DATA Monitor Inspection

Note
•  The coolant control valve position sensor is built into the coolant control valve. When replacing the coolant control valve position sensor, replace the coolant control valve.

1.  Connect the M-MDS to the DLC-2.

2.  Switch the ignition ON (engine off).

3.  Access the PID/DATA monitor item CCV_ACT and simulation item CCV_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

4.  Verify that PID CCV_ACT value conforms to the CCV_DSD value when the simulation item CCV_DSD value is fluctuated.

•  If not as verified, replace the coolant control valve. (See COOLANT CONTROL VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
