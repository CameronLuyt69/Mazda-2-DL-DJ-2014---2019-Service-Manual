LIGHTING SYSTEM PERSONALIZATION

id091800013300

Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the Mazda Modular Diagnostic System (M-MDS). Do not select [Not equipped] in the setting displayed on the Mazda Modular Diagnostic System (M-MDS).
Note
•  Settings of some personalization features displayed on the Mazda Modular Diagnostic System (M-MDS) cannot be changed depending on the vehicle specification.
•  A personalization feature has been adopted with which settings for each function can be changed.
•  The setting for each function can be switched using the Mazda Modular Diagnostic System (M-MDS) or the center display (with center display). Refer to the [LIGHTING SYSTEM PERSONALIZATION FEATURES SETTING PROCEDURE] in the workshop manual for the detailed setting procedure.

Note
•  If the mode is set to [Extra High (Except Japan)] and [High (Except Japan)], the illuminance level for turning on the headlight LO, TNS, and panel light increases. Therefore, each light turns on when the ambient light is brighter than when the level is set to [Standard (All Others)]. In addition, if the mode is set to [Extra Low (Except Japan)] or [Low (All Others)], the illuminance level for turning on the headlight LO, TNS, and panel light decreases. Therefore, each light turns on when the ambient light is darker than when the level is set to [Standard (All Others)].
•  The personalization feature may not be set correctly if [Japan Only], such as [Extra High (Japan Only)], is selected. Do not select [Japan Only].
•  The auto light sensitivity setting turns on/off the headlight LO, TNS, and panel light according to the following illumination levels.
Note
•  The following illumination levels are a reference. The illumination levels vary depending on the surrounding conditions (weather, reflection off buildings).
