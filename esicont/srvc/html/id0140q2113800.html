(See COMPULSORY DIESEL PARTICULATE FILTER REGENERATION [SKYACTIV-D 1.5].)
13
Perform the following procedure:
1.  Warm up the engine until the engine coolant temperature is 70 °C {158 °F} or more.
2.  Switch the ignition off.
3.  Store “Complete (delete record)” the M-MDS session.
4.  Remove the M-MDS.
5.  Start the engine.
6.  Leave for 3 min while idling.
7.  Continuously drive the vehicle for 30 s at a vehicle speed of 50 km/h {31 mph} or more.
―  When the warning light turns on or flashes, repeat from step 5 (start the engine).
8.  After stopping the vehicle, leave it idling for 3 min without stopping the engine.
9.  Continuously drive the vehicle for 30 s at a vehicle speed of 50 km/h {31 mph} or more again.
―  When the warning light turns on or flashes, repeat from step 5 (start the engine).
—
14
Verify that the learning value (O2S11_CAL) for the A/F sensor is other than 0.
―  If the learning value (O2S11_CAL) for the A/F sensor is 0, repeat from step 5 of the procedure in Step 13 (start the engine).
(See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)
15
Clear the DTCs.
(See CLEARING DTC [SKYACTIV-D 1.5].)
16
Replace the engine oil.
Note
•  Because the PCM is new, it is not necessary to perform the engine oil data reset procedure.
(See ENGINE OIL REPLACEMENT [SKYACTIV-D 1.5].)


PCM Removal/Installation


Without set bolt

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the bolt.

am2zzw00011979

3.  Disconnect the PCM connectors. (See PCM Connector Connection Note.)

4.  Remove the bolt.

am2zzw00011980

5.  Remove the PCM.

6.  Remove the clip A from the PCM bracket.

am2zzw00011981

7.  Remove the clip B from the PCM bracket.

8.  Remove the nut.

am2zzw00011982

9.  Remove the bolt.

10.  Remove the PCM bracket. (See PCM Bracket Installation Note.)

11.  Install in the reverse order of removal.

12.  When replacing the PCM on the vehicles, perform the “PCM Replacement”. (See PCM Replacement.)


With set bolt

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the PCM cover. (See Set Bolt Removal Note.) (See Set Bolt Installation Note.) (See PCM Cover Installation Note.)

am2zzw00011983

3.  Remove the bolt.

am2zzw00011984

4.  Disconnect the PCM connectors. (See PCM Connector Connection Note.)

5.  Remove the bolt.

am2zzw00011985

6.  Remove the nut.

7.  Remove the bracket.

8.  Remove the PCM.

9.  Remove the clip A from the PCM bracket.

am2zzw00011986

10.  Remove the clip B from the PCM bracket.

11.  Remove the nut.

am2zzw00011987

12.  Remove the bolt.

13.  Remove the PCM bracket. (See PCM Bracket Installation Note.)

14.  Install in the reverse order of removal.

15.  When replacing the PCM on the vehicles, perform the “PCM Replacement”. (See PCM Replacement.)


PCM Bracket Installation Note

1.  Install the PCM bracket using the following procedure:

am2zzw00011988

(1)  Temporarily tighten the bolt (1).
(2)  Install the bolt (2).
(3)  Install the nut.
(4)  Tighten the bolt (1).
(5)  Install the bolt (3).


Set Bolt Removal Note

1.  Using a chisel and a hammer, cut a groove on the head of the set bolt so that a screwdriver can be inserted.

2.  Loose the set bolt using an impact screwdriver or pliers.

am6zzw00010942


Set Bolt Installation Note

1.  Install a new set bolt and tighten it until the neck of the bolt breaks off.

PCM Connector Connection Note

Caution
•  Do not touch the PCM connector terminal. The terminal is extremely thin and can be damaged by touching it.
•  If the PCM connector is inserted at an angle and the lever is moved, the connector could be damaged. Verify that the PCM connector is inserted straight.
am2zzw00011991

1.  Set the PCM connector lever to the position shown in the figure.

am2zzw00011992

2.  Align the PCM connector straight against the connection surface.

adejjw00012311

3.  Insert the PCM connector straight and press it in until the lever moves up naturally. (Front harness-side connector)

am2zzw00011993

4.  Press the PCM connector lever until a click sound is heard.
