Note
•  Because the MAP sensor is integrated with the boost air temperature sensor, replacing the MAP sensor includes replacement of the MAP sensor/boost air temperature sensor. (See MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/BOOST AIR TEMPERATURE SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

Visual inspection

1.  Disconnect the negative battery cable.(See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the MAP sensor/boost air temperature sensor. (See MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/BOOST AIR TEMPERATURE SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)

3.  Visually inspect the MAP sensor/boost air temperature sensor for the following malfunction:

•  Damage, cracks, dirt
―  If there is any malfunction, repair or replace the MAP sensor/boost air temperature sensor. (See MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/BOOST AIR TEMPERATURE SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)


Voltage inspection

1.  Switch the ignition ON (engine off).

2.  Measure the voltage at the MAP sensor/boost air temperature sensor terminal D.

am2zzw00011420

•  If the voltage is within the specification, go to the next step.
•  If the voltage is not within the specification, replace the MAP sensor/boost air temperature sensor. (See MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/BOOST AIR TEMPERATURE SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
Specification
Approx. 1.6 V

3.  Connect the M-MDS to the DLC-2.

4.  Access the PID/DATA monitor item MAP_DSD using the M-MDS.(See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

5.  Start the engine.

6.  Measure the voltage at the MAP sensor/boost air temperature sensor terminal D when the MAP_DSD PID increases.

•  If the voltage does not increase, replace the MAP sensor/boost air temperature sensor. (See MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/BOOST AIR TEMPERATURE SENSOR REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
