DTC
C1031:68
Tire Pressure Monitoring System (TPMS)
DETECTION CONDITION
•  Error is detected in ambient temperature sensor from PCM via CAN communication
FAIL-SAFE FUNCTION
Refer to DTC TABLE. (See DTC TABLE [DSC HU/CM].)
POSSIBLE CAUSE
•  Ambient temperature sensor malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
