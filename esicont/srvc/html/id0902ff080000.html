DTC B1207:09 [ELECTRICAL SUPPLY UNIT (ESU)]

id0902ff080000

Description

Error signal received from SAS control module
Detection condition
•  The electrical supply unit (ESU) detected the following conditions for 2 s or more with the ignition switched ON (engine off or on).
―  A signal is received which cannot normally determine the collision conditions from SAS control module even though the collision detection unlock function presence signal received from the BCM determines that the function is present.
Fail-safe
Not applicable
Possible cause
•  SAS control module malfunction
System wiring diagram
Not applicable
