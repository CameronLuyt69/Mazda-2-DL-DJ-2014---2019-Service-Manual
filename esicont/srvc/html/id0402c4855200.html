U0420:82
DETECTION CONDITION
•  Error detected in signal from EPS control module via CAN communication
FAIL-SAFE FUNCTION
•  Smart City Brake Support (SCBS) warning light (amber) Illuminates
•  Smart City Brake Support (SCBS) control disabled
POSSIBLE CAUSE
•  EPS control module malfunction

•  Using the M-MDS, perform the laser sensor DTC inspection.
(See DTC INSPECTION [LASER SENSOR].)
•  Is the same DTC present?
Yes
Perform the following procedures:
•  Verify that the steering angle sensor is equipped, and its wiring harness connects with start stop unit
(See STEERING ANGLE SENSOR REMOVAL/INSTALLATION.)
•  Using the M-MDS, select the PID item STR_AB_EST for EPS control module.
•  Verify the monitor value with steering wheel position 0 ° (vehicle wheels straight-ahead).
―  If monitor value is ± 20 ° or less, replace the steering column, then go to the next step.
(See STEERING WHEEL AND COLUMN REMOVAL/INSTALLATION.)
―  If monitor value is ± 20 ° or more, verify that the Smart City Brake Support (SCBS) warning light (amber) blacks out when vehicle is driven for approx. 5 min after the steering angle signal is reset.
(See START STOP UNIT CONFIGURATION (USING AS-BUILT DATA).)
If the malfunction recurs, replace the steering column, then go to the next step.
(See STEERING WHEEL AND COLUMN REMOVAL/INSTALLATION.)
