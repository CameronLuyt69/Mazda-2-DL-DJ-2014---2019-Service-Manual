DTC C0051:95 [START STOP UNIT]

id0902p6027700

Description

Steering angle sensor assembly malfunction
Detection condition
•  Start stop unit receives the following signals with the ignition switched ON (engine off or on).
―  Steering angle sensor assembly malfunction from EPS control module for 1 s or more
―  Improper assembly of steering angle sensor at 360°
―  Steering wheel angle of 720° or more for 0.048 s or more
Fail-safe
Not applicable
Possible cause
•  DTCs are stored in the EPS control module.
•  Improper assembly of steering angle sensor
•  Start stop unit malfunction
System wiring diagram
Not applicable
