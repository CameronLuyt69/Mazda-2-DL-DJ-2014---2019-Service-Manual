DTC P0850:23 [START STOP UNIT]

id0902p6023200

Description

Transaxle range sensor circuit malfunction
Detection condition
•  The start stop unit detected the following condition 5 times continuously with the ignition switched ON (engine off or on).
―  A transaxle range sensor signal is in the P or N position for a continuous 1 s or more even though the TCM CAN signal is in a position other than the P and N positions.
Fail-safe
•  Perform control of the internal signal for control of the transaxle range sensor as position other than P, N positions.
Possible cause
•  DTCs are stored in the TCM.
•  Start stop unit connector or terminal malfunction
•  TCM connector or terminal malfunction
•  Short to power supply in wiring harness between start stop unit terminal 1F and TCM terminal J
•  Transaxle range sensor malfunction
•  Start stop unit malfunction
