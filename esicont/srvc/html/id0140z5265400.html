DIESEL PARTICULATE FILTER INDICATOR LIGHT [SKYACTIV-D 1.5]

id0140z5265400


Purpose

•  When the PM accumulation amount in the diesel particulate filter exceeds a certain value, the diesel particulate filter indicator light illuminates/flashes to inform the driver that DPF regeneration is required.

Function

•  The PCM sends a diesel particulate filter indicator light illumination/flashing request to the instrument cluster via CAN communication.

Construction

•  The diesel particulate filter indicator light is built into the instrument cluster.
am2zzn00003702
•  For vehicles with center display, a warning message in the center display is displayed when the diesel particulate filter indicator light is illuminated or flashes. For the message content and verification method, refer to the CENTER DISPLAY. (See CENTER DISPLAY [WITH CENTER DISPLAY].)

Operation

•  The diesel particulate filter indicator light illumination/flashing conditions are as follows:
Diesel particulate filter indicator light illumination conditions
―  Ignition switch ON (turns off after several second)
―  PM accumulation amount in diesel particulate filter is 8.0 g/L {0.50 lb/ft3} or more (turns off when it is 5.0 g/L {0.31 lb/ft3} or less)
Diesel particulate filter indicator light flashing condition
―  PM accumulation amount in diesel particulate filter is 10.0 g/L {0.62 lb/ft3} or more (turns off when it is 5.0 g/L {0.31 lb/ft3} or less)

1.  When the illumination or flashing conditions are met, the instrument cluster receives (1) a diesel particulate filter indication light-on request signal or a diesel particulate filter indication flash request signal from the PCM.

2.  The instrument cluster turns the transistor on (2) intermittently when it receives a diesel particulate filter indication flash request signal, and it turns the transistor on continuously when it receives a diesel particulate filter indication on request signal.

3.  The diesel particulate filter indicator light flashes (3) when the transistor is turned on intermittently, and it turns on (3) when the transistor is turned on continuously.
