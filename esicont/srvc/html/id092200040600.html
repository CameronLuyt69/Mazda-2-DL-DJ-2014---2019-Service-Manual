LDWS OFF INDICATOR LIGHT

id092200040600


Purpose

•  The LDWS OFF indicator light notifies the driver that the lane departure warning system (LDWS) is not operable.

Function

•  The instrument cluster turns the LDWS OFF indicator light on based on the system conditions display request signal sent from the forward sensing camera (FSC) via CAN communication.

Construction

•  The LDWS OFF indicator light is built into the instrument cluster.
am2zzn00002944

Operation

1.  The instrument cluster receives (1) the system conditions display request signal from the forward sensing camera (FSC) via CAN communication.

2.  The instrument cluster turns the transistor on (2) based on the system conditions display request signal.

3.  When the transistor turns on, the LDWS OFF indicator light turns on (3).
