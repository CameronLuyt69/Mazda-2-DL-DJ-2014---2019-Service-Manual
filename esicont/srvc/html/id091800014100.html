REAR FOG LIGHT

id091800014100


Purpose

•  The rear fog light enhances the visibility of the vehicle from vehicle rear during poor weather conditions such as rain and fog.

Functions

•  When the BCM receives a rear fog light signal sent via CAN communication from the start stop unit, it turns the rear fog light on.

Construction

•  The rear fog light is located on the rear bumper.
am2zzn00003791

Operation

1.  When the fog light switch is turned to R.FOG position with the ignition switched ON (engine off or on) and the headlight LO or HI signal received, the start stop unit detects (1) a rear fog light signal.
2.  The start stop unit sends (2) the rear fog light signal to the BCM via CAN communication.
3.  When the BCM receives the rear fog light signal, it sends (3) a rear fog light on request signal to the electrical supply unit (ESU) via LIN communication.
4.  When the electrical supply unit (ESU) receives the rear fog light on request signal, it turns the rear fog light on (4).
