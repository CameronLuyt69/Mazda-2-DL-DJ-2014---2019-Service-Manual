BLIND SPOT MONITORING (BSM) OFF INDICATOR LIGHT

id092200027500


Purpose

•  The blind spot monitoring (BSM) OFF indicator light alerts the driver that the blind spot monitoring (BSM) system is not operating or a malfunction in the system has occurred.

Function

•  The instrument cluster turns on the blind sport monitoring (BSM) OFF indicator light based on the blind spot monitoring (BSM) status display signal sent via CAN communication from the blind spot monitoring (BSM) control module (LH).

Construction

•  The blind spot monitoring (BSM) OFF indicator light is built into the instrument cluster.
am2zzn00002031
•  For vehicles with the center display, a warning message is displayed in the center display at the same time as when the blind spot monitoring (BSM) OFF indicator light is turned on after a malfunction occurs in the blind spot monitoring (BSM) system. For the message content and verification method, refer to the CENTER DISPLAY. (See CENTER DISPLAY [WITH CENTER DISPLAY].)

Operation

1.  The instrument cluster receives (1) blind spot monitoring (BSM) status display signal from the blind spot monitoring (BSM) control module (LH) via CAN communication.

2.  When the instrument cluster receives the blind spot monitoring (BSM) status display signal, it turns the transistor on (2).

3.  When the transistor turns on, the blind spot monitoring (BSM) OFF indicator light turns on (3).
