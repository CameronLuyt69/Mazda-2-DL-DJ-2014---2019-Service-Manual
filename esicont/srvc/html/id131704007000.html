CAPACITOR (i-ELOOP) INSPECTION [i-ELOOP]

id131704007000

1.  Verify that the capacitor (i-ELOOP) related DTC is detected. (See DTC INSPECTION [i-ELOOP].) (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-G 1.3, SKYACTIV-G 1.5].) (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

•  If DTCs are detected, repair the malfunctioning part according to the applicable DTC troubleshooting. (See DTC TABLE [i-ELOOP].) (See DTC TABLE [SKYACTIV-G 1.3, SKYACTIV-G 1.5].) (See DTC TABLE [SKYACTIV-D 1.5].)
•  If a DTC is not detected, go to the next step.

2.  Turn the steering wheel completely to the right.

3.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

4.  Set the front mudguard (LH) aside as shown in the figure.

am2zzw00010388

5.  Do a visual inspection of the capacitor (i-ELOOP).

•  If the capacitor (i-ELOOP) is damaged, replace it. (See CAPACITOR (i-ELOOP) REMOVAL/INSTALLATION [i-ELOOP].)

6.  Install in the reverse order of removal.
