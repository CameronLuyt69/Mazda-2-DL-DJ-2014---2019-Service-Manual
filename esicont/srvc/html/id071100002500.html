HEATER SYSTEM

id071100002500


Outline

•  The heater system warms the heater core using the engine coolant warmed while the engine is operating, and warms the air passing through the heater core.

Function


Heater core

•  The heater system intakes a portion of the warmed engine coolant into the heater core and circulates it.


PTC heater (With PTC heater)

•  The heater system warms the air passing in the A/C unit using the heat generated by the PTC heater.

Operation


1.  Engine coolant flows into the heater core by the operation of the water pump.
2.  When the warmed engine coolant circulates in the heater core, the heater core warms up.
