LP-EGR CONTROL VALVE POSITION SENSOR [SKYACTIV-D 1.5]

id0140z5433600


Purpose/Function

•  Detects the LP-EGR control valve open/closed condition as basic information for mainly EGR control and boost control.
•  Detects the LP-EGR control valve opening/closing condition and sends it to the PCM as the LP-EGR control valve opening angle signal.

Construction

•  Built into the LP-EGR control valve.
am2zzn00003720
•  A Hall element has been adopted as the detecting element for detecting the LP-EGR control valve opening/closing condition.

Operation

•  Sends the signal, which fluctuates according to the LP-EGR control valve opening/closing, to the PCM.
