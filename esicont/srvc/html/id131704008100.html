CAPACITOR (i-ELOOP) RECHARGING [i-ELOOP]

Capacitor Quick Charge

1.  Connect the M-MDS to the DLC-2.

2.  Turn the capacitor quick charge function on using the M-MDS simulation function (simulation item: CHARGE_FLG). (See ACTIVE COMMAND MODES INSPECTION [i-ELOOP].)

3.  Verify the following displays.

Vehicles without center display
•  Verify that the i-ELOOP indicator light (green) in the instrument cluster is flashing.
Vehicles with center display
•  Verify that the i-ELOOP charging is displayed in the center display.

4.  Switch the ignition OFF (LOCK).

5.  Switch the ignition ON (engine off).

6.  Wait until the display verified in procedure 3. disappears.

7.  Turn the capacitor quick charge function (PID: CHARGE_FLG) off using the M-MDS simulation function. (See ACTIVE COMMAND MODES INSPECTION [i-ELOOP].)

8.  Verify that the i-ELOOP operates normally. (See i-ELOOP Operation Verification.)


i-ELOOP Operation Verification

1.  Start the engine. (no electrical load)

2.  Display the DC-DC converter (i-ELOOP) voltage reduction circuit operation status (PID: CONV_STAT) using the M-MDS data monitor function.

Power Output (Normal) is displayed
•  The i-ELOOP operates normally therefore the procedure is completed.
Power Output (Normal) is not displayed
•  Verify if any i-ELOOP related DTC is detected. (See DTC INSPECTION [i-ELOOP].)
―  If DTCs are detected, repair the malfunctioning location according to the applicable DTC troubleshooting. (See DTC TABLE [i-ELOOP].)
―  If a DTC is not detected, verify i-ELOOP operation again after leaving the vehicle as is for approx. 30 min.
