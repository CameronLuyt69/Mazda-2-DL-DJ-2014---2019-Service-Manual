PID/DATA Monitor Inspection

Note
•  The exhaust shutter valve position sensor is built into the exhaust shutter valve actuator. When replacing the exhaust shutter valve position sensor, replace the exhaust shutter valve actuator.

1.  Connect the M-MDS to the DLC-2.

2.  Switch the ignition ON (engine off).

3.  Access the PID/DATA monitor item EXHSHUT_ACT and EXHSHUT_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

4.  Verify that the EXHSHUT_ACT monitor value conforms to the EXHSHUT_DSD monitor value.

•  If the EX_SHUT_VLV_ACT PID does not increase according to the exhaust shutter valve opening angle, inspect the exhaust shutter valve.
(See EXHAUST SHUTTER VALVE INSPECTION [SKYACTIV-D 1.5].)
•  If the EX_SHUT_VLV_ACT PID increases increase linearly according to the exhaust shutter valve opening angle, the exhaust shutter valve is normal.
