ENGINE OIL MAINTENANCE MONITOR [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1687900


Outline

•  Calculates the engine oil replacement period as an appropriate target period for replacing the engine oil.

Block Diagram

am2zzn00003447

Operation

•  The PCM calculates the traveled distance and the number of elapsed days since the engine oil maintenance monitor function was activated, and if the traveled distance and number of elapsed days exceeds the specified value, it determines that engine oil replacement period is reached.
•  When the PCM determines that the engine oil replacement period has been reached, the wrench indicator light illumination request signal is sent to the instrument cluster. (See WRENCH INDICATOR LIGHT [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)
