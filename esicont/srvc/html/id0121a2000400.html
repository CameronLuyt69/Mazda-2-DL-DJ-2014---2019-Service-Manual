SELECT MODE INDICATOR LIGHT [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0121a2000400


Purpose

•  The select mode indicator light notifies the driver that the sport mode has been selected using the drive selection switch, or that switching of the drive selection is not possible.

Function

•  When the sport mode is selected using the drive selection switch, the instrument cluster turns the select mode indicator light on.
•  The instrument cluster flashes the select mode indicator light based on the select mode indicator light flash request signal from the PCM.

Construction

•  Instrument cluster with built-in select mode indicator light have been adopted.
am2zzn00003478

Operation

1.  The instrument cluster receives (1) the select mode indicator light illumination/flashing request signal via CAN communication from the PCM.

2.  The instrument cluster turns the transistor on (2) intermittently for the select mode indicator light flash request signal.

3.  The instrument cluster turns the transistor on (2) continuously for the select mode indicator light llumination request signal.

4.  When the transistor is turned on intermittently, the select mode indicator light flashes (3).

5.  When the transistor is turned on continuously, the select mode indicator light illuminates (3).
