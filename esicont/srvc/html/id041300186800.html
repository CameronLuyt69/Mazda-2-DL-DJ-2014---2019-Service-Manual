CONTROLLER AREA NETWORK (CAN)

id041300186800


Outline

•   The ABS HU/CM sends and receives data to and from other modules via the CAN system. Refer to MULTIPLEX COMMUNICATION SYSTEM for a detailed explanation of the CAN system. (See MULTIPLEX COMMUNICATION SYSTEM.)

Data sent

•  Brake system status
•  ABS system related information
•  Vehicle speed
•  Wheel speed (LF, RF. LR, RR)


Data received

•  Battery charge status
•  Brake switch (No.1 signal)
•  Brake pedal status
•  Car configuration data
•  Ignition switch status
•  Lateral acceleration
•  Longitudinal acceleration
•  Traveled distance
•  Tire circumference
•  Yaw rate
