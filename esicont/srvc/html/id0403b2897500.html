5

ABS or TCS*1 operates frequently

TCS does not work correctly

*1: DSC system function contains traction control function, TCS/DSC indicator light turns on and off while TCS operates
POSSIBLE CAUSE
•  Difference in size or air pressure between front and rear tires.
•  Incorrect ABS wheel-speed signal is input to DSC HU/CM.
•  Malfunction in engine control system. (TCS malfunction)
