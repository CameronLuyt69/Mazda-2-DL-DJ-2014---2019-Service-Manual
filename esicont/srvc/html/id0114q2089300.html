FUEL WARMER INSPECTION [SKYACTIV-D 1.5]

id0114q2089300

1.  Perform the DTC inspection using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

•  If DTC P0182:00 or P0183:00 is detected, repair the malfunctioning location according to the applicable DTC troubleshooting. (See DTC P0182:00 [SKYACTIV-D 1.5].) (See DTC P0183:00 [SKYACTIV-D 1.5].)

2.  Access the FRT PID using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

3.  FRT PID value is less than 5 °C {41 °F}, go to the next step.

4.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

5.  Perform the “Fuel Line Safety Procedure” referring to the “BEFORE SERVICE PRECAUTION”. (See BEFORE SERVICE PRECAUTION [SKYACTIV-D 1.5].)

6.  Remove the fuel warmer. (See FUEL FILTER DISASSEMBLY/ASSEMBLY [SKYACTIV-D 1.5].)

7.  Measure the resistance between the fuel warmer terminals A and B.

Fuel warmer resistance (specification)
Approx. 0.85—1.28 ohms
•  If not within the specification, replace the fuel filter. (See FUEL FILTER REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
