i-ELOOP WARNING LIGHT (AMBER) [i-ELOOP]

id131704500400


Purpose, Function

•  The i-ELOOP warning light (amber) notifies the user that an i-ELOOP-related part is malfunctioning.

Construction

•  The i-ELOOP warning light (amber) is built into the instrument cluster.
am2zzn00003832

Operation

•  When any one of the following conditions is met, the i-ELOOP warning light (amber) turns on.
―  PCM detects DC-DC converter (i-ELOOP) malfunction
―  DC-DC converter (i-ELOOP) detects malfunction in capacitor (i-ELOOP), DC-DC converter (i-ELOOP), or wiring harness
―  DC-DC converter (i-ELOOP) detects any one of the following CAN communication errors
•  Unit communication error (HS-CAN)
•  Communication error with PCM
•  Communication error with RCM
•  Communication error with BCM
•  The DC-DC converter (i-ELOOP) sends an i-ELOOP warning light (amber) on request to the instrument cluster via CAN communication.
•  For vehicles with the center display, a warning message in the center display is displayed when the i-ELOOP warning light (amber) is turned on. For the message content and verification method, refer to the [CENTER DISPLAY]. (See CENTER DISPLAY [WITH CENTER DISPLAY].)
