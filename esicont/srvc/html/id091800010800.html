HEADLIGHT LEVELING SWITCH

id091800010800


Purpose

•  Changes the resistance value according to the position the headlight leveling switch has been changed.

Function

•  The position of the headlight leveling switch can be switched between 11 levels: 0—5.

Construction

•  The headlight leveling switch is integrated with the cluster switch.
am2zzn00001713

Operation

1.  When the headlight leveling switch is turned (1) upward, the resistance value in the switch decreases (2). When the switch is turned (3) downward, the resistance value in the switch increases (4).

2.  The headlight leveling switch applies (5) current to the headlight leveling actuator, which flows according to the position the switch is switched to.
