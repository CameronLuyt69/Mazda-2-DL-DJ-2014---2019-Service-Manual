TIRE PRESSURE MONITORING SYSTEM WARNING ALARM

id021200202800


Purpose

•  The tire pressure monitoring system warning alarm warns the user that a tire pressure has decreased or notifies the user that the tire pressure monitoring alarm has been reset.

Function

•  If the instrument cluster receives a tire pressure monitoring alarm request signal sent from the DSC HU/CM via the CAN signal, the tire pressure monitoring alarm is sounded.
•  The tire pressure monitoring alarm sound pattern is as shown in the figure: For the conditions in which each alarm pattern sounds. (See TIRE PRESSURE MONITORING SYSTEM (TPMS).)

Construction

•  The tire pressure monitoring alarm sounds using the buzzer built into the instrument cluster.

Operation

1.  The instrument cluster receives (1) the tire pressure monitoring alarm request signal from the DSC HU/CM.

2.  The instrument cluster microcomputer turns the transistor on (2) based on the tire pressure monitoring alarm request signal.

3.  When the transistor turns on, the ground circuit of the alarm is established and the alarm sounds (3).
