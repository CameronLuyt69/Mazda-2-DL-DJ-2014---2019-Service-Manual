Operation


Operation conditions

•  When the following operation conditions are met, the BCM activates the running light system.
―  Vehicle speed: 3 km/h {2 mph} or more (vehicle speed signal)
―  Ignition switched ON (engine on) (ignition switch position signal)
―  Parking brake: Released (parking brake switch signal)
―  Selector lever position: Except P position (selector lever position signal) (ATX)
―  Light switch position: OFF or AUTO (auto light system not operated) (light switch signal)


Operation

1.  When the operation conditions are met (1), the BCM sends (2) a running light on request signal to the electrical supply unit (ESU) via LIN communication.

2.  When the electrical supply unit (ESU) receives the running light on request signal, it turns the running lights on (3).
