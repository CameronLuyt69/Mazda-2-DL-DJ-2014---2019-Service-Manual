FRONT POWER WINDOW MOTOR REMOVAL/INSTALLATION

id091200001500

1.  Fully lower the front door glass.

Caution
•  If the front power window motor is removed with the front door glass fully closed, the front door glass may fall off and be damaged.
Note
•  If the front door glass cannot be fully opened by operating the power window main switch or the power window subswitch, remove the front power window motor while inserting your hand through the front door speaker installation hole to support the front door glass.

2.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

3.  Remove the following parts:

(1)  Power window main switch (driver-side) (See POWER WINDOW MAIN SWITCH REMOVAL/INSTALLATION.)
(2)  Power window subswitch (passenger-side) (See POWER WINDOW SUBSWITCH REMOVAL/INSTALLATION.)
(3)  Front door trim (See FRONT DOOR TRIM REMOVAL/INSTALLATION.)
(4)  Front door speaker (See FRONT DOOR SPEAKER REMOVAL/INSTALLATION.)

4.  Disconnect the connector.

am2zzw00008039

5.  Remove the bolt.

6.  Remove the front power window motor.

7.  Install in the reverse order of removal. (See Front Power Window Motor Installation Note.)


Front Power Window Motor Installation Note

•  If the front power window motor is installed without securing the front power window regulator drum housing, the drum housing may detach from the front door module panel and the front power window motor may not install correctly. When installing the front power window motor, insert your hand through the front door speaker installation hole and secure the drum housing so that the clip shown in the figure does not detach.

•  When installing the front power window motor installation bolts, tighten the bolts in the order shown in the figure.
