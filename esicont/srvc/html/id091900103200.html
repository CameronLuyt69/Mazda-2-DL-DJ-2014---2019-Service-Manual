WIPER/WASHER SYSTEM PERSONALIZATION

id091900103200

Caution
•  The personalization feature may not be set correctly if [Not equipped] is selected in the setting displayed on the Mazda Modular Diagnostic System (M-MDS). Do not select [Not equipped] in the setting displayed on the Mazda modular diagnostic system (M-MDS).
Note
•  Settings of some personalization features displayed on the Mazda Modular Diagnostic System (M-MDS) cannot be changed depending on the vehicle specification.
•  A personalization feature has been adopted with which settings for the auto wiper system can be changed.
•  The auto wiper system personalization settings can be changed using the Mazda Modular Diagnostic System (M-MDS) or the center display (with center display). Refer to the [WIPER/WASHER SYSTEM PERSONALIZATION FEATURES SETTING PROCEDURE] in the workshop manual for the detailed setting procedure.
