DTC P0218:00

Automatic transaxle protection control
DETECTION CONDITION
•  Under the following conditions, the ATF temperature is 135 °C {275 °F} or more for 10 s:
―  Engine is running.
―  TFT sensor related DTC is not recorded.
FAIL-SAFE FUNCTION
•  Inhibits learning control.
•  Inhibits manual mode.
•  Inhibits i-stop control.
•  Inhibits AAS.
POSSIBLE CAUSE
•  Oil cooler malfunction
•  ATF is more than specified value
SYSTEM WIRING DIAGRAM
Not applicable
