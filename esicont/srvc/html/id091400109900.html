COIL ANTENNA

id091400109900


Purpose, Function

•  Sends the ID data programmed to the electronic transmission device (transponder) in the remote transmitter to the start stop unit.

Construction, Operation

•  The coil antenna built into the push button start sends a signal to the transponder and sends the returned signal to the start stop unit.
