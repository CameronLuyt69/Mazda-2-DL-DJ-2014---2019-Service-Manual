DOOR LOCK SYSTEM OPERATION RECORD

id091400005000


Purpose

•  Stores the record of the user's operation and the door lock system operation corresponding to the user's operation.

Function

•  The door lock system operation record is stored by the BCM and displayed using the Mazda Modular Diagnostic System (M-MDS).
•  The BCM stores the following when the front/rear door lock actuator operates.
―  Time and date
―  Part or function which output unlock signal
―  Part or function which output lock signal
―  Operated actuator
―  Vehicle condition

Construction

•  Based on the stored record, the BCM displays the following operation record on the M-MDS screen.
am2zzn00001672

Operation

•  Based on the lock/unlock signal, the BCM sends an operation signal to the front/rear door lock actuator motor, and stores the operation record at the same time.
•  Because it takes time from when the front/rear door lock actuator motor operates until the lock/unlock is switched, the BCM may store the operation record before the lock/unlock switching is completed.

Fail-safe

•  Not applicable
