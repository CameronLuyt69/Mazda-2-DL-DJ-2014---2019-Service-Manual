Note
•  The fuel injector codes are printed on the upper surface of the fuel injector. Read the fuel injector codes in the order shown in the figure.
am2zzw00011373

1.  Connect the M-MDS to the DLC-2.

2.  After the vehicle is identified, select the following item from the initial screen of the M-MDS.

(1)  Select the “Module Programming”.

3.  Then, select the items from the screen menu in the following order.

(1)  Select the “Programmable Parameters”.
(2)  Select the “Injector Correction Factors”.
(3)  Select the “Program”.

4.  Perform the procedure according to the directions on the screen.
