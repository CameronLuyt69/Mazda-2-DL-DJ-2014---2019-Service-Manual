ROOM LIGHT CONTROL SYSTEM

id091800012300


Outline

•  The room light control system changes the illumination condition and illumination level of the interior lights (door position) according to whether the doors are opened/closed and locked/unlocked.

Function

•  The BCM changes the illumination condition of the map light and trunk compartment light (4SD)/cargo compartment light (5HB) and illumination level of the map light based on the following signals:
