PANEL LIGHT

id092200033000


Purpose

•  The panel light adjusts the brightness of the instrument cluster and steering switch illumination.

Function

•  The instrument cluster adjusts the brightness of the following illumination lights when it receives a TNS signal sent via CAN communication from the BCM.
―  Instrument cluster
―  Climate control unit
―  Steering switch
―  Cluster switch
―  Hazard warning switch
―  Shift panel (indicator)
―  Drive selection switch (With drive selection system)
―  Indicator unit
―  Audio unit (Without center display)
―  CD player (With CD player)
―  DVD/CD player (With DVD/CD player)
―  Commander switch (With center display)
•  The instrument cluster changes the brightness of the illumination lights according to the rotation signal of the panel light control switch.

Construction

•  The panel light control switch is positioned in the instrument cluster.
am2zzn00002935

Operation

1.  When the ignition is switched ON (engine off or on), the instrument cluster receives (1) a TNS signal from the BCM.
2.  The instrument cluster performs the following controls when it receives the TNS signal.
―  Changes (2) the brightness of the instrument cluster illumination.
―  Outputs (2) a panel light on request signal to the climate control unit via CAN communication.
―  Outputs (2) a panel light on request signal to the indicator unit via serial communication.
―  Turns (2) the panel light circuit transistor on.
3.  When the transistor turns on, a ground circuit with the panel light is established and the panel light turns on (3).
am2zzn00002936

Panel light control switch operation

1.  When the ignition is switched ON (engine off or on), the instrument cluster receives (1) a TNS signal from the BCM.
2.  When the instrument cluster detects (2) a panel light control switch rotation signal while receiving the TNS signal, it changes (3) the brightness of the panel light according to the rotation angle.
3.  The instrument cluster outputs (4) a panel light on request signal to the related modules.
4.  If the instrument cluster detects (2) that the panel light control switch is in the maximum right rotation position, it maximizes (5) the brightness of the panel light, and sends (6) a dimmer cancel signal to the related module.
