DTC U0074:00

CAN system communication error (local CAN between PCM and TCM)
DETECTION CONDITION
•  With the following conditions met, a CAN bus communication line error is continued for 1 s or more.
MONITORING CONDITIONS
―  Battery voltage: 10 V or more
―  1.5 s have elapsed after the ignition was switched ON (engine off or on)
Diagnostic support note
•  This is an intermittent monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA/Snapshot data is not available.
•  DTC is not stored in the PCM memory.
FAIL-SAFE FUNCTION
Not applicable
POSSIBLE CAUSE
•  CAN communication line malfunction between PCM and TCM (local CAN between PCM and TCM)
―  TCM terminal G—PCM terminal 1G
―  TCM terminal H—PCM terminal 1C
•  TCM DTC is stored.
•  PCM malfunction
•  TCM malfunction
