DTC C0023:62/C0040:64 [DSC HU/CM]

id040262906400

DTC
C0023:62
Brake switch
C0040:64
DETECTION CONDITION
•  C0023:62
―  Brake light ON signal is not input even though the brake light request signal is input
―  Brake light ON signal is input even though the brake light request signal is not input
―  Brake light request signal is not input even though the brake fluid pressure sensor signal reaches the specified value
―  Brake light request signal is input even though the brake fluid pressure sensor signal does not reach the specified value
―  Communication error with brake light is detected in CAN communication via Body Control Module (BCM)
•  C0040:64
―  Brake switch ON signal is input for 6 min or more when driving at a vehicle speed of 20 km/h {12 mph} or more
―  A brake switch ON signal is not input when the brake fluid pressure sensor signal reaches the specified value
FAIL-SAFE FUNCTION
Refer to DTC TABLE. (See DTC TABLE [DSC HU/CM].)
POSSIBLE CAUSE
•  Open or short to GND circuit in wiring harness between IG1 relay and DSC HU/CM terminal Q
•  Open or short to power supply circuit in wiring harness between brake switch terminal D and PCM terminal 2G (SKYACTIV-G 1.3, SKYACTIV-G 1.5)
•  Open or short to power supply circuit in wiring harness between brake switch terminal D and PCM terminal 2AA (SKYACTIV-D 1.5)
•  Brake switch malfunction
•  Body Control Module (BCM) malfunction (brake light circuit)
•  PCM malfunction
•  Poor connection at each connector
