SAS control module
DETECTION CONDITION
•  Communication error to SAS control module is detected in CAN communication
FAIL-SAFE FUNCTION
Refer to DTC TABLE. (See DTC TABLE [ABS HU/CM].)
POSSIBLE CAUSE
•  Poor SAS control module installation
•  Low-G sensor malfunction in SAS control module
