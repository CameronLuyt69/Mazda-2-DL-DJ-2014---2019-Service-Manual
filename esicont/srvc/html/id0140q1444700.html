European Specs.

Note
•  If the engine oil was replaced with the engine oil maintenance monitor function ON, perform the engine oil data reset to reset the engine oil replacement period calculation data recorded in the PCM regardless of whether or not the wrench indicator light is illuminated.
•  The ON/OFF condition of the engine oil maintenance monitor function can be verified using the M-MDS. (See MAINTENANCE MONITOR OPERATION PROCEDURE.)
