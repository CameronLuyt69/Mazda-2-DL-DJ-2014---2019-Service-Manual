MASS AIR FLOW (MAF) SENSOR/INTAKE AIR TEMPERATURE (IAT) SENSOR NO.1 REMOVAL/INSTALLATION [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0140q1900300

Note
•  Because the IAT sensor No.1 is integrated in the MAF sensor, replacing the IAT sensor No.1 includes replacement of the MAF sensor/IAT sensor No.1.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Disconnect the MAF sensor/IAT sensor No.1 connector.

am2zzw00011943

3.  Remove the screws.

4.  Remove the MAF sensor/IAT sensor No.1.

5.  Install in the reverse order of removal.
