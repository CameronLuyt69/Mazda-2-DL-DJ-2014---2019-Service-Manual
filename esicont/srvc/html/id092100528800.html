FUSE BLOCK

id092100528800


Purpose

•  Fuses used by each system are grouped and housed together for smooth inspection and replacement servicing.

Function

•  Fuses used by each system are grouped and housed together.

Construction

•  The fuse block is located inside the front side trim (LH).
am2zzn00001942

Operation


Fuse operation

1.  If electric current of the specified value or more flow to a fuse, the fuse blows due to heat generation.

2.  The current between the fuse and ground is interrupted.


Fail-safe

•  Not applicable
