AUTO LEVELING SENSOR

id091800011100


Purpose

•  The auto leveling sensor detects the vehicle height and outputs it to the auto leveling control module.

Function

•  The auto leveling sensor changes the detected vehicle height into a voltage value and outputs it to the auto leveling control module.

Construction

•  The auto leveling sensor is located on the rear shock absorber and rear side frame.
•  The auto leveling sensor consists of link No. 1, link No.2, and the Hall sensor.
am2zzn00001720

Operation

1.  If the rear crossmember slumps under a load and passengers, the auto leveling sensor link changes.

2.  The auto leveling sensor changes the voltage value according to the angles of the links and outputs to the auto leveling control module.
