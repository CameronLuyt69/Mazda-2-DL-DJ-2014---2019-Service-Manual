CHARGING SYSTEM WARNING LIGHT [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0117q7308400


Purpose, Function

•  The charging system warning light warns the driver of a charging system malfunction.
―  For details on DTCs which illuminate the charging system warning light, refer to ON-BOARD DIAGNOSTIC SYSTEM. (See ON-BOARD DIAGNOSTIC SYSTEM TEST MODE [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)

Construction

•  The charging system warning light is built into the instrument cluster. (See INSTRUMENT CLUSTER.)
am2zzn00003863

Operation

•  Illuminates when a malfunction occurs in the charging system and a DTC is stored in the PCM.
•  For vehicles with center display, a warning message in the center display is displayed when the charging system warning light is turned on. For the message content and verification method, refer to the CENTER DISPLAY. (See CENTER DISPLAY [WITH CENTER DISPLAY].)
