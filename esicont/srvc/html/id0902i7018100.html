DTC U3000:42 [HEADLIGHT AUTO LEVELING SYSTEM]

id0902i7018100

Description

Auto leveling control module internal malfunction
Detection condition
•  Auto leveling control module detects the internal EEPROM malfunction.
Fail-safe
•  The headlight leveling actuator is stopped at the position when the malfunction is determined.
Possible cause
•  Auto leveling control module internal malfunction
System wiring diagram
Not applicable

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY IF MALFUNCTIONING LOCATION IS AUTO LEVELING CONTROL MODULE DEPENDING ON REPEATABILITY
•  Clear the DTC for the auto leveling control module using the M-MDS.
(See CLEARING DTC [HEADLIGHT AUTO LEVELING SYSTEM].)
•  Retrieve the auto leveling control module DTCs using the M-MDS.
(See DTC INSPECTION [HEADLIGHT AUTO LEVELING SYSTEM].)
•  Is the same DTC displayed?
Yes
Replace the auto leveling control module, then go to the next step.
(See AUTO LEVELING CONTROL MODULE REMOVAL/INSTALLATION.)
No
Go to the next step.
2
VERIFY IF OTHER DTCs DISPLAYED
•  Are any other DTCs displayed?
Yes
Repair or replace the malfunctioning part according to the applicable DTC troubleshooting.
(See DTC TABLE [HEADLIGHT AUTO LEVELING SYSTEM].)
No
DTC troubleshooting completed.
