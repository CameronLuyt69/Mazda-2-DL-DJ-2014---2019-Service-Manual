Piston Rod Nut Removal Note

Warning
•  When removing the piston rod nut, if the piston rod nut is removed before compressing the coil spring, the coil spring may fly off, which may cause serious injury or death, or vehicle damage. Set the front shock absorber and the coil spring to the SST first, then remove the piston rod nut.

1.  Install the front shock absorber and coil spring to the SST according to the following procedures.

Caution
•  The coil spring may be damaged when installing the SST to the coil spring. Install the SST to the coil spring using a rag so that the coil spring is not damaged.
(1)  Set the SST attachments (tabs) to the positions shown in the figure.
