MANIFOLD ABSOLUTE PRESSURE (MAP) SENSOR/INTAKE AIR TEMPERATURE (IAT) SENSOR NO.2 REMOVAL/INSTALLATION [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

Note
•  Because the IAT sensor No.2 is integrated in the MAP sensor, replacing the IAT sensor No.2 includes replacement of the MAP sensor/IAT sensor No.2.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Disconnect the MAP sensor/IAT sensor No.2 connector.

am2zzw00011944

3.  Remove the screw.

4.  Remove the MAP sensor/IAT sensor No.2.

5.  Install in the reverse order of removal.
