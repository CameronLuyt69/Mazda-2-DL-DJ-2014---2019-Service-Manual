Voltage Inspection

Note
•  The HP-EGR control valve position sensor is built into the HP-EGR control valve. When replacing the HP-EGR control valve position sensor, replace the HP-EGR control valve.

1.  Switch the ignition ON (engine off).

2.  Measure the voltage at the HP-EGR control valve terminal D.

am2zzw00011406

•  If the voltage is within the specification, go to the next step.
•  If the voltage is not within the specification, replace the HP-EGR control valve. (See HP-EGR CONTROL VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
Specification
1.05—1.35 V

3.  Connect the M-MDS to the DLC-2.

4.  Access the PID/DATA monitor item HPEGR_ACT and simulation item HPEGR_DSD using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

5.  Verify that the HPEGR_ACT monitor value conforms to the HPEGR_DSD monitor value when the simulation item HPEGR_DSD is set from 0 % to 80 %.

•  If not as verified, replace the HP-EGR control valve. (See HP-EGR CONTROL VALVE REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
