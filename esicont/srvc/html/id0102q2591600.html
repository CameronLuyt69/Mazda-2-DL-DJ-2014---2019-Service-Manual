DTC U0599:00

Invalid data received from DC-DC converter
DETECTION CONDITION
•  Invalid data is received from DC-DC converter.
Diagnostic support note
•  This is a continuous monitor (CCM).
•  The check engine light illuminates if the PCM detects the above malfunction condition during the first drive cycle.
FAIL-SAFE FUNCTION
•  The engine speed is fixed idle speed to prevent over current is generated by generator.
POSSIBLE CAUSE
•  DC-DC detects DTC via diagnosis function.
SYSTEM WIRING DIAGRAM
Not applicable
