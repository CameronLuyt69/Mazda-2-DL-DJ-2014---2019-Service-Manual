Evaporator temperature sensor assembly note

1.  Assemble the evaporator temperature sensor as shown in the figure.

am2zzw00009583

Caution
•  If the evaporator temperature sensor is assembled to its previous installation position, it may not function due to poor contact of the evaporator fin surface with the sensor detection area caused by fin deformation. When replacing only the evaporator sensor, shift the evaporator temperature sensor installation position from the current position and assemble.
Note
•   If an evaporator temperature sensor cannot be correctly positioned on the evaporator, replace the evaporator.
