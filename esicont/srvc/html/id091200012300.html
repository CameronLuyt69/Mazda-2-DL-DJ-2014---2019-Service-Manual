POWER WINDOW MAIN SWITCH

id091200012300


Purpose

•  Transmits the power window main switch operation of the driver to the power window control module.

Function


Manual

•  When the power window main switch is operated for manual open/close operation, it sends a manual open/close signal to the power window control module.


Auto

•  When the power window main switch is operated for auto open/close operation, it sends an auto open/close signal to the power window control module.


Power cut

•  When the power-cut switch is on (contact point: Open), the open/close operation of the front passenger seat and rear seat windows is disabled.


Construction

•  The power window main switch consists of the following parts:
―  Driver's side switch
―  Passenger's side switch
―  Rear side switch (LR)
―  Rear side switch (RR)
―  Power cut switch

Operation


Power window main switch operation

•  Contact points for door glass opening/closing can be changed by operating the power window main switch.
am2zzn00001980


Power-cut switch operation

•  When the power-cut switch of the power window main switch is on (contact point: Open), current from each power window subswitch is interrupted.
