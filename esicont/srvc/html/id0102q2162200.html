DTC STORE RECORD [SKYACTIV-D 1.5]

id0102q2162200


Purpose

•  When an engine control malfunction is detected, the PCM stores a DTC.
For the DTC store record, the DTC recorded by the PCM can be displayed in chronological order using the Mazda Modular Diagnostic System (M-MDS), and it can be used during malfunction diagnosis when several DTCs are recorded.

Function/display

•  The PCM stores the following information as the DTC storage record.
―  DTC
―  DTC type (CMDTC/pending code)
―  Odometer value
•  The Mazda Modular Diagnostic System (M-MDS) reads out the DTC storage record and indicates it as shown in the figure below.
