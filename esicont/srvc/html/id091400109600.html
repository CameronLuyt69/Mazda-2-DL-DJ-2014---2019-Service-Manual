REQUEST SWITCH

id091400109600


Purpose

•  Transmits the request switch operation of the user to the LF control unit.

Function

•  The request switch ON signal is sent to the LF control unit by operating the request switch.

Construction/Operation

•  The request switch is located on the outer handle of the driver's/passenger's front door.
•  While the request switch is pressed, the switch turns on (contact point: closed).
