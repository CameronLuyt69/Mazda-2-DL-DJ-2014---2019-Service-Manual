PID/DATA MONITOR INSPECTION (i-stop) [SKYACTIV-D 1.5]

id1102b0000100

Note
•  PIDs related to i-stop can be displayed in a list using the M-MDS data monitor diagnostic function.
•  If the engine is stopped by the i-stop control while the following data monitor items on the M-MDS are being viewed, the data monitor items may no longer be displayed.
―  BRAKE_SW
―  BRK_F_P_C
―  LON_ACCL_C
―  WSPD_SEN_LF
―  WSPD_SEN_RF
―  WSPD_SEN_LR
―  WSPD_SEN_RR

1.  Connect the M-MDS to the DLC-2.

2.  After vehicle identification is completed, select the following from the M-MDS initial screen.

(1)  [Data logger]
(2)  [Powertrain]
(3)  [i-stop]

3.  Select the applicable item from the PID/DATA Monitor Table.

4.  Verify the monitored value according to the directions on the screen.
