DOOR SASH FILM INSTALLATION

id091600805300


Front door sash film installation

1.  Remove any grease or dirt from the adhesion surface of the front door.

2.  Peel off the backing of the door sash film and install the door sash film to the position shown in the figure.

am2uuw00001370

Standard clearance
a: -0.5—0.5 mm {-0.01—0.01 in}
b: 2.0 mm {0.079 in} or less
c: 3.0 mm {0.12 in} or less
d: 3.0—5.0 mm {0.12—0.19 in}
Caution
•  The removed glass run channel cannot be reused.

3.  Install the glass run channel.

4.  Install the following parts:

(1)  Front door glass (See FRONT POWER WINDOW MOTOR REMOVAL/INSTALLATION)
(2)  Front door speaker (See FRONT DOOR SPEAKER REMOVAL/INSTALLATION)
(3)  Front door trim (See FRONT DOOR TRIM REMOVAL/INSTALLATION)
(4)  Power window main switch (driver-side) (See POWER WINDOW MAIN SWITCH REMOVAL/INSTALLATION)
(5)  Power window subswitch (passenger-side) (See POWER WINDOW SUBSWITCH REMOVAL/INSTALLATION)
(6)  Front beltline molding (See FRONT BELTLINE MOLDING REMOVAL/INSTALLATION)
(7)  Sail garnish (See SAIL GARNISH REMOVAL/INSTALLATION)
