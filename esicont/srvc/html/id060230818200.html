DTC
U0001:88
CAN communication: module communication error
U0100:00
CAN communication: communication error to PCM
U0121:00
CAN communication: communication error to DSC HU/CM
U0155:00
CAN communication: communication error to instrument cluster
U0214:00
CAN communication: communication error to start stop unit
DETECTION CONDITION
•  U0001:88
―  Error detected in CAN bus communication line with CAN connection modules
•  U0100:00
―  Communication error to PCM is detected in CAN communication
•  U0121:00
―  Communication error to DSC HU/CM is detected in CAN communication
•  U0155:00
―  Communication error to instrument cluster is detected in CAN communication
•  U0214:00
―  Communication error to start stop unit is detected in CAN communication
FAIL-SAFE FUNCTION
•  U0001:88
―  Power steering malfunction indicator light does not Illuminate
―  EPS motor current control enabled
•  U0100:00
―  Power steering malfunction indicator light Illuminates
―  EPS motor current control is maintained by gradually changing the controlled vehicle speed and setting it to specified speed
•  U0121:00, U0155:00, U0214:00
―  Power steering malfunction indicator light does not Illuminate
―  EPS motor current control enabled
POSSIBLE CAUSE
•  CAN communication line malfunction
•  CAN communication line malfunction with PCM
•  CAN communication line malfunction with DSC HU/CM
•  CAN communication line malfunction with instrument cluster
•  CAN communication line malfunction with start stop unit
•  Poor connection at each connector
