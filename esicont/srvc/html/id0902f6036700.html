DTC: 30:Er01 [AUDIO]

id0902f6036700

Description

CD player mechanism malfunction
Detection condition
CD player mechanism malfunction detected.
Fail-safe
Not applicable
Possible cause
•  Disc malfunction or malfunction due to customer use method
―  CD insertion direction mistaken
―  CD scratching or soiling
―  Incompatible CD used
•  CD player malfunction
System wiring diagram
Not applicable
