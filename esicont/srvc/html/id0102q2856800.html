DTC P1260:00

Immobilizer system problem
DETECTION CONDITION
•  The start stop unit detects an immobilizer system malfunction.
Diagnostic support note
•  This is an intermittent monitor (other).
•  The check engine light does not illuminate.
•  FREEZE FRAME DATA/Snapshot data is not available.
•  DTC is not stored in the PCM memory.
FAIL-SAFE FUNCTION
Not applicable
POSSIBLE CAUSE
•  Immobilizer system malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable
