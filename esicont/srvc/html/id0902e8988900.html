DTC U0402:68 [INSTRUMENT CLUSTER]

id0902e8988900

Description

Error signal received from transmission/transaxle
Detection condition
•  Instrument cluster received the error signals from the transmission/transaxle for 1 s or more with the ignition switched ON (engine off or on).
Fail-safe
Not applicable
Possible cause
•  The transaxle could not send a normal signal temporarily. (DTCs are stored in the TCM.)
•  TCM malfunction
•  Instrument cluster malfunction
System wiring diagram
Not applicable
