SPEED SENSOR ASSY (TURBOCHARGER WITH VARIABLE TURBINE GEOMETRY) INSPECTION [SKYACTIV-D 1.5]

id0140q2497900

Note
•  The speed sensor assy of the turbocharger with variable turbine geometry is built into the turbocharger with variable turbine geometry. When replacing the speed sensor assy of the turbocharger with variable turbine geometry, replace the turbocharger with variable turbine geometry itself. (European (L.H.D.) Specs.)

1.  Connect the M-MDS to the DLC-2.

2.  Start the engine and warm up the engine.

3.  Access the PID/DATA monitor item APP1 and VGTURB_RPM using the M-MDS. (See ON-BOARD DIAGNOSTIC TEST [SKYACTIV-D 1.5].)

4.  While gradually depressing the accelerator pedal, verify that PID VGTURB_RPM value increases following the APP1 value.

•  If not as verified, replace the speed sensor assy (turbocharger with variable turbine geometry). (See SPEED SENSOR ASSY (TURBOCHARGER WITH VARIABLE TURBINE GEOMETRY) REMOVAL/INSTALLATION [SKYACTIV-D 1.5].)
