CHARGING SYSTEM WARNING LIGHT ILLUMINATED/MESSAGE RELATED TO CHARGING SYSTEM MALFUNCTION INDICATED IN DISPLAY
DESCRIPTION
•  Charging system warning light illuminated.
•  Message related to charging system malfunction indicated in display.
POSSIBLE CAUSE
•  i-ELOOP system malfunction (with i-ELOOP)
•  Erratic signal to PCM
―  Generator or related circuit malfunction
•  Battery malfunction
•  Generator malfunction
•  Instrument cluster malfunction
