PUSH BUTTON START SYSTEM [KEYLESS ENTRY SYSTEM]

id0914001116b3


Outline

•  A push button start system has been adopted that automatically performs authorization of the remote transmitter being brought within the request signal output range of the keyless antennas.
•  If the engine stalls due to incorrect operation of the clutch by the driver, an engine restarting by depressing clutch pedal function has been adopted to allow the engine to be restarted by only depressing the clutch pedal.(MTX)

Function

•  When the bush button start is pressed, the push button start system performs authorization of the remote transmitter in the vehicle.
―  Engine start: When authorization of the remote transmitter is completed with the engine-start conditions met, the engine is started.
•  The guidance function is indicated by the KEY warning light (red) and the keyless warning alarm if there are insufficient conditions for starting the engine, remote transmitter authorization issues, or the steering lock cannot be released.

Engine restarting function by depressing clutch pedal

•  If the start stop unit determines that the driver intends to restart the engine because the engine has stalled, the engine restarting by depressing clutch pedal function restarts the engine.
•  The start stop unit determines that the driver is seated based on the conditions that the driver's seat belt is fastened and the driver's door is closed, and it determines that the driver intends to restart the engine when the clutch pedal is depressed from a released condition within 3 s after the engine stalls.

Operation


Remote transmitter authorization

1.  When the push button start is pressed, a push button start signal is input (1) to the start stop unit.

2.  When the start stop unit detects a push button start signal, it outputs (2) a request signal via the keyless antennas.

3.  The remote transmitter receives the request signal from the keyless antennas, and sends (3) ID data to the keyless receiver.

4.  The keyless receiver transmits (4) the received ID data to the start stop unit.

5.  The start stop unit verifies the ID data and if it matches, the steering lock in the module is released (5) and the power supply is switched simultaneously to turn the push button start indicator light (amber) on. For details on the power supply switching, refer to the [POWER SUPPLY SWITCHING]. (See POWER SUPPLY SWITCHING.)

Engine start

•  When the push button start is pressed with all the following conditions met, authorization of the remote transmitter is performed to start the engine.
Engine start conditions
―  Clutch pedal position switch and starter interlock switch on signals (clutch pedal depressed) detected (MTX)
―  Brake light switch on signal (brake pedal depressed) detected (ATX)
―  P or N position signal from selector lever (selector lever at P or N position) received (ATX)
―  Remote transmitter is within request signal output range of keyless antennas in vehicle interior


Engine emergency stop

•  If a push button start on signal is input for 3 s or more (ignition switch held pressed) or 3 times within 1.5 s with the engine running, the start stop unit switches the ignition to ACC or OFF according to the position of the shift lever (MTX)/selector lever (ATX).


Back-up mode (MTX) for engine-start

•  If the start stop unit determines that either the clutch pedal position switch or starter interlock switch is malfunctioning, the system switches to back-up mode.
•  If the push button start is pressed when all the following conditions are met while in the back-up mode, the remote transmitter authorization is performed and the engine starts.
―  Start stop unit detects that either clutch pedal position switch or starter interlock switch is on
―  Neutral switch signal is received via CAN communication from PCM
―  Remote transmitter is within request signal output range of keyless antennas in vehicle interior


Engine restarting function by depressing clutch pedal

1.  The start stop unit enables the engine restarting by depressing clutch pedal function operation when all of the following conditions are met.
―  Within 3 s after engine-stall signal is received via CAN communication from PCM (1)
―  Driver buckle switch off signal (seat belt fastened) is received via CAN communication from SAS control module (2)
―  Driver door latch off signal (door closed) is received via ISO communication from BCM (3)
2.  If all of the following are detected, the start stop unit sends an engine starting enabled signal (3) to the PCM via CAN communication and restarts the engine.
―  Clutch pedal position switch off to on detected (1)
―  Starter interlock switch off to on detected (2)
