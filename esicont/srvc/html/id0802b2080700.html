Inspection for DTCs not usually displayed so the related function is not equipped


Diagnostic procedure

Step

Inspection

Action
1
INSPECT FOR ANY DTC DISPLAYED SIMULTANEOUSLY
•  Is any DTC not within [ ] in the DTC table displayed simultaneously?
Yes
Repair the malfunctioning part according to the applicable DTC troubleshooting. (See DTC TABLE [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
No
Go to the next step.
2
VERIFY IF MALFUNCTION CAUSED BY TEMPORARY MALFUNCTION IN SAS CONTROL MODULE
•  Clear the DTC for the SAS control module using the M-MDS. (See CLEARING DTC [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
•  Perform the DTC inspection for the SAS control module using the M-MDS. (See DTC INSPECTION [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
•  Are the same DTCs displayed?
Yes
Go to the next step.
No
DTC troubleshooting completed.
3
VERIFY IF MALFUNCTION CAUSED BY CONFIGURATION ERROR
•  Perform the SAS control module configuration using the M-MDS. (See SAS CONTROL MODULE CONFIGURATION (USING AS-BUILT DATA) [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
•  Clear the DTC for the SAS control module using the M-MDS. (See CLEARING DTC [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
•  Perform the DTC inspection for the SAS control module using the M-MDS. (See DTC INSPECTION [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
•  Are the same DTCs displayed?
Yes
Re-perform the configuration, then perform the DTC inspection.
•  If the same DTC is displayed, replace the SAS control module. (See SAS CONTROL MODULE REMOVAL/INSTALLATION [TWO-STEP DEPLOYMENT CONTROL SYSTEM].)
No
DTC troubleshooting completed.
