DOOR GLASS OTHER THAN DRIVER'S DOOR CANNOT BE OPERATED (CANNOT BE OPERATED USING POWER WINDOW MAIN SWITCH BUT CAN BE OPERATED USING EACH SUBSWITCH) [POWER WINDOW SYSTEM]

id0903a0433700

Description
Door glass other than driver's door can be operated using subswitches but cannot be operated using power window main switch
Possible Causes
•  Power window main switch malfunction
•  Short to ground in wiring harness between the following terminals:
―  Power window main switch terminal 1D (L.H.D.)/1J (R.H.D.) and power window subswitch (RF) terminal E
―  Power window main switch terminal 1B (L.H.D.)/1D (R.H.D.) and power window subswitch (RF) terminal B
―  Power window main switch terminal 1I and power window subswitch (LR) terminal E
―  Power window main switch terminal 1G and power window subswitch (LR) terminal B
―  Power window main switch terminal 1C and power window subswitch (RR) terminal E
―  Power window main switch terminal 1A and power window subswitch (RR) terminal B
•  Open circuit in wiring harness between the following terminals:
―  Power window main switch terminal 1D (L.H.D.)/1J (R.H.D.) and power window subswitch (RF) terminal E
―  Power window main switch terminal 1B (L.H.D.)/1D (R.H.D.) and power window subswitch (RF) terminal B
―  Power window main switch terminal 1I and power window subswitch (LR) terminal E
―  Power window main switch terminal 1G and power window subswitch (LR) terminal B
―  Power window main switch terminal 1C and power window subswitch (RR) terminal E
―  Power window main switch terminal 1A and power window subswitch (RR) terminal B
•  Connector poor contact or terminal damage

POWER WINDOW MAIN SWITCH INSPECTION
•  Reconnect all the disconnected connectors.
•  Connect the negative battery cable.
(See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)
•  Measure the voltage at the following power window main switch terminals (vehicle wiring harness).
(See POWER WINDOW MAIN SWITCH INSPECTION.)
―  Terminals 1B (L.H.D.)/1D (R.H.D.) and 1D (L.H.D.)/1J (R.H.D.) if door glass (RF) does not operate
―  Terminals 1G and 1I if door glass (LR) does not operate
―  Terminals 1A and 1C if door glass (RR) does not operate
•  Is the power window main switch normal?
Yes
Refer to the wiring diagram and verify if there is a common connector between the following terminals.
•  Power window main switch terminal 1D (L.H.D.)/1J (R.H.D.) and power window subswitch (RF) terminal E
•  Power window main switch terminal 1B (L.H.D.)/1D (R.H.D.) and power window subswitch (RF) terminal B
•  Power window main switch terminal 1I and power window subswitch (LR) terminal E
•  Power window main switch terminal 1G and power window subswitch (LR) terminal B
•  Power window main switch terminal 1C and power window subswitch (RR) terminal E
•  Power window main switch terminal 1A and power window subswitch (RR) terminal B
If there is a common connector:
•  Inspect the common connector and terminals for corrosion, damage, or disconnection and the common wiring harnesses for an open or short circuit to determine the malfunctioning location.
•  Repair or replace the malfunctioning location.
If there is no common connector:
•  Repair or replace the wiring harness which has an open or short circuit.
Go to the next step.
No
Replace the power window main switch, then go to the next step.
(See POWER WINDOW MAIN SWITCH REMOVAL/INSTALLATION.)
