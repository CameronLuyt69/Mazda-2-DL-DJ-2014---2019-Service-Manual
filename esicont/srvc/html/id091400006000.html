PUSH BUTTON START

id091400006000


Purpose

•  By pressing the switch ON/OFF, the push button start notifies the start stop unit of the driver power supply switching operation.

Function


Push button start indicator light

•  If the push button start indicator light detects the engine switch condition, a malfunction, or the steering lock cannot be released, it indicates the driver by turning on/flashing the light.


START/STOP/ENGINE indicator light

•  The push button start turns on the characters to improve visibility of the button.


Construction

•  The push button start is located on the meter hood.
•  Two types of switches are integrated in the push button start.
•  The push button start has the following integrated indicators. Operation

•  When the push button start is pressed, switches 1 and 2 turn on (contact point: closed), and when released, it turns off (contact point: open).

Push button start indicator light

Green illumination
•  Illuminates if the conditions necessary for engine-start are met.
Green flashing
•  Flashes when the steering lock cannot be released.
Amber illumination
•  Turns on when the ignition is switched ON (engine off) or to ACC.
Amber flashing
•  Flashes when a malfunction is detected.

START/STOP/ENGINE indicator light

•  When a door is open/closed, the START/STOP/ENGINE indicator light turns on when the headlights are turned on.
