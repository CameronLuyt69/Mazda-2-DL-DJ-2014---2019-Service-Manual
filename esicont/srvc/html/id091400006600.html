BONNET RELEASE LEVER AND RELEASE CABLE REMOVAL/INSTALLATION

id091400006600


Bonnet Release Lever

1.  While pulling the bonnet release lever, insert a tape-wrapped flathead screwdriver into the position shown in the figure.

am2zzw00007793

2.  Move the tape-wrapped flathead screwdriver in the direction of arrow (1) shown in the figure to press the tab, and pull the bonnet release cable in the direction of arrow (2) to detach the bonnet release lever from the driver's side lower panel.

Caution
•  Remove the bonnet release lever while being careful not to damage the bonnet release cable with the flathead screwdriver.

3.  Pull the bonnet release lever to remove it from the driver's side lower panel.

am2zzw00007794

4.  Disconnect the bonnet release cable from the bonnet release lever.

5.  Install in the reverse order of removal.


Bonnet Release Cable


L.H.D.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the front bumper. (See FRONT BUMPER REMOVAL.) (See FRONT BUMPER INSTALLATION.)

3.  Remove the front mudguard (Driver's side). (See MUDGUARD REMOVAL/INSTALLATION.)

4.  Remove the bonnet latch protector. (See BONNET LATCH REMOVAL/INSTALLATION.)

5.  Disconnect the bonnet release cable from the bonnet latch.

6.  Remove the bonnet release cable from clips.

am2zzw00007795

7.  Remove the bonnet release cable from clips.

am2zzw00007796

8.  Remove the grommet.

9.  Pull out the hood release cable from front fender insulator No.1.

10.  Remove the bonnet release cable.

11.  Install in the reverse order of removal.


R.H.D.

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the front bumper. (See FRONT BUMPER REMOVAL.) (See FRONT BUMPER INSTALLATION.)

3.  Remove the front mudguard (Driver's side). (See MUDGUARD REMOVAL/INSTALLATION.)

4.  Remove the bonnet latch protector. (See BONNET LATCH REMOVAL/INSTALLATION.)

5.  Disconnect the bonnet release cable from the bonnet latch.

6.  Remove the bonnet release cable from clips.
