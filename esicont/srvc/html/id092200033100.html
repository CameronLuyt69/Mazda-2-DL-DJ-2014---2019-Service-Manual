INSTRUMENT CLUSTER OPERATION RECORD

id092200033100


Purpose

•  The instrument cluster stores the record of the warning/indicator lights which turned on or flashed as the operation record.

Function

•  The operation record is stored by the instrument cluster and displayed using the Mazda Modular Diagnostic System (M-MDS).
•  The instrument cluster stores the following when any of the warning/indicator lights turns on or flashes.
―  Time and date
―  Control module which sent warning/indicator lights light on/flash request
―  Battery voltage

Construction

•  Based on the stored record, the instrument cluster displays the following operation record on the Mazda Modular Diagnostic System (M-MDS) screen.
adejjn00003716

Operation

•  When the instrument cluster receives a CAN signal or a warning/indicator light on/flash request signal sent from each switch, it controls the warning/indicator light to turn on/flash and stores the operation record at the same time.

Fail-safe

•  Not applicable
