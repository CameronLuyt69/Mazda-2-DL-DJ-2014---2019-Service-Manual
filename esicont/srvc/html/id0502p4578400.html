DTC P1738:00

Automatic transaxle internal malfunction
DETECTION CONDITION
•  Malfunction location cannot be determined based on combination of gear ratio malfunction and oil pressure switch pattern malfunction.
FAIL-SAFE FUNCTION
•  Inhibits learning control.
•  Inhibits manual mode.
•  Inhibits i-stop control.
•  Inhibits AAS.
POSSIBLE CAUSE
•  ATF is less than specified value
•  Automatic transaxle internal malfunction
SYSTEM WIRING DIAGRAM
Not applicable

INSPECTION

ACTION
