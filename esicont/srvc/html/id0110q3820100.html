Bolt Removal/Installation Note

1.  When removing or installing the bolt, lock the idler pulley against rotation using the following procedure.

Caution
•  When connecting the positive battery cable to the magnetic clutch connector, use a cable with a female terminal of the correct size. Otherwise, load will be applied to the male terminal, resulting in deformation or damage, and poor contact. In addition, the positive battery cable could disconnect from the connector resulting in a short circuit.
1.  Apply battery positive voltage to the magnetic clutch terminal and apply battery negative voltage to the idler body.
am2zzw00011232
2.  Wrap the no longer usable drive belt tightly around the idler pulley.
am2zzw00011233
3.  Hold the drive belt in place with pliers.
4.  Remove or install the bolt.
5.  When replacing the idler body, replace the bolt.

Idler Pulley Removal Note

Note
•  Wrap protective tape around the tabs of the SST (49 0839 425C) so that the idler pulley is not scratched.

1.  Remove the idler pulley using the SST (49 0839 425C, 49 U027 001).

am2zzw00011234

Caution
•  If the idler pulley is removed with the SST (49 0839 425C) tabs attached to the stator, the stator could be damaged. When using the SST (49 0839 425C), make sure the tabs are not attached.

1.  Set the SST (49 F034 207) as shown in the figure.

2.  Install the idler pulley using the SST (49 0839 425C, 49 F034 207).

Caution
•  If the SSTs are not properly positioned when the idler pulley is press-fit, the idler axle will interfere with the SSTs, possibly damaging component parts. Verify that the SST and axle are properly positioned and perform the press-fit procedure very carefully.
