ADJUSTABLE SPEED LIMITER [SKYACTIV-D 1.5]

id0140z5300200


Purpose, Outline

•  For the purpose of safety performance improvement, the adjustable speed limiter restricts unintended excess vehicle speed by allowing the driver to optionally set the maximum vehicle speed.
•  The adjustable speed limiter restricts the engine output so that the vehicle speed does not exceed the set maximum vehicle speed even if the accelerator pedal is being depressed.
•  The adjustable speed limiter does not operate simultaneously with the cruise control system.
Note
•  Because the brakes are not used during engine output restriction, the vehicle speed could exceed the set maximum speed limit when the vehicle is descending a slope.
•  If the maximum vehicle speed exceeds the specified value, the instrument cluster flashes the maximum speed indicated in the display and activates the buzzer to warn the driver.

Function

•  The driver can change the adjustable speed limiter control condition by operating each type of switch on the steering wheel.
am2zzn00003709

SPEED LIMITER SWITCH
•  When the speed limiter switch is pressed, the adjustable speed limiter control condition goes on maximum vehicle speed setting standby.
•  The standby condition can be canceled by pressing the speed limiter switch while the adjustable speed limiter is on maximum vehicle speed setting standby.
SET (+)/SET (-) SWITCH
•  The maximum vehicle speed can be set.
•  Short-pressing the SET (+)/SET (-) switch adjusts the maximum vehicle speed in 1 km/h {0.6 mph} increments, and long-pressing it adjusts it in 10 km/h {6.2 mph} increments. Additionally, the maximum speed limit can be set between 30 km/h {19 mph} and 200 km/h {124 mph}.
RESUME (RES) SWITCH
•  The maximum vehicle speed can be set to the previous maximum vehicle speed recorded by the PCM.
CANCEL SWITCH
•  If the CANCEL button is pressed while the adjustable speed limiter control is operating, the adjustable speed limiter control is temporarily canceled.

Operation

•  The adjustable speed limiter control condition switches according to the driving conditions/each type of switch operation.
am2zzn00003711
•  When the variable speed limiter control transitions to a limiter temporarily canceled condition due to kickdown, if the actual vehicle speed exceeds the maximum vehicle speed by 3 km/h {2 mph} or more, the maximum vehicle speed flashes.
•  When the CANCEL switch is pressed, the variable speed limiter control is temporarily stopped.
•  While the adjustable speed limiter control is operating, the PCM restricts the engine output so that the maximum vehicle speed is not exceeded even if the accelerator pedal is depressed.

•  If the actual vehicle speed while descending a slope exceeds the maximum vehicle speed by 3 km/h {2 mph} or more, the PCM sends a adjustable speed limiter warning alarm activation request to the instrument cluster.The PCM cancels the activation request to the instrument cluster if the actual vehicle speed is decreased 3 km/h {2 mph} lower than the maximum vehicle speed.
•  The instrument cluster receives the activation request from the PCM and activates the adjustable speed limiter warning alarm.

Engine output restriction method

•  The PCM restricts the engine output using the following controls.
―  Fuel injection control
•  Engine output is restricted by performing fuel-cutting.
•  The TCM shifts the gears optimally according to the control condition signal/set vehicle speed signal from the PCM. (ATX)


Engine output restriction cancelation

•  While the adjustable speed limiter control is operating, the engine output restriction can be canceled by performing the following operations.
―  CANCEL switch is ON
―  Kickdown
―  Speed limiter switch is OFF*
―  Switch the ignition off*
*  :The adjustable speed limiter control condition is OFF.
