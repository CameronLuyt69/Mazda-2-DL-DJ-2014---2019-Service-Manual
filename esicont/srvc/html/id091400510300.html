INNER HANDLE REMOVAL/INSTALLATION

id091400510300


Front Inner Handle

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the power window main switch. (See POWER WINDOW MAIN SWITCH REMOVAL/INSTALLATION.)

3.  Remove the front door trim. (See FRONT DOOR TRIM REMOVAL/INSTALLATION.)

4.  Disconnect the door lock knob cable and the inner handle cable from the front inner handle.

am2zzw00008331

5.  Install in the reverse order of removal.


Rear Inner Handle

1.  Disconnect the negative battery cable. (See NEGATIVE BATTERY CABLE DISCONNECTION/CONNECTION.)

2.  Remove the following parts:

(1)  Power window subswitch (with power window system) (See POWER WINDOW SUBSWITCH REMOVAL/INSTALLATION.)
(2)  Regulator handle (with manual window system) (See REGULATOR HANDLE REMOVAL.) (See REGULATOR HANDLE INSTALLATION.)
(3)  Rear door trim (See REAR DOOR TRIM REMOVAL/INSTALLATION.)

3.  Disconnect the door lock knob cable and the inner handle cable from the rear inner handle.

am2zzw00008332

4.  Install in the reverse order of removal.
