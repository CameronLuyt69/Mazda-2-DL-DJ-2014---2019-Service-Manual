LED HEADLIGHT WARNING LIGHT

id091800014700


Purpose

•  The LED headlight warning light notifies the driver the following conditions:
―  Headlight auto leveling system non-initialization
―  Headlight auto leveling system malfunction
―  LED headlight malfunction

Function

•  The instrument cluster flashes the LED headlight warning light based on the following signals:

Signal name

Sending module/part name

Communication method
Headlight auto leveling system non-initialization signal
Auto leveling control module
HS-CAN
Headlight auto leveling system malfunction signal/LED headlight malfunction signal

Construction

•  The LED headlight warning light is built into the instrument cluster.
am2zzn00001770

Operation

1.  When the auto leveling control module detects the headlight auto leveling system non-initialization, headlight auto leveling system malfunction, or LED headlight malfunction, it sends (1) a headlight auto leveling system non-initialization signal or headlight auto leveling system malfunction signal/LED headlight malfunction signal to the instrument cluster via CAN communication.
2.  The instrument cluster turns the transistor on (2) intermittently based on each signal.
3.  When the transistor turns on intermittently, the LED headlight warning light flashes (3).
