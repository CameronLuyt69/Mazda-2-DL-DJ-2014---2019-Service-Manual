DRIVE SELECTION SYSTEM [SKYACTIV-G 1.3, SKYACTIV-G 1.5]

id0121a2000100


Outline

•  The drive selection system can switch the vehicle’s drive mode.
•  When the sport mode is selected, the drive force response corresponding to the accelerator pedal operation is enhanced.

Function

•  The sport mode can be selected/canceled by operating the drive selection switch.

Operation


When sports mode is selected

1.  When the sports mode is selected using the drive selection switch (1), the instrument cluster sends a drive selection signal to the TCM and the PCM via CAN communication (2). At the same time, it turns the select mode indicator light on (3).

2.  When the PCM sends a drive selection signal to the TCM, the TCM will change the shift points. (4)

3.  When the PCM receives the drive selection signal, it switches the control corresponding to the accelerator opening angle (5).

Drive selection switch inhibition conditions

•  If any of the following conditions is met, the mode is not switched even if the drive selection switch is operated.
―  During sudden maneuvering
―  During DSC control
―  During ABS control
•  If the drive selection switch has been operated with a drive selection switching inhibition condition being met, the PCM sends a sport light flash request signal to the instrument cluster.
•  The instrument cluster flashes the sport lamp to notify the driver that drive selection is currently prohibited.


Drive selection stop conditions

•  If any of the following conditions is met while in sport mode, the drive mode is canceled.
―  Ignition is switched off
―  During cruise control operation
―  Malfunction with PCM control-related part
