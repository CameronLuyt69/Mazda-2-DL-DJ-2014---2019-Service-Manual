AUTOMATIC TRANSAXLE REMOVAL/INSTALLATION [CW6A-EL]

id0517l1117200

Caution
•  If the automatic transaxle has been replaced, perform TCM configuration. (See TCM CONFIGURATION [CW6A-EL].)
•  If the automatic transaxle has been replaced, perform initial learning. (See INITIAL LEARNING [CW6A-EL].)
•  Performing the following procedures without first removing the front ABS wheel-speed sensor may possibly cause an open circuit in the harness if it is pulled by mistake. Before performing the following procedures, disconnect the front ABS wheel-speed sensor (axle side) and fix it to an appropriate place where the sensor will not be pulled by mistake while servicing the vehicle.
•  Secure the steering wheel using tape or a cable to prevent the steering shaft from rotating after disconnecting the steering shaft. If the steering wheel rotates after the steering shaft and the steering gear and linkage are disconnected, the internal parts of the clock spring could be damaged.

No.4 Engine Mount Bracket Removal Note

Caution
•  A slot has been adopted for the No.4 engine mount bracket installation hole. If the No.4 engine mount bracket is deviated from the original position when installing the No.4 engine mount, engine noise or vibration could increase. When removing the No.4 engine mount, place alignment marks on the No.4 engine mount bracket so that they can be assembled to the same positions as before removal.
