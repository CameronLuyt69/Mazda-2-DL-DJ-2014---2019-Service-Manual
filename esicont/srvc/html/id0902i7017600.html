DTC U0423:68 [HEADLIGHT AUTO LEVELING SYSTEM]

id0902i7017600

Description

Error signal received from instrument cluster
Detection condition
•  Auto leveling control module received headlight illumination state signal which undefined for 5 s or more with the ignition switched ON (engine off or on).
Fail-safe
•  Control of the headlight auto leveling system is continued.
Possible cause
•  DTCs are stored in the instrument cluster.
•  Instrument cluster malfunction
•  Auto leveling control module malfunction
System wiring diagram
Not applicable

Step

Action
