INTERIOR LIGHTING SYSTEM

id091800012200


Outline

•  A room light control system has been adopted in which the illumination time and illumination level of the interior lights change.

Function

•  The BCM turns the interior light on/off based on each switch and door/trunk lid (4SD)/liftgate (5HB) open/close condition signal.

Interior light off function

•  When the BCM receives a lock signal on the remote transmitter with the ignition switched off and all doors/trunk lid (4SD)/liftgate (5HB) closed, it automatically turns the interior light off.
