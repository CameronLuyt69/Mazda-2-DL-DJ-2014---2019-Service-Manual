DTC B1D19:00 [CONNECTIVITY MASTER UNIT]

id0902n7091000

Description

Region code error or parental lock function error
Detection condition
•  The connectivity master unit (CMU) detects a region code error or parental lock function error with the ignition switched ON (engine off or on).
Fail-safe
Not applicable
Possible cause
•  Use of incompatible DVD
―  The region code of the DVD inserted in the DVD/CD player differs from the region code which can be played by DVD/CD player.
•  The DVD viewing restriction level is out of the viewing restriction level set using the parental lock function, and the PIN code input failed.
•  DVD/CD player malfunction
System wiring diagram
Not applicable

Diagnostic Procedure

Step

Inspection

Action
1
VERIFY DVD REGION CODE
Note
•  The region code which can be played by the vehicle DVD/CD player is region 2 (for Europe and Japan).
•  Verify the region code indicated on the back of the DVD package or the DVD label of the unplayable DVD.
•  Is region code 2 indicated?
Yes
Go to the next step.
No

2
VERIFY IF CAUSE IS VIEWING RESTRICTION LEVEL SETTING
•  Operate the center display as follows and verify if the parental lock function has been set.
1.  Select “Entertainment” on the home screen.
2.  Select “DVD” on the entertainment screen.
3.  Select the parental lock button on the DVD screen.
4.  Verify the “Parental Lock” setting on the parental lock screen.
•  Is the function set to “ON”?
Yes
Verify the DVD package to check whether a viewing restriction level has been set on the disc.
Viewing restriction level has been set:
•  Explain the following to the customer and input the PIN code which has been set.
―  If the DVD viewing restriction level is out of the viewing restriction level set using the parental lock function, playback of the media has been restricted.
―  To play a DVD with the parental lock function set to valid, input of the PIN code (4-digit) set by the customer is required.
Viewing restriction level has not been set:
•  Go to the next step.
No
