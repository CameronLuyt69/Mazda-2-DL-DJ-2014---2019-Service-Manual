DTC U1A14:49 [LASER SENSOR]

id0402c4894700

DTC
U1A14:49
Laser sensor
DETECTION CONDITION
•  Electronic malfunction detected by self-diagnosis program of laser sensor when the ignition is switched ON
FAIL-SAFE FUNCTION
•  Smart City Brake Support (SCBS) warning light (amber) Illuminates
•  Smart City Brake Support (SCBS) control disabled
POSSIBLE CAUSE
•  Laser sensor malfunction
SYSTEM WIRING DIAGRAM
—


Diagnostic Procedure

Step

Inspection

Action
1
RECORD CONFIGURATION DATA
•  Switch the ignition to OFF.
•  Switch the ignition ON (engine off).
Go to the next step.
2
VERIFY DTC TROUBLESHOOTING COMPLETED
•  Using the M-MDS, clear the DTC from the laser sensor.
(See CLEARING DTC [LASER SENSOR].)
•  Using the M-MDS, perform the laser sensor DTC inspection.
(See DTC INSPECTION [LASER SENSOR].)
•  Is the same DTC present?
Yes
Repeat the inspection from Step1.
If the malfunction recurs, replace the laser sensor, then go to the next step.
(See LASER SENSOR REMOVAL/INSTALLATION.)
No
Go to the next step.
3
VERIFY NO DTC IS PRESENT
•  Are any DTCs present?
Yes
Go to applicable DTC inspection.
(See DTC TABLE [LASER SENSOR].)
No
DTC troubleshooting completed.
