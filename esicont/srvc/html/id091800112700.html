REAR MAP LIGHT

id091800112700


Purpose

•  The rear map light illuminates the center of the vehicle interior.

Function

•  When the room light switch for the front map light is in the ON position, the rear map light turns on.
•  The rear map light turns on according to the lock condition of the driver's door and open/close conditions of the doors under the BCM control when the room light switch for front map light is in the DOOR position.

Construction

•  The rear map light is positioned in the center part of the headliner.
am2zzn00001782

Operation


Room light switch for front map light operation

ON position
1.  When the room light switch for the front map light is in the ON position (1), the rear map light turns on (2).
Note
•  When the BCM receives a lock signal on the remote transmitter with the ignition switched off and all doors/ trunk lid (4SD)/liftgate (5HB) closed, it automatically turns the rear map light off.
am2zzn00001783


DOOR position

1.  When any door is opened (2) with the room light switch for the front map light in the DOOR position (1), the BCM detects (3) a door open signal.
2.  When the BCM detects the door open signal, it sends (4) the rear map light on request signal to the electrical supply unit (ESU) via LIN communication.
3.  When the electrical supply unit (ESU) receives the rear map light on request signal, it turns the transistor on (5).
4.  When the transistor is on, the rear map light turns on (6).
Note
•  When the room light switch for the front map light is in the DOOR position, the room light control system controls the timing for turning the rear map light on and off. For details, refer to the [ROOM LIGHT CONTROL SYSTEM]. (See ROOM LIGHT CONTROL SYSTEM.)
