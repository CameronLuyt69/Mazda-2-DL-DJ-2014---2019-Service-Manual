DTC P0610:00

PCM vehicle configuration error
DETECTION CONDITION
•  PCM data configuration error.
Diagnostic support note
•  This is a continuous monitor (CCM).
•  The check engine light illuminates if the PCM detects the above malfunction condition during the first drive cycle.
•  FREEZE FRAME DATA/Snapshot data is available.
•  DTC is stored in the PCM memory.
FAIL-SAFE FUNCTION
Not applicable
POSSIBLE CAUSE
•  Configuration procedure has not been completed
•  PCM connector or terminals malfunction
•  PCM malfunction
SYSTEM WIRING DIAGRAM
Not applicable

STEP

INSPECTION

ACTION

•  Switch the ignition off.
•  Disconnect the PCM connector.
•  Inspect for poor connection (such as damaged/pulled-out pins, corrosion).

Yes

No

(See PCM CONFIGURATION (USING READ/WRITE FUNCTION) [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)

5
VERIFY DTC TROUBLESHOOTING COMPLETED

(See KOEO/KOER SELF TEST [SKYACTIV-G 1.3, SKYACTIV-G 1.5].)

Go to the next step.
