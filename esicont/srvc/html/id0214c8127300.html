REAR COIL SPRING REMOVAL/INSTALLATION [REAR BRAKE (DISC)]

id0214c8127300

Caution
•  Performing the following procedures without first removing the rear ABS wheel-speed sensor may possibly cause an open circuit in the wiring harness if it is pulled by mistake. Before performing the following procedures, disconnect the rear ABS wheel-speed sensor wiring harness (axle side) and fix the wiring harness to an appropriate place where it will not be pulled by mistake while servicing the vehicle.
Note
•  Even when replacing only one of the left or right rear coil springs, to assure a space for the rear coil spring, remove the rear shock absorber lower side bolts on both the left and right sides so that the rear side of the torsion beam axle can be lowered.

1.  Remove the rear ABS wheel-speed sensor from the wheel hub component.

am2zzw00008242

2.  Remove the rear ABS wheel-speed sensor wiring harness from the bracket and set it aside.

3.  Disconnect the auto leveling sensor link. (With headlight auto leveling system)

am2zzw00008235

4.  Support the torsion beam axle using a jack.

Warning
•  If the torsion beam axle falls off while it is removed/installed, it may cause serious injury or death, or vehicle damage. Always use a jack when removing/installing the torsion beam axle and verify that it is securely supported.

5.  Remove in the order indicated in the table.

6.  Install in the reverse order of removal.

2

Rear Coil Spring Installation Note

1.  Install the rear coil spring with the mark facing the vehicle lower side.

am2zzw00008120

2.  Install the rear coil spring with the end of the coil spring seated on the stopper of the upper spring seat.

3.  Install the upper spring seat pin to the positioning hole on the body side.
