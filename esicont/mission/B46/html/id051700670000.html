Preparation Before Servicing

1.  Print out the measurement/adjustment value input sheet. (See MEASUREMENT/ADJUSTMENT VALUE INPUT SHEET.)

Note
•  When performing the measurement/adjustment, input the measured and calculated values into the measurement/adjustment value input sheet.
•  If the measurement/adjustment value input sheet has already been printed out for the other measurements/adjustments, use the sheet.


Secondary Gear and Output Gear End Play Measurement/Adjustment

1.  Calculate distance A of the converter housing using the following procedure:

A  :Distance A
B  :Converter housing end (alignment surface with transaxle case)
(1)  Remove any remaining old sealant on the contact surfaces of the transaxle case and converter housing.
(2)  Set the transaxle case of the converter housing so that the mating surface side is facing upward.
bcw6ja00000990
(3)  Measure the thickness of the straight edge rulers.
Note
•  Recommended measuring instrument: Micrometer
(4)  Input the straight edge ruler thickness into the measurement/adjustment value input sheet.
(5)  Set 2 straight edge rulers and the depth micrometer to the converter housing.

A  :Straight edge ruler
(6)  Measure the optional positions (3 locations) shown in the figure with a depth micrometer and subtract the thickness of the straight edge ruler to calculate distance A.
Note
•  Recommended measuring instrument: Depth micrometer, straight edge ruler

(7)  Input distance A and distance A average value into the measurement/adjustment value input sheet.
(8)  Remove the 2 straight edge rulers and depth micrometer from the converter housing.

5.  Calculate distance B of the secondary gear and output gear using the following procedure.

bcw6ja00000999

A  :Distance B
B  :Transaxle case end (alignment surface with converter housing)
(1)  Measure the thickness of the SST (49 G027 004).
Note
•  Recommended measuring instrument: Micrometer
(2)  Input the thickness of the SST in the measurement/adjustment value input sheet.
(3)  Install the thickness measured SST on to the thrust needle bearing.
Caution
•  Install the SST to the center of the thrust needle bearing to reduce measurement differences on the secondary gear and output gear end play measurement.
bcw6ja00001008
(4)  Set the 2 straight edge rulers and depth micrometer to the transaxle case.
bcw6ja00001009
A  :Straight edge ruler
(5)  Measure near the SST center with a depth micrometer.
Caution
•  Measure near the center of the SST to reduce measurement differences on the secondary gear and output gear end play measurement.
Note
•  Recommended measuring instrument: Depth micrometer, straight edge ruler
(6)  Input the depth micrometer measurement value into the measurement/adjustment value input sheet.
(7)  Perform the following calculation to calculate distance B.
Distance B = A - D - E
A: Straight edge ruler thickness
D: SST thickness
E: Depth micrometer measurement value
Note
Example
A: Straight edge ruler thickness is 39.76 mm {1.565 in}
D: SST thickness is 15.00 mm {0.5906 in}
E: Depth Micrometer measurement value is 5.82 mm {0.229 in}
Distance B = 39.76 mm {1.565 in} - 15.00 mm {0.5906 in} - 5.82 mm {0.229 in}= 18.94 mm {0.7457 in}
(8)   Input distance B into the measurement/adjustment value input sheet.
