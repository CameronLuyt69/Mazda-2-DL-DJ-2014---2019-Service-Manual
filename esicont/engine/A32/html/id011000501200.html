VALVE GUIDE REPLACEMENT

id011000501200


Removal

1.  Tap the valve guide out from combustion chamber side using the SST.

bes3ze00000015


Installation

1.  Apply clean engine oil to the valve guide.

2.  Tap the valve guide from the camshaft side using the SST so that the projection height (dimension A) is within the specification.

bes3ze00000016

Standard valve guide projection height
14.8—15.3 mm {0.583—0.602 in}
